### Q1: 岛屿数量（LeetCode 200）

**题目**：给定 `'1'`（陆地）和 `'0'`（水）组成的二维网格，计算岛屿数量。

**思路**：遍历网格，遇到 `'1'` 就 DFS 把整个岛"沉掉"（标记为 `'0'`），计数+1。

```python
def num_islands(grid: list[list[str]]) -> int:
    if not grid:
        return 0

    rows, cols = len(grid), len(grid[0])
    count = 0

    def dfs(r, c):
        if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] != '1':
            return
        grid[r][c] = '0'  # 沉岛
        dfs(r + 1, c)
        dfs(r - 1, c)
        dfs(r, c + 1)
        dfs(r, c - 1)

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                count += 1
                dfs(r, c)
    return count
```

**复杂度**：时间 O(M×N)，空间 O(M×N)（递归栈最坏情况）。

### Q2: 二叉树的路径总和（LeetCode 112）

**题目**：判断二叉树是否存在从根到叶子的路径，其节点值之和等于目标值。

```python
def has_path_sum(root, target_sum: int) -> bool:
    if not root:
        return False
    # 叶子节点：检查剩余值是否为 0
    if not root.left and not root.right:
        return root.val == target_sum
    remaining = target_sum - root.val
    return (has_path_sum(root.left, remaining) or
            has_path_sum(root.right, remaining))
```

### Q3: 课程表（LeetCode 207）

**题目**：判断能否完成所有课程（检测有向图是否有环）。

**思路**：拓扑排序（Kahn 算法）。如果排序后的节点数 = 总课程数，说明无环。

```python
from collections import deque, defaultdict

def can_finish(num_courses: int, prerequisites: list[list[int]]) -> bool:
    graph = defaultdict(list)
    in_degree = [0] * num_courses

    for course, prereq in prerequisites:
        graph[prereq].append(course)
        in_degree[course] += 1

    queue = deque([i for i in range(num_courses) if in_degree[i] == 0])
    count = 0

    while queue:
        node = queue.popleft()
        count += 1
        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    return count == num_courses
```

```python
def subsets(nums: list[int]) -> list[list[int]]:
    result = []

    def backtrack(start, path):
        result.append(path[:])
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1, path)
            path.pop()
```

```python
def permute(nums: list[int]) -> list[list[int]]:
    result = []

    def backtrack(path, remaining):
        if not remaining:
            result.append(path[:])
            return
        for i in range(len(remaining)):
            path.append(remaining[i])
            backtrack(path, remaining[:i] + remaining[i+1:])

    backtrack([], nums)
```

### Q8: 括号生成（LeetCode 22）

**题目**：生成所有合法的 n 对括号组合。

```python
def generate_parenthesis(n: int) -> list[str]:
    result = []

    def backtrack(path, open_count, close_count):
        if len(path) == 2 * n:
            result.append(''.join(path))
            return
        if open_count < n:
            path.append('(')
            backtrack(path, open_count + 1, close_count)
            path.pop()
        if close_count < open_count:
            path.append(')')
            backtrack(path, open_count, close_count + 1)
            path.pop()

    backtrack([], 0, 0)
    return result
```

**剪枝条件**：左括号数 < n 可以加左括号；右括号数 < 左括号数可以加右括号。

### Q9: 组合总和（LeetCode 39）

```python
def combination_sum(candidates: list[int], target: int) -> list[list[int]]:
    result = []
    candidates.sort()

    def backtrack(start, path, remaining):
        if remaining == 0:
            result.append(path[:])
            return
        for i in range(start, len(candidates)):
            if candidates[i] > remaining:
                break  # 排序后剪枝
            path.append(candidates[i])
            backtrack(i, path, remaining - candidates[i])  # i 不是 i+1，允许重复
            path.pop()

    backtrack(0, [], target)
    return result
```

```python
def max_area_of_island(grid: list[list[int]]) -> int:
```

### Q12: 网络延迟时间（LeetCode 743）—— Dijkstra

**题目**：给定 n 个节点的有向加权图和起始节点 k，求信号到达所有节点的最短时间。

```python
import heapq

def network_delay_time(times: list[list[int]], n: int, k: int) -> int:
    graph = defaultdict(list)
    for u, v, w in times:
        graph[u].append((v, w))

    dist = {}
    pq = [(0, k)]

    while pq:
        d, u = heapq.heappop(pq)
        if u in dist:
            continue
        dist[u] = d
        for v, w in graph[u]:
            if v not in dist:
                heapq.heappush(pq, (d + w, v))

    if len(dist) != n:
        return -1  # 有节点不可达
    return max(dist.values())
```

### Q13: 冗余连接（LeetCode 684）—— 并查集

**题目**：一个本该是树的图多了一条边，找出可以删除的那条边。

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y) -> bool:
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return False
        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1
        return True

def find_redundant_connection(edges: list[list[int]]) -> list[int]:
    n = len(edges)
    uf = UnionFind(n + 1)  # 节点从 1 开始
    for u, v in edges:
        if not uf.union(u, v):
            return [u, v]  # 这条边使图产生了环
    return []
```

### Q14: 单词搜索（LeetCode 79）—— 回溯

**题目**：给定字母二维网格和一个单词，判断单词是否存在于网格中（相邻字母连接，不重复使用）。

```python
def exist(board: list[list[str]], word: str) -> bool:
    rows, cols = len(board), len(board[0])

    def backtrack(r, c, idx):
        if idx == len(word):
            return True
        if (r < 0 or r >= rows or c < 0 or c >= cols or
            board[r][c] != word[idx]):
            return False

        temp = board[r][c]
        board[r][c] = '#'  # 标记为已访问

        found = (backtrack(r+1, c, idx+1) or backtrack(r-1, c, idx+1) or
                 backtrack(r, c+1, idx+1) or backtrack(r, c-1, idx+1))

        board[r][c] = temp  # 回溯恢复
        return found

    for r in range(rows):
        for c in range(cols):
            if backtrack(r, c, 0):
                return True
    return False
```

### Q16: 二叉树的最近公共祖先（LeetCode 236）

```python
def lowest_common_ancestor(root, p, q):
    if not root or root == p or root == q:
        return root
    left = lowest_common_ancestor(root.left, p, q)
    right = lowest_common_ancestor(root.right, p, q)
```

- 如果 p 和 q 分别在左右子树，当前节点就是 LCA
- 否则返回非空的那一侧

```python
def find_order(num_courses: int, prerequisites: list[list[int]]) -> list[int]:
```

### Q18: 分割回文串（LeetCode 131）—— 回溯

```python
def partition(s: str) -> list[list[str]]:
    result = []

    def is_palindrome(sub):
        return sub == sub[::-1]

    def backtrack(start, path):
        if start == len(s):
            result.append(path[:])
            return
        for end in range(start + 1, len(s) + 1):
            sub = s[start:end]
            if is_palindrome(sub):
                path.append(sub)
                backtrack(end, path)
                path.pop()

    backtrack(0, [])
    return result
```

**优化**：可以预计算回文子串（DP 二维表），避免重复判断。

### Q19: 二叉树中的最大路径和（LeetCode 124）

**题目**：找出二叉树中路径和最大的路径（不一定经过根节点）。

```python
def max_path_sum(root) -> int:
    max_sum = float('-inf')

    def dfs(node) -> int:
        """返回以 node 为端点的最大单边路径和"""
        nonlocal max_sum
        if not node:
            return 0

        left = max(dfs(node.left), 0)   # 负数贡献取 0
        right = max(dfs(node.right), 0)

        # 经过当前节点的最大路径和（左-根-右）
        max_sum = max(max_sum, left + node.val + right)

        # 返回给父节点：只能选一边
        return node.val + max(left, right)

    dfs(root)
    return max_sum
```

**关键**：每个节点的"经过路径和" = left + val + right；但**返回给父节点时只能选一边**。

**追问**：为什么 `left` 和 `right` 要和 0 取 max？因为如果子树路径和为负数，不如不走。

### Q20: 最小生成树 — Kruskal（LeetCode 1584 变体）

```python
def min_cost_connect_points(points: list[list[int]]) -> int:
    n = len(points)
    edges = []
    for i in range(n):
        for j in range(i + 1, n):
            dist = abs(points[i][0] - points[j][0]) + abs(points[i][1] - points[j][1])
            edges.append((dist, i, j))

    edges.sort()
    uf = UnionFind(n)
    total = 0
    count = 0

        if uf.union(u, v):
            total += w
            count += 1
            if count == n - 1:
                break
    return total
```

### Q21: N 皇后（LeetCode 51）

```python
def solve_n_queens(n: int) -> list[list[str]]:
    result = []
    board = [['.' for _ in range(n)] for _ in range(n)]
    cols = set()
    diag1 = set()  # row - col
    diag2 = set()  # row + col

    def backtrack(row):
        if row == n:
            result.append([''.join(r) for r in board])
            return
        for col in range(n):
            if col in cols or (row - col) in diag1 or (row + col) in diag2:
                continue
            board[row][col] = 'Q'
            cols.add(col)
            diag1.add(row - col)
            diag2.add(row + col)

            backtrack(row + 1)

            board[row][col] = '.'
            cols.remove(col)
            diag1.remove(row - col)
            diag2.remove(row + col)

    backtrack(0)
    return result
```

**剪枝三件套**：列冲突(`cols`)、主对角线(`row - col`)、副对角线(`row + col`)。

**复杂度**：时间 O(n!)，因为每行最多尝试 n 个位置，逐行减少。

**追问**：8 皇后有几种解法？92 种。N 皇后的总解数没有封闭公式。

### Q22: 外星人字典（LeetCode 269）—— 拓扑排序

**题目**：给定用外星语言排序的单词列表，推导出字母的排序顺序。

```python
def alien_order(words: list[str]) -> str:
    # 建图：比较相邻单词
    graph = defaultdict(set)
    in_degree = {c: 0 for word in words for c in word}

    for i in range(len(words) - 1):
        w1, w2 = words[i], words[i + 1]
        min_len = min(len(w1), len(w2))
        # 特判：如果 w1 是 w2 的前缀但更长，无效
        if len(w1) > len(w2) and w1[:min_len] == w2[:min_len]:
            return ""
        for j in range(min_len):
            if w1[j] != w2[j]:
                if w2[j] not in graph[w1[j]]:
                    graph[w1[j]].add(w2[j])
                    in_degree[w2[j]] += 1
                break

    # 拓扑排序
    queue = deque([c for c in in_degree if in_degree[c] == 0])
    order = []

    while queue:
        c = queue.popleft()
        order.append(c)
        for neighbor in graph[c]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    if len(order) != len(in_degree):
        return ""  # 有环
    return ''.join(order)
```

**核心**：通过比较相邻单词的首个不同字符来建立偏序关系，然后拓扑排序。

### S1: 社交网络好友推荐系统

**题目**：设计一个好友推荐系统。给定用户的好友关系图，为用户推荐"二度好友"（好友的好友，但不是直接好友）中共同好友最多的人。

**设计思路**：

```python
from collections import defaultdict, deque

def recommend_friends(graph: dict, user: str, top_k: int = 5) -> list:
    """
    graph: {user: [friend1, friend2, ...]}
    返回: [(推荐用户, 共同好友数), ...]
    """
    direct_friends = set(graph.get(user, []))
    direct_friends.add(user)  # 排除自己

    # BFS 找二度好友，统计共同好友数
    mutual_count = defaultdict(int)

    for friend in graph.get(user, []):
        for fof in graph.get(friend, []):  # friend of friend
            if fof not in direct_friends:
                mutual_count[fof] += 1

    # 按共同好友数降序排序
    recommendations = sorted(mutual_count.items(), key=lambda x: -x[1])
    return recommendations[:top_k]
```

**面试展开**：

- **时间复杂度**：O(F × F')，F 是好友数，F' 是好友的好友数
- **大规模优化**：
  - 预计算每个用户的二度好友列表（离线 MapReduce）
  - 用图数据库（Neo4j）直接查询二度关系
  - 结合用户特征（兴趣/地区/职业）做加权排序
- **实时性**：新增/删除好友关系后增量更新推荐

### S2: 任务调度系统设计

**题目**：设计一个支持任务依赖的调度系统。每个任务可能依赖其他任务，需要按正确顺序执行，并尽量并行。

```python
from collections import defaultdict, deque

def schedule_tasks(tasks: dict, dependencies: list) -> list[list[str]]:
    """
    tasks: {task_id: execution_time}
    dependencies: [(prerequisite, task)] 表示 task 依赖 prerequisite
    返回: 每个阶段可并行执行的任务列表
    """
    graph = defaultdict(list)
    in_degree = defaultdict(int)

    all_tasks = set(tasks.keys())
    for prereq, task in dependencies:
        graph[prereq].append(task)
        in_degree[task] += 1

    # BFS 分层 → 每层的任务可并行执行
    queue = deque([t for t in all_tasks if in_degree[t] == 0])
    schedule = []

    while queue:
        stage = []
        next_queue = deque()
        while queue:
            task = queue.popleft()
            stage.append(task)
            for dependent in graph[task]:
                in_degree[dependent] -= 1
                if in_degree[dependent] == 0:
                    next_queue.append(dependent)
        schedule.append(stage)
        queue = next_queue

    # 检测循环依赖
    completed = sum(len(s) for s in schedule)
    if completed != len(all_tasks):
        raise ValueError("Circular dependency detected!")

    return schedule

# 示例
tasks = {'A': 2, 'B': 3, 'C': 1, 'D': 4, 'E': 2}
deps = [('A', 'C'), ('B', 'C'), ('C', 'D'), ('C', 'E')]
print(schedule_tasks(tasks, deps))
# [['A', 'B'], ['C'], ['D', 'E']]
#  阶段1(并行)  阶段2    阶段3(并行)
```

**面试展开**：

- **关键路径法**：找到最长路径确定总工期，这条路径上的任务不能并行
- **贪心优化**：每个阶段内优先执行耗时长的任务（类似操作系统的 SJF 调度）
- **容错**：任务失败重试策略、依赖任务失败时的级联处理
- **分布式实现**：用 Airflow/Prefect 的 DAG 调度引擎

### S3: 地图导航最短路径设计

**题目**：设计一个地图导航系统，支持实时路线计算。

**核心算法**：Dijkstra 变体

```python
import heapq
from collections import defaultdict

class NavigationSystem:
    def __init__(self):
        self.graph = defaultdict(list)  # node → [(neighbor, travel_time)]
        self.traffic = {}               # (u, v) → 拥堵系数

    def add_road(self, u, v, base_time, bidirectional=True):
        self.graph[u].append((v, base_time))
        if bidirectional:
            self.graph[v].append((u, base_time))

    def update_traffic(self, u, v, congestion_factor):
        """实时更新交通拥堵系数"""
        self.traffic[(u, v)] = congestion_factor

    def _get_travel_time(self, u, v, base_time):
        """考虑实时交通的实际通行时间"""
        factor = self.traffic.get((u, v), 1.0)
        return base_time * factor

    def find_shortest_path(self, start, end):
        """Dijkstra + 实时交通权重"""
        dist = {start: 0}
        prev = {start: None}
        pq = [(0, start)]

        while pq:
            d, u = heapq.heappop(pq)
            if u == end:
                break
            if d > dist.get(u, float('inf')):
                continue
            for v, base_time in self.graph[u]:
                actual_time = self._get_travel_time(u, v, base_time)
                new_dist = d + actual_time
                if new_dist < dist.get(v, float('inf')):
                    dist[v] = new_dist
                    prev[v] = u
                    heapq.heappush(pq, (new_dist, v))

        # 回溯路径
        if end not in dist:
            return None, float('inf')
        path = []
        node = end
        while node is not None:
            path.append(node)
            node = prev[node]
        return list(reversed(path)), dist[end]
```

**面试展开**：

- **A\* 算法**：加启发式函数 h(n)（如直线距离），`f(n) = g(n) + h(n)`，优先探索方向正确的节点
- **双向 BFS/Dijkstra**：从起点和终点同时搜索，中间相遇，减少搜索空间
- **分层图/CH（Contraction Hierarchies）**：预处理阶段缩减图，查询阶段极速计算（Google Maps 核心）
- **实时交通**：定期更新边权（交通流数据源），或用 D\* Lite 增量更新最短路
- **多路径推荐**：最快/最短/避免高速/避免收费 → 多目标 Dijkstra 或 Pareto 最优

## 面试答题技巧总结

| 技巧                | 说明                                                           |
| ------------------- | -------------------------------------------------------------- |
| **画图**            | 图和树的题一定画示例图，理解结构再写代码                       |
| **BFS vs DFS 选型** | 最短路 → BFS，全路径/回溯 → DFS，两者都行的问题 → 选空间更优的 |
| **回溯三步曲**      | 1.做选择 2.递归 3.撤销选择。写之前先明确这三步                 |
| **贪心先验证**      | 想到贪心策略后，用小用例和边界用例验证再动手                   |
| **拓扑排序模板**    | Kahn 算法（入度表+BFS）是最好记的模板                          |
| **并查集默写**      | find(路径压缩) + union(按秩合并) 五分钟内写完                  |
| **复杂度先报**      | 面试写完代码后主动分析时间和空间复杂度                         |
