## ⭐ 基础题

### Q1：什么是动态规划？它和暴力递归、贪心算法有什么区别？

**参考答案**：

动态规划通过**存储子问题的解**避免重复计算。三者对比：

|            | 暴力递归   | 动态规划                | 贪心                         |
| ---------- | ---------- | ----------------------- | ---------------------------- |
| 子问题重叠 | 重复计算   | 记忆化/DP 表            | 不适用                       |
| 时间复杂度 | 通常指数级 | 多项式级                | 多项式级                     |
| 最优保证   | ✅         | ✅                      | ❌（局部最优不一定全局最优） |
| 适用条件   | 任何       | 最优子结构 + 重叠子问题 | 贪心选择性质                 |

### Q2：爬楼梯问题——n 级台阶，每次爬 1 或 2 级，有几种爬法？写出 DP 解法和空间优化。

**参考答案**：

```python
# DP 表
def climb(n):
    dp = [0] * (n + 1)
    dp[0], dp[1] = 1, 1
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]

# 空间优化：只需两个变量
def climb_opt(n):
    a, b = 1, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b
```

**追问**：如果每次可以爬 1/2/3 级呢？→ `dp[i] = dp[i-1] + dp[i-2] + dp[i-3]`

### Q3：0-1 背包问题的状态转移方程和空间优化是什么？

**参考答案**：

```
dp[i][w] = max(dp[i-1][w], dp[i-1][w-weight[i]] + value[i])

空间优化（逆序遍历）：
dp[w] = max(dp[w], dp[w-weight[i]] + value[i])  (w 从大到小遍历)
```

**为什么逆序？** 正序遍历时 dp[w-weight[i]] 可能已经被当前物品更新过，导致同一物品被选多次（变成完全背包）。

### Q4：零钱兑换——用最少硬币凑出金额 amount。给出状态设计和代码。

**参考答案**：

```python
def coin_change(coins, amount):
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    for i in range(1, amount + 1):
        for coin in coins:
            if coin <= i:
                dp[i] = min(dp[i], dp[i - coin] + 1)
    return dp[amount] if dp[amount] != float('inf') else -1
```

这是**完全背包**变体——每个硬币可以用无限次。

### Q5：最大子数组和的 DP 解法（Kadane 算法）是什么？

**参考答案**：

```python
def max_subarray(nums):
    max_sum = current = nums[0]
    for num in nums[1:]:
        current = max(num, current + num)  # 续上 or 从头开始
        max_sum = max(max_sum, current)
    return max_sum
```

`current` 代表"以当前元素结尾的最大子数组和"。如果加上当前元素后和比当前元素本身还小，就从当前元素重新开始。

### Q6：打家劫舍问题的 DP 思路？如果房屋排成环形怎么办？

**参考答案**：

**线性版**：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

**环形版**：首尾不能同时偷。分两种情况取最大值：

1. 偷第 1 间 → 不偷最后一间 → 在 nums[0:n-1] 上做线性版
2. 不偷第 1 间 → 在 nums[1:n] 上做线性版

### Q7：什么是"状态定义"？为什么说它是 DP 最难的一步？

**参考答案**：

状态定义就是决定 dp[i]（或 dp[i][j]）代表什么含义。它决定了：

- 转移方程怎么写
- 初始值怎么设
- 最终答案在哪

**常见状态定义模式**：

- `dp[i]` = 前 i 个元素的最优解（前缀型）
- `dp[i]` = 以第 i 个元素结尾的最优解（后缀型）
- `dp[i][j]` = 第 i 到 j 范围的最优解（区间型）

---

### Q8：最长递增子序列的 O(n²) DP 解法和 O(n log n) 优化思路分别是什么？

**参考答案**：

**O(n²)**：`dp[i] = max(dp[j] + 1) for j < i where nums[j] < nums[i]`

**O(n log n)**：维护 tails 数组（长度为 k 的 LIS 的最小末尾），每个新元素用二分查找定位。tails 始终有序，因此可以二分。

### Q9：编辑距离的转移方程和时间/空间复杂度？

**参考答案**：

```
dp[i][j] =
  dp[i-1][j-1]            if word1[i] == word2[j]
  1 + min(dp[i-1][j],     ← 删除
          dp[i][j-1],     ← 插入
          dp[i-1][j-1])   ← 替换
```

时间 O(mn)，空间 O(mn)，可优化到 O(min(m,n))。

**实际应用**：Git diff、拼写检查、DNA 比对。

### Q10：如何判断一个问题能用 DP 解？

**参考答案**：

两个必要条件：

1. **最优子结构**：大问题的最优解包含子问题的最优解（可以通过"剪切-粘贴"反证法验证）
2. **重叠子问题**：不同决策路径会遇到相同子问题

**判断技巧**：画出递归树，如果同一个节点出现多次就有重叠子问题。如果贪心选择导致反例就不能贪心，考虑 DP。

### Q11：完全背包和 0-1 背包在代码上的唯一区别是什么？为什么？

**参考答案**：

一维 DP 中，0-1 背包**逆序**遍历容量，完全背包**正序**遍历。

- 逆序：dp[w-weight] 还没被当前物品更新，保证每件只选一次
- 正序：dp[w-weight] 可能已包含当前物品，允许重复选

---

### Q12：最长公共子序列（LCS）和最长公共子串的区别？

**参考答案**：

- **LCS**：子序列可以不连续。状态：dp[i][j] = text1 前 i 和 text2 前 j 的 LCS 长度
- **最长公共子串**：必须连续。不匹配时 dp[i][j] = 0（不能从上方或左方继承）

### Q13：如何用 DP 解决"分割等和子集"问题？

**参考答案**：

判断数组能否分成两个子集使得和相等 → 转化为 0-1 背包：能否用若干元素凑出 sum/2。

```python
def can_partition(nums):
    total = sum(nums)
    if total % 2: return False
    target = total // 2
    dp = [False] * (target + 1)
    dp[0] = True
    for num in nums:
        for j in range(target, num - 1, -1):  # 0-1 背包逆序
            dp[j] = dp[j] or dp[j - num]
    return dp[target]
```

### Q14：股票买卖问题系列（最多 k 次交易）的通用 DP 框架？

**参考答案**：

```
状态：dp[i][k][0/1] = 第 i 天、已交易 k 次、持有(1)/未持有(0) 股票时的最大利润

转移：
dp[i][k][0] = max(dp[i-1][k][0], dp[i-1][k][1] + prices[i])  # 今天不操作 or 卖出
dp[i][k][1] = max(dp[i-1][k][1], dp[i-1][k-1][0] - prices[i])  # 不操作 or 买入
```

k=1、k=2、k=∞、含冷冻期、含手续费都是这个框架的特例。

### Q15：单词拆分（Word Break）问题的 DP 解法？

**参考答案**：

dp[i] = s[0:i] 能否被字典中的单词拆分

```python
def word_break(s, word_dict):
    dp = [False] * (len(s) + 1)
    dp[0] = True
    for i in range(1, len(s) + 1):
        for word in word_dict:
            if i >= len(word) and dp[i - len(word)] and s[i-len(word):i] == word:
                dp[i] = True
                break
    return dp[len(s)]
```

### Q16：不同路径问题——网格从左上到右下有多少条路径？有障碍物时怎么处理？

**参考答案**：

无障碍：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`，初始化第一行和第一列为 1。

有障碍：障碍物处 dp = 0，且初始化时遇到障碍后面都是 0。

## ⭐⭐⭐ 高级题

### Q17：如何用 DP 解决矩阵链乘法问题？

**参考答案**：

区间 DP：dp[i][j] = 计算矩阵 i 到 j 连乘的最少标量乘法次数。枚举分割点 k：

```
dp[i][j] = min(dp[i][k] + dp[k+1][j] + p[i-1]*p[k]*p[j])  for k in [i, j-1]
```

时间 O(n³)，空间 O(n²)。

---

### Q18：什么是状态压缩 DP？以旅行商问题（TSP）为例说明。

**参考答案**：

用二进制位表示集合状态。`dp[mask][i]` = 访问了 mask 表示的城市集合，当前在城市 i 时的最短路径。

`mask = 0b10110` 表示访问了城市 1、2、4。

时间 O(2ⁿ × n²)，只适用于 n ≤ 20。

---

### Q19：DP 中的"滚动数组"和"空间压缩"分别是什么？

**参考答案**：

- **滚动数组**：dp[i] 只依赖 dp[i-1]，用两个一维数组交替使用
- **空间压缩**：直接在一个数组上原地修改（注意遍历顺序）

滚动数组更安全（不用考虑遍历顺序），空间压缩更极致（只用一行）。

---

### Q20：如何确定一个 DP 问题的遍历顺序？

**参考答案**：

**原则**：计算 dp[i][j] 时，它依赖的状态必须已经计算完毕。

- 依赖左和上方 → 从左到右、从上到下
- 依赖右和下方 → 从右到左、从下到上
- 区间 DP → 按区间长度从小到大遍历

---

### Q21：最长回文子序列和最长回文子串的 DP 区别？

**参考答案**：

- **子序列**（可不连续）：dp[i][j] = s[i..j] 中的最长回文子序列长度。遍历顺序：从下到上。
- **子串**（必须连续）：dp[i][j] = s[i..j] 是否是回文。如果 s[i]==s[j] 且 dp[i+1][j-1]，则 dp[i][j]=true。

另一个子串高效解法是 **Manacher 算法** O(n)。

---

### Q22：如何用 DP 求解"正则表达式匹配"（. 和 \* 通配符）？

**参考答案**：

```
dp[i][j] = s[0:i] 和 p[0:j] 是否匹配

转移：
  p[j-1] 是普通字符或 '.'：dp[i][j] = dp[i-1][j-1] and (s[i-1]==p[j-1] or p[j-1]=='.')
  p[j-1] 是 '*'：
    匹配 0 次：dp[i][j] = dp[i][j-2]
    匹配 1+ 次：dp[i][j] = dp[i-1][j] and (s[i-1]==p[j-2] or p[j-2]=='.')
```

## 🎯 场景题

### Q23：设计一个文本编辑器的"撤销/重做"功能。从编辑距离的角度分析，如何高效存储编辑历史？

**参考答案**：

不存储完整文本快照，而存储**操作增量**（插入/删除/替换），本质上就是编辑距离中的操作序列。撤销 = 反向执行操作（插入→删除，删除→插入，替换→换回来）。这就是 **Command 模式**的经典应用。

---

### Q24：推荐系统需要计算两个用户的"行为序列相似度"，你会选择什么算法？

**参考答案**：

选择 **LCS（最长公共子序列）** 或 **编辑距离** 的变体：

- LCS 衡量两个行为序列的共同行为数
- 归一化相似度 = LCS 长度 / max(len(seq1), len(seq2))
- 对于长序列，可以用 Hunt-Szymanski 算法将 LCS 从 O(mn) 优化到 O((r + n) log n)（r 是匹配对数）

### Q25：一个电商平台有 100 种商品，背包容量是用户预算。如何用 DP 生成"凑单推荐"（尽量接近包邮门槛）？

**参考答案**：

转化为 0-1 背包变体：物品 = 商品，价值 = 用户偏好评分，重量 = 价格，容量 = 预算。

```python
# dp[i] = 花 i 元能获得的最大偏好评分
dp = [0] * (budget + 1)
for item in items:
    for w in range(budget, item.price - 1, -1):
        dp[w] = max(dp[w], dp[w - item.price] + item.score)
```

实际工程中需考虑：商品库存、类目多样性约束（分组背包变体）、实时计算性能（预计算+缓存）。

### Q26：区间 DP 的通用模板是什么？用矩阵链乘法、石子合并、戳气球三道经典题说明。⭐⭐⭐

<details>
<summary>参考答案</summary>

**区间 DP 核心思想**：

在区间 `[i, j]` 上做决策，枚举分割点 k ∈ [i, j]，将大区间的最优解用子区间的最优解组合。

**通用模板**：

```python
# 按区间长度从小到大枚举（保证子问题已解决）
for length in range(2, n + 1):         # 区间长度
    for i in range(0, n - length + 1):  # 左端点
        j = i + length - 1              # 右端点
        dp[i][j] = float('inf')         # 或 -inf，取决于求 min/max
        for k in range(i, j):           # 分割点
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + cost(i, j, k))
```

**类比**：像切木棍——一根长木棍需要在若干位置切断，每次切割的代价等于被切段的长度。你需要找到最优切割顺序使总代价最小。

**题目一：矩阵链乘法**

> 给定 n 个矩阵的维度 `p[0..n]`，第 i 个矩阵维度为 `p[i-1] × p[i]`。求最少的标量乘法次数。

```python
def matrix_chain(p):
    n = len(p) - 1  # 矩阵个数
    dp = [[0] * n for _ in range(n)]

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = float('inf')
            for k in range(i, j):
                # 矩阵 i..k 乘 矩阵 k+1..j，合并代价 p[i]*p[k+1]*p[j+1]
                cost = dp[i][k] + dp[k+1][j] + p[i] * p[k+1] * p[j+1]
                dp[i][j] = min(dp[i][j], cost)

    return dp[0][n-1]
```

**题目二：石子合并（环形版本）**

> n 堆石子排成一排，每次合并相邻两堆，代价 = 两堆石子数之和。求最小总代价。

```python
def merge_stones(stones):
    n = len(stones)
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i+1] = prefix[i] + stones[i]

    dp = [[0] * n for _ in range(n)]
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = float('inf')
            for k in range(i, j):
                dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + prefix[j+1] - prefix[i])

    return dp[0][n-1]
```

环形变体：将数组复制一遍拼接（长度 2n），然后取 `min(dp[i][i+n-1])` for i in 0..n-1。

**题目三：戳气球（LeetCode 312）**

> 戳破所有气球获得最大硬币。戳破第 i 个气球获得 `nums[left] × nums[i] × nums[right]`。

关键转换：不考虑"戳破"的顺序，而是考虑**最后戳破的气球**。

```python
def maxCoins(nums):
    nums = [1] + nums + [1]  # 添加虚拟边界
    n = len(nums)
    dp = [[0] * n for _ in range(n)]

    for length in range(2, n):  # 区间长度（不含两端虚拟气球）
        for i in range(0, n - length):
            j = i + length
            for k in range(i + 1, j):  # k 是 [i,j] 中最后戳破的
                dp[i][j] = max(dp[i][j],
                    dp[i][k] + dp[k][j] + nums[i] * nums[k] * nums[j])

    return dp[0][n-1]
```

**追问**：区间 DP 的时间复杂度通常是 O(n³)，有优化方法吗？
→ 四边形不等式优化：如果 cost 函数满足四边形不等式，最优分割点 k 单调，可将 O(n³) 优化到 O(n²)。石子合并问题就满足此条件。

### Q27：树形 DP 的一般做法是什么？如何求树的直径？换根 DP（rerooting）解决什么问题？⭐⭐⭐

<details>
<summary>参考答案</summary>

**树形 DP 核心思想**：

在树上做 DP，状态定义在节点上，转移方向通常是**从子节点到父节点**（后序遍历）。

**类比**：公司组织架构——每个员工的绩效 = 自身表现 + 综合下属的贡献，从基层向上汇总。

**题目一：树的直径（两次 BFS 或树形 DP）**

树形 DP 方法：对每个节点维护经过它的最长路径 = 最深子树 + 次深子树。

```python
def tree_diameter(adj):
    """adj: 邻接表，adj[u] = [(v, weight), ...]"""
    n = len(adj)
    diameter = 0

    def dfs(u, parent):
        nonlocal diameter
        max_depth = 0  # 从 u 出发的最大深度

        for v, w in adj[u]:
            if v == parent:
                continue
            child_depth = dfs(v, u) + w
            # 经过 u 的最长路径 = 之前的最大深度 + 当前子树深度
            diameter = max(diameter, max_depth + child_depth)
            max_depth = max(max_depth, child_depth)

        return max_depth

    dfs(0, -1)
    return diameter
```

- 时间复杂度：O(n)，一次 DFS
- 关键：在 DFS 过程中同时维护"最长"和"次长"子树路径

**题目二：换根 DP（以 LeetCode 834 "Sum of Distances in Tree" 为例）**

> 给定一棵 n 个节点的树，求每个节点到所有其他节点的距离之和。

朴素做法：对每个节点 BFS → O(n²)。换根 DP 可以做到 O(n)。

**两遍 DFS**：

```python
def sumOfDistancesInTree(n, edges):
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)

    count = [1] * n   # count[i] = 以 i 为根的子树大小
    dist = [0] * n    # dist[i] = i 到所有节点的距离和

    # 第一遍 DFS：以 0 为根，计算 count 和 dist[0]
    def dfs1(u, parent, depth):
        dist[0] += depth
        for v in adj[u]:
            if v != parent:
                dfs1(v, u, depth + 1)
                count[u] += count[v]

    dfs1(0, -1, 0)

    # 第二遍 DFS：换根——从 u 换到 v
    # dist[v] = dist[u] - count[v] + (n - count[v])
    # 解释：v 的子树节点都近了 1 步（-count[v]），其余节点都远了 1 步（+n-count[v]）
    def dfs2(u, parent):
        for v in adj[u]:
            if v != parent:
                dist[v] = dist[u] - count[v] + (n - count[v])
                dfs2(v, u)

    dfs2(0, -1)
    return dist
```

**换根公式的直觉**：把根从 u 移到 v（v 是 u 的子节点）时：
- v 的子树中的节点：距离都 -1（更近了），共 `count[v]` 个
- 其余节点：距离都 +1（更远了），共 `n - count[v]` 个
- 所以 `dist[v] = dist[u] + (n - count[v]) - count[v] = dist[u] + n - 2*count[v]`

**追问**：换根 DP 还能解决哪些问题？
→ 树上每个节点到最远叶子的距离、树的重心（使最大子树最小的节点）、树中每个节点为根时的最优解等。核心技巧都是"第一遍求一个根的答案，第二遍换根转移"。

</details>

### Q28：博弈 DP 和 SG（Sprague-Grundy）函数是什么？以 Nim 游戏和石子取子博弈为例说明。⭐⭐⭐

<details>
<summary>参考答案</summary>

**博弈 DP 基本框架**：

两个理性玩家交替操作，无随机因素，有终止状态。分析先手是否必胜。

**核心概念**：
- **必胜态（W）**：当前玩家有至少一种操作可以让对手进入必败态
- **必败态（L）**：当前玩家无论怎么操作，对手都进入必胜态

**类比**：两人轮流从一堆巧克力中拿（每次拿 1-3 块），拿到最后一块的人赢。4 块时先手必败（无论拿几块，对手都能拿完剩余）。

**Nim 游戏**：

> n 堆石子，每堆 a[i] 个。两人轮流从任一堆取任意数量（至少 1 个），取完最后一个的人赢。

```python
def nim_game(piles):
    xor_sum = 0
    for p in piles:
        xor_sum ^= p
    # Nim 定理：先手必胜当且仅当异或和 ≠ 0
    return xor_sum != 0
```

**Nim 定理证明直觉**：
1. 全为 0 → 终态，当前玩家输（必败态）
2. 异或和 = 0 → 无论取哪堆多少，异或和必变为非 0（对手进入必胜态 → 当前必败）
3. 异或和 ≠ 0 → 总存在一种取法使异或和变为 0（让对手进入必败态 → 当前必胜）

**SG 函数（Sprague-Grundy）**：

对于更复杂的组合博弈，SG 函数是 Nim 的推广。

```python
def sprague_grundy(state, moves_func, memo={}):
    """
    state: 当前游戏状态
    moves_func(state): 返回所有可达的后继状态
    SG(state) = mex({SG(next) for next in moves_func(state)})
    mex(S) = 最小的不在集合 S 中的非负整数
    """
    if state in memo:
        return memo[state]

    reachable_sg = set()
    for next_state in moves_func(state):
        reachable_sg.add(sprague_grundy(next_state, moves_func, memo))

    # mex: minimum excludant
    sg = 0
    while sg in reachable_sg:
        sg += 1

    memo[state] = sg
    return sg

# SG = 0 → 必败态（当前玩家输）
# SG > 0 → 必胜态（当前玩家赢）
```

**多堆组合博弈**：总 SG 值 = 各堆 SG 值的异或（SG 定理），与 Nim 完美类比。

**实际面试题：预测赢家（LeetCode 486）**

> 两人从数组两端取数，每次取一端，求先手能否得分 ≥ 后手。

```python
def predict_winner(nums):
    n = len(nums)
    # dp[i][j] = 当前玩家在 nums[i..j] 中能比对手多得的分数
    dp = [[0] * n for _ in range(n)]

    for i in range(n):
        dp[i][i] = nums[i]

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            # 取左端：得 nums[i]，对手在 [i+1, j] 中比你多 dp[i+1][j]
            # 取右端：得 nums[j]，对手在 [i, j-1] 中比你多 dp[i][j-1]
            dp[i][j] = max(nums[i] - dp[i+1][j], nums[j] - dp[i][j-1])

    return dp[0][n-1] >= 0
```

**追问**：如果改为"取到最后一个石子的人输"（反 Nim），结论怎么变？
→ 反 Nim（Misère Nim）：如果所有堆 ≤ 1，先手必胜当且仅当堆数为偶数；否则结论与正常 Nim 相同（异或和 ≠ 0 时先手必胜）。

</details>

### Q29：什么是状态压缩 DP 和数位 DP？各自的适用场景和模板是什么？⭐⭐⭐

<details>
<summary>参考答案</summary>

**状态压缩 DP（Bitmask DP）**：

当状态包含一个**集合**（如"哪些节点已访问"），用二进制位图表示集合，将指数级状态空间压缩到 O(2^n × n)。

**适用场景**：n ≤ 20 的 NP 难问题（旅行商、分配、棋盘覆盖等）

**经典题：旅行商问题（TSP）**

```python
def tsp(dist):
    """dist[i][j] = 城市 i 到 j 的距离，求最短哈密顿回路"""
    n = len(dist)
    INF = float('inf')
    # dp[mask][i] = 访问了 mask 表示的城市集合，当前在城市 i 的最短路径
    dp = [[INF] * n for _ in range(1 << n)]
    dp[1][0] = 0  # 从城市 0 出发

    for mask in range(1, 1 << n):
        for u in range(n):
            if dp[mask][u] == INF:
                continue
            if not (mask & (1 << u)):
                continue
            for v in range(n):
                if mask & (1 << v):  # v 已访问
                    continue
                new_mask = mask | (1 << v)
                dp[new_mask][v] = min(dp[new_mask][v], dp[mask][u] + dist[u][v])

    full_mask = (1 << n) - 1
    # 回到起点
    return min(dp[full_mask][i] + dist[i][0] for i in range(n))
```

**位运算技巧**：

```python
# 枚举 mask 的所有子集
sub = mask
while sub > 0:
    # sub 是 mask 的一个子集
    sub = (sub - 1) & mask

# 检查第 i 位是否为 1
if mask & (1 << i): ...

# 设置第 i 位
mask |= (1 << i)

# 清除第 i 位
mask &= ~(1 << i)

# 统计 1 的个数
bin(mask).count('1')  # 或 mask.bit_count() (Python 3.10+)
```

---

**数位 DP**：

统计 [L, R] 范围内满足某种"数位条件"的数的个数。

**核心思想**：从高位到低位逐位构造数字，用 `tight` 标志表示当前是否受上界限制。

**模板（以"不含连续相同数字的数的个数"为例）**：

```python
def count_special(n):
    """统计 [1, n] 中没有连续相同数字的数的个数"""
    digits = list(map(int, str(n)))
    L = len(digits)

    from functools import lru_cache

    @lru_cache(maxsize=None)
    def dp(pos, prev, tight, started):
        """
        pos: 当前处理的位置（从高位到低位）
        prev: 上一位的数字（-1 表示还没选）
        tight: 是否受上界限制
        started: 是否已经开始填非零数字（处理前导零）
        """
        if pos == L:
            return 1 if started else 0

        limit = digits[pos] if tight else 9
        result = 0

        for d in range(0, limit + 1):
            if started and d == prev:
                continue  # 不允许连续相同
            result += dp(
                pos + 1,
                d,
                tight and (d == limit),
                started or (d != 0)
            )

        return result

    return dp(0, -1, True, False)

# 求 [L, R] 范围 = count_special(R) - count_special(L - 1)
```

**数位 DP 的通用状态**：

| 参数    | 含义                                         |
| ------- | -------------------------------------------- |
| pos     | 当前位的位置                                 |
| tight   | 前面的位是否都取到上界（限制当前位的取值范围） |
| started | 是否已填非零数字（处理前导零）               |
| 自定义  | 题目相关状态（前一位数字、数位和、模余数等）  |

**追问**：如何用数位 DP 统计 [1, n] 中各数位之和为 k 的数的个数？
→ 在状态中加一个 `digit_sum` 维度，`dp(pos, digit_sum, tight, started)`，最终返回 `digit_sum == k` 时的计数。

</details>

### Q30：DP 有哪些常见优化技巧？用单调队列优化和斜率优化分别解一道题。⭐⭐⭐

<details>
<summary>参考答案</summary>

**DP 优化全景**：

| 优化技巧     | 适用条件                              | 复杂度提升         |
| ------------ | ------------------------------------- | ------------------ |
| 空间压缩     | 状态只依赖前一行/前两行               | O(n²) → O(n) 空间 |
| 单调队列优化 | 转移方程中的决策区间有大小限制         | O(nk) → O(n)      |
| 斜率优化     | 转移方程可变形为线性规划（凸包/斜率）  | O(n²) → O(n)      |
| 四边形不等式 | 区间 DP 中最优决策点单调               | O(n³) → O(n²)     |
| 数据结构优化 | 用线段树/树状数组加速状态查询          | 因题而异           |

---

**单调队列优化 DP**：

经典题：**滑动窗口最大值（LeetCode 239）的 DP 推广**

> 给定数组，求 dp[i] = max(dp[j] + cost(j, i)) for j in [i-k, i-1]

当决策范围有窗口限制时，用单调队列维护窗口内的最优决策。

实际题目——**跳跃游戏变体**：从位置 0 跳到 n-1，每次最多跳 k 步，每个位置有得分 nums[i]，求最大总得分。

```python
from collections import deque

def max_score_jump(nums, k):
    n = len(nums)
    dp = [float('-inf')] * n
    dp[0] = nums[0]
    dq = deque([0])  # 单调递减队列，存下标

    for i in range(1, n):
        # 移除窗口外的元素
        while dq and dq[0] < i - k:
            dq.popleft()

        # 队首就是窗口内 dp 最大值
        dp[i] = dp[dq[0]] + nums[i]

        # 维护单调性：新元素入队前，移除所有 dp 值 ≤ dp[i] 的队尾
        while dq and dp[dq[-1]] <= dp[i]:
            dq.pop()
        dq.append(i)

    return dp[n - 1]
```

- 每个元素最多入队出队各一次 → 总时间 O(n)

---

**斜率优化 DP**：

经典题：**任务安排问题 / 玩具装箱（IOI 类）**

> dp[i] = min(dp[j] + (sum[i] - sum[j] + i - j - 1 - L)²) for j < i

转移方程展开后，dp[i] 的决策可以表达为：在平面上的点集中，找与当前查询斜率最匹配的点。

**核心思想**：

1. 将转移方程变形为 `dp[j] + f(j) = g(i) × h(j) + dp[i] - c(i)` 的线性形式
2. 将 (h(j), dp[j] + f(j)) 视为二维平面上的点
3. 找使 dp[i] 最小的 j，等价于用斜率 g(i) 的直线从下方"托"这些点，首先碰到的点就是最优决策
4. 如果斜率 g(i) 单调，用单调队列维护下凸包即可

```python
def toy_packing(C, L):
    """C[i] = 第 i 个玩具长度，L = 容器基准长度"""
    n = len(C)
    S = [0] * (n + 1)
    for i in range(1, n + 1):
        S[i] = S[i-1] + C[i-1] + 1  # 前缀和（含间隔）

    dp = [0] * (n + 1)
    dq = deque([0])

    def Y(j):
        return dp[j] + (S[j] + L) ** 2

    def X(j):
        return S[j] + L

    for i in range(1, n + 1):
        # 斜率 = 2 * S[i]，单调递增
        # 队首检查：如果前两个点的斜率 < 当前查询斜率，弹出队首
        while len(dq) >= 2:
            j1, j2 = dq[0], dq[1]
            if (Y(j2) - Y(j1)) <= 2 * S[i] * (X(j2) - X(j1)):
                dq.popleft()
            else:
                break

        j = dq[0]
        dp[i] = dp[j] + (S[i] - S[j] - 1 - L) ** 2

        # 队尾维护凸包
        while len(dq) >= 2:
            j1, j2 = dq[-2], dq[-1]
            # 检查新点 i 是否使 j2 成为凸包上的冗余点
            if (Y(i) - Y(j1)) * (X(j2) - X(j1)) <= (Y(j2) - Y(j1)) * (X(i) - X(j1)):
                dq.pop()
            else:
                break
        dq.append(i)

    return dp[n]
```

**追问**：如果斜率不单调怎么办？
→ 不能用单调队列了，需要用**李超线段树**（Li Chao Segment Tree）或**CDQ 分治**维护凸包，支持任意斜率查询。

</details>

```python
# dp[i][k][0] = 第 i 天，已完成 ≤ k 次交易，不持有股票的最大利润
```

```python
dp[i][k][0] = max(dp[i-1][k][0],          # 保持不持有
```

```python
def max_profit_cooldown(prices):
    if not prices:
        return 0
    hold, empty, cooldown = -prices[0], 0, 0
    for price in prices[1:]:
        new_hold = max(hold, empty - price)
        new_empty = max(empty, cooldown)
        new_cooldown = hold + price
        hold, empty, cooldown = new_hold, new_empty, new_cooldown
    return max(empty, cooldown)
```

### Q32：零钱兑换系列问题如何用 DP 解决？完全背包和零钱兑换的关系是什么？⭐⭐

<details>
<summary>参考答案</summary>

**零钱兑换 I（LeetCode 322）—— 最少硬币数**：

> 凑出金额 amount 的最少硬币数。每种硬币无限供应。

这就是**完全背包的最小化版本**。

```python
def coinChange(coins, amount):
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0

    for coin in coins:
        for j in range(coin, amount + 1):
            dp[j] = min(dp[j], dp[j - coin] + 1)

    return dp[amount] if dp[amount] != float('inf') else -1
```

**关键区别**：0-1 背包内层**倒序**遍历（每个物品用一次），完全背包内层**正序**遍历（每个物品无限次）。

**零钱兑换 II（LeetCode 518）—— 组合数**：

> 有多少种方式凑出 amount？

```python
def change(amount, coins):
    dp = [0] * (amount + 1)
    dp[0] = 1

    for coin in coins:           # 外层遍历硬币种类
        for j in range(coin, amount + 1):  # 内层遍历金额
            dp[j] += dp[j - coin]

    return dp[amount]
```

**注意遍历顺序**：
- **求组合数**（不区分顺序）：外层遍历硬币，内层遍历金额
- **求排列数**（区分顺序）：外层遍历金额，内层遍历硬币

```python
# 排列数版本（如 LeetCode 377 组合总和 IV）
def combinationSum4(nums, target):
    dp = [0] * (target + 1)
    dp[0] = 1
    for j in range(1, target + 1):   # 外层遍历金额
        for num in nums:              # 内层遍历硬币
            if j >= num:
                dp[j] += dp[j - num]
    return dp[target]
```

**追问**：为什么遍历顺序影响组合/排列？
→ 外层遍历硬币时，硬币 A 只能在硬币 B 之前被考虑（固定顺序 → 组合）。外层遍历金额时，每个金额都会考虑所有硬币（允许任意顺序 → 排列）。

</details>

### Q33：分割等和子集（LeetCode 416）如何转化为 0-1 背包？有哪些优化技巧？⭐⭐

<details>
<summary>参考答案</summary>

**问题转化**：

> 给定正整数数组 nums，判断能否分为两个子集使得两子集元素和相等。

等价于：能否从 nums 中选出若干元素，使它们的和 = sum(nums) / 2？

这就是标准的 **0-1 背包可行性问题**（不求最大价值，只判断是否可达）。

```python
def canPartition(nums):
    total = sum(nums)
    if total % 2 != 0:
        return False  # 奇数不可能

    target = total // 2
    dp = [False] * (target + 1)
    dp[0] = True

    for num in nums:
        for j in range(target, num - 1, -1):  # 倒序 → 0-1 背包
            dp[j] = dp[j] or dp[j - num]

    return dp[target]
```

**优化技巧**：

1. **位运算加速**（用 bitset 代替 bool 数组）：

```python
def canPartition_bitset(nums):
    total = sum(nums)
    if total % 2:
        return False
    target = total // 2

    bits = 1  # 用一个大整数的二进制位表示可达状态
    for num in nums:
        bits |= (bits << num)  # 左移 num 位 = 用 num 更新所有可达状态

    return bool(bits & (1 << target))
```

Python 大整数的位运算在 C 层实现，比逐个遍历 bool 数组快得多。

2. **剪枝优化**：

```python
def canPartition_pruned(nums):
    total = sum(nums)
    if total % 2:
        return False
    target = total // 2

    nums.sort(reverse=True)  # 大数优先
    if nums[0] > target:
        return False  # 最大值已超过目标

    dp = {0}
    for num in nums:
        if num == target:
            return True
        dp = dp | {s + num for s in dp if s + num <= target}
        if target in dp:
            return True

    return target in dp
```

| 变体                            | 转化思路                                  |
| ------------------------------- | ----------------------------------------- |
| LeetCode 494（目标和）          | 选 + 和选 - 的分组 → 背包求方案数         |
| LeetCode 1049（最后一块石头 II） | 分两组使差最小 → 背包求最接近 sum/2 的和  |
| LeetCode 698（K 个相等子集）     | NP 难，回溯 + 剪枝 或 状态压缩 DP          |

**追问**：如果数组元素和可能非常大（如 10^9），背包开不了这么大的数组怎么办？
→ 如果元素种类少（如只有几十种不同值），可以用 "多重背包 + 二进制分组" 或直接用 set 记录可达状态。如果 n 较小（≤ 40），可用**折半搜索（Meet in the Middle）**：将数组分两半，各自枚举所有子集和，然后双指针匹配。
