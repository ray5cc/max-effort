## ⭐ 基础题

### Q1：常见排序算法的时间复杂度和稳定性分别是什么？

**参考答案**：

| 算法     | 平均时间   | 最坏时间   | 空间     | 稳定 |
| -------- | ---------- | ---------- | -------- | ---- |
| 冒泡排序 | O(n²)      | O(n²)      | O(1)     | ✅   |
| 选择排序 | O(n²)      | O(n²)      | O(1)     | ❌   |
| 插入排序 | O(n²)      | O(n²)      | O(1)     | ✅   |
| 归并排序 | O(n log n) | O(n log n) | O(n)     | ✅   |
| 快速排序 | O(n log n) | O(n²)      | O(log n) | ❌   |
| 堆排序   | O(n log n) | O(n log n) | O(1)     | ❌   |

**追问**：为什么快速排序不稳定？→ 分区操作中的交换可能改变相等元素的相对位置。

### Q2：什么是排序的"稳定性"？实际工程中什么时候需要稳定排序？

**参考答案**：

稳定性指相等元素排序后保持原来的相对顺序。

**实际场景**：数据库多列排序。先按"部门"排序，再按"工资"排序时，如果第二次排序不稳定，可能打乱同工资员工的部门排列顺序。这就是为什么 Python 的 `sorted()` 和 Java 的 `Arrays.sort(Object[])` 都使用稳定排序（TimSort）。

### Q3：手写二分搜索，并分析为什么 `mid = left + (right - left) // 2` 比 `mid = (left + right) // 2` 更好？

**参考答案**：

```python
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = left + (right - left) // 2  # 防止 left + right 整数溢出
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

当 `left` 和 `right` 都是非常大的整数时（如 Java 的 `int` 最大值 2³¹-1），`left + right` 会溢出。`left + (right - left) // 2` 在数学上等价但不会溢出。

### Q4：快速排序为什么实践中比归并排序快？

**参考答案**：

虽然两者平均都是 O(n log n)，但快排更快是因为：

1. **缓存友好**：快排在连续内存上原地操作，CPU 缓存命中率高；归并需要额外数组来回复制
2. **常数因子小**：快排的交换操作比归并的元素复制少
3. **分支预测友好**：快排的比较模式对 CPU 分支预测器更友好

但归并排序有自己的优势：**保证 O(n log n)**、**稳定**、**适合链表排序**（不需要随机访问）。

---

### Q5：插入排序在什么场景下比快排更快？

**参考答案**：

1. **数据量很小（n < 50）**：此时 O(n²) 的常数因子小，比 O(n log n) 的递归开销更快
2. **数据近乎有序**：插入排序对几乎有序的数据是 O(n)

这就是为什么 TimSort 在子数组较小时切换到插入排序，快排的优化版本也会在分区小于某个阈值时用插入排序。

### Q6：描述 BFS 和 DFS 的区别，各自适用什么场景？

**参考答案**：

| 特征       | BFS               | DFS          |
| ---------- | ----------------- | ------------ |
| 数据结构   | 队列              | 栈（或递归） |
| 搜索方式   | 层层推进          | 一条路走到底 |
| 空间复杂度 | O(分支因子^深度)  | O(深度)      |
| 最短路径   | ✅ 无权图最短路径 | ❌ 不保证    |

**BFS 适用**：最短路径、层序遍历、社交网络 N 度好友
**DFS 适用**：路径搜索、回溯问题（全排列/子集/N皇后）、拓扑排序、连通分量

### Q7：如何在 O(n) 时间内找到数组中第 K 大的元素？

**参考答案**：

使用**快速选择算法（QuickSelect）**——快排的变体：

```python
import random

def find_kth_largest(nums, k):
    k = len(nums) - k  # 转为第 k 小

    def quickselect(left, right):
        pivot_idx = random.randint(left, right)
        nums[pivot_idx], nums[right] = nums[right], nums[pivot_idx]
        store = left
        for i in range(left, right):
            if nums[i] < nums[right]:
                nums[store], nums[i] = nums[i], nums[store]
                store += 1
        nums[store], nums[right] = nums[right], nums[store]

        if store == k:
            return nums[store]
        elif store < k:
            return quickselect(store + 1, right)
        else:
            return quickselect(left, store - 1)

    return quickselect(0, len(nums) - 1)
```

平均 O(n)，因为每次只需处理一半（n + n/2 + n/4 + ... ≈ 2n）。

### Q8：堆排序的建堆过程为什么是 O(n) 而不是 O(n log n)？

**参考答案**：

虽然单次 heapify 是 O(log n)，但建堆时从底部向上调整，越底层的节点调整距离越短：

- 底层 n/2 个叶节点：不需要调整（0 步）
- 倒数第二层 n/4 个节点：最多调整 1 步
- 倒数第三层 n/8 个节点：最多调整 2 步
- ...
- 根节点 1 个：最多调整 log n 步

总和：n/4 × 1 + n/8 × 2 + n/16 × 3 + ... = O(n)（等比数列求和）

### Q9：在旋转排序数组 [4,5,6,7,0,1,2] 中搜索目标值，要求 O(log n)。

**参考答案**：

关键洞察：旋转数组总有一半是有序的。每次判断 mid 在哪一半，然后确定 target 在有序的那半还是无序的那半。

```python
def search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        if nums[left] <= nums[mid]:  # 左半有序
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        else:  # 右半有序
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1
    return -1
```

### Q10：如何用二分搜索解决"分割数组的最大值最小化"问题？

**参考答案**：

**问题**：将数组分成 m 段，使得各段和的最大值最小。

**关键思路**：二分答案！答案的范围在 [max(nums), sum(nums)] 之间。对于每个候选答案 mid，贪心检查能否分成 ≤ m 段，每段和 ≤ mid。

```python
def split_array(nums, m):
    def can_split(max_sum):
        count, current = 1, 0
        for num in nums:
            if current + num > max_sum:
                count += 1
                current = num
            else:
                current += num
        return count <= m

    left, right = max(nums), sum(nums)
    while left < right:
        mid = left + (right - left) // 2
        if can_split(mid):
            right = mid
        else:
            left = mid + 1
    return left
```

### Q11：归并排序如何统计逆序对数量？

**参考答案**：

在归并合并阶段，当右边元素 < 左边元素时，左边剩余的所有元素都与这个右边元素构成逆序对。

```python
def count_inversions(arr):
    if len(arr) <= 1:
        return arr, 0
    mid = len(arr) // 2
    left, left_inv = count_inversions(arr[:mid])
    right, right_inv = count_inversions(arr[mid:])

    merged, split_inv = [], 0
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            merged.append(left[i]); i += 1
        else:
            merged.append(right[j]); j += 1
            split_inv += len(left) - i  # 关键：左边剩余元素都是逆序对
    merged.extend(left[i:])
    merged.extend(right[j:])
    return merged, left_inv + right_inv + split_inv
```

### Q12：什么是 TimSort？为什么 Python 和 Java 都采用它？

**参考答案**：

TimSort 是归并排序和插入排序的混合算法：

1. **检测 run**：找到数组中已经有序的连续子序列（自然有序段）
2. **扩展短 run**：用插入排序将短 run 扩展到 minrun 长度（32-64）
3. **归并 run**：用归并排序合并这些 run，维护一个栈保证合并效率

**优势**：

- 对部分有序数据（现实中常见）接近 O(n)
- 最坏情况仍是 O(n log n)
- 稳定排序
- 利用了已有的顺序信息，不做无用功

### Q13：如何在两个有序数组中找到中位数？要求 O(log(min(m,n)))。

**参考答案**：

经典 LeetCode Hard 题。对较短数组做二分，找到一个分割点使得左半部分的所有元素 ≤ 右半部分：

```python
def find_median(nums1, nums2):
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1
    m, n = len(nums1), len(nums2)
    left, right = 0, m

    while left <= right:
        i = (left + right) // 2  # nums1 的分割点
        j = (m + n + 1) // 2 - i  # nums2 的分割点

        left1 = nums1[i-1] if i > 0 else float('-inf')
        right1 = nums1[i] if i < m else float('inf')
        left2 = nums2[j-1] if j > 0 else float('-inf')
        right2 = nums2[j] if j < n else float('inf')

        if left1 <= right2 and left2 <= right1:
            if (m + n) % 2 == 0:
                return (max(left1, left2) + min(right1, right2)) / 2
            return max(left1, left2)
        elif left1 > right2:
            right = i - 1
        else:
            left = i + 1
```

### Q14：回溯法解决 N 皇后问题的核心思路？

**参考答案**：

逐行放置皇后，检查列、主对角线、副对角线是否冲突。冲突则回溯。

```python
def solve_n_queens(n):
    result = []
    def backtrack(row, cols, diag1, diag2, board):
        if row == n:
            result.append([''.join(r) for r in board])
            return
        for col in range(n):
            if col in cols or (row-col) in diag1 or (row+col) in diag2:
                continue
            board[row][col] = 'Q'
            backtrack(row+1, cols|{col}, diag1|{row-col}, diag2|{row+col}, board)
            board[row][col] = '.'

    backtrack(0, set(), set(), set(), [['.']*n for _ in range(n)])
    return result
```

**关键优化**：用集合（set）O(1) 检查冲突，用 row-col 和 row+col 标识对角线。

### Q15：什么是"二分答案"？举一个例子说明。

**参考答案**：

**思想**：当直接求解困难时，如果答案具有单调性（答案越大/越小，越容易满足条件），就可以二分答案，对每个候选答案用贪心/模拟验证是否可行。

**经典例子**：木材切割——有 N 根木头，要切成 K 段等长的木头，求每段最大长度。

答案范围 [1, max(木头)]，对候选长度 mid，检查每根木头能切 `wood // mid` 段，总段数 ≥ K 则可行。

### Q16：如何对一个链表进行排序？最优时间和空间复杂度是什么？

**参考答案**：

归并排序最适合链表（O(n log n) 时间 + O(1) 空间）：

- 用快慢指针找中点
- 断开链表
- 递归排序两半
- 合并两个有序链表

快排不适合链表（随机访问 pivot 不方便），堆排序也不适合（需要数组随机访问）。

### Q17：解释快速排序的三向切分（3-way partition）及其应用场景。

**参考答案**：

标准快排将数组分为 [< pivot, >= pivot]，三向切分分为 [< pivot, = pivot, > pivot]。当数组有大量重复元素时，标准快排仍是 O(n²)（所有等于 pivot 的元素都在一边），三向切分可以跳过所有等于 pivot 的元素，从 O(n²) 优化到 O(n)。

**应用**：荷兰国旗问题（将 0/1/2 三种元素排序）——一次遍历 O(n) 完成。

### Q18：外部排序的原理是什么？如何优化多路归并？

**参考答案**：

当数据量远大于内存时：

1. **拆分排序**：将数据分成内存大小的块，逐块排序写回磁盘
2. **K 路归并**：打开 K 个有序文件，用**最小堆**维护每个文件当前最小值，每次取堆顶写入输出

**优化**：

- **替代选择**：初始 run 的平均长度可达 2M（M 是内存可容纳的元素数），减少 run 数量
- **I/O 缓冲**：每个文件维护一个输入缓冲区，减少磁盘随机读取
- **败者树**：比最小堆更高效的 K 路归并结构（比较次数更少）

### Q19：如何在无限数据流中维护 Top-K？对比堆和快速选择。

**参考答案**：

| 方法     | 时间       | 空间 | 适用                           |
| -------- | ---------- | ---- | ------------------------------ |
| 最小堆   | O(n log k) | O(k) | **流式数据**（数据持续到来）   |
| 快速选择 | O(n) 平均  | O(n) | **离线数据**（一次性全部可见） |

### Q20：分析 `Arrays.sort()` 在 Java 中对不同类型使用不同算法的原因。

**参考答案**：

- **基本类型（int/double/...）**：使用 **Dual-Pivot QuickSort**（双 pivot 快排），因为基本类型不需要稳定性
- **对象类型（Object[]）**：使用 **TimSort**，因为对象排序需要稳定性（相等对象保持原始顺序可能有业务含义）

双 pivot 快排用两个 pivot 将数组分成三段，减少比较次数，实践中比单 pivot 快排快约 20%。

### Q21：如何实现一个 O(n log n) 的最长递增子序列（LIS）算法？

**参考答案**：

维护一个 **tails 数组**，tails[i] 表示长度为 i+1 的递增子序列的最小末尾元素。对每个新元素，用二分搜索找到它在 tails 中的插入位置。

```python
import bisect

def length_of_lis(nums):
    tails = []
    for num in nums:
        pos = bisect.bisect_left(tails, num)
        if pos == len(tails):
            tails.append(num)  # 扩展最长子序列
        else:
            tails[pos] = num   # 更新为更小的末尾
    return len(tails)
```

**核心洞察**：tails 始终保持有序，所以可以用二分搜索，将朴素 O(n²) DP 优化到 O(n log n)。

### Q22：解释计数排序、基数排序、桶排序三者的关系和各自适用场景。

**参考答案**：

- **计数排序**：直接统计每个值出现次数。适用：值域小的整数（如年龄、分数）。
- **基数排序**：从最低位到最高位，按每一位做稳定排序（通常用计数排序）。适用：定长整数/字符串。
- **桶排序**：将数据分到若干桶中，每个桶内部排序。适用：数据均匀分布在一个范围内。

三者都是**非比较排序**，可以突破 O(n log n) 下界，但都有使用条件（数据类型、范围、分布）。

### Q23：设计一个实时排行榜系统，支持实时更新和快速查询 Top-N。

**参考答案**：

**方案**：Redis Sorted Set + 定期快照

### Q24：有一个包含 100 亿条 URL 的日志文件（约 1TB），如何找出出现次数最多的 Top-100 URL？

**参考答案**：

1. **哈希分片**：对每条 URL 计算 hash，hash % 1000 分到 1000 个小文件
2. **分别统计**：对每个小文件用 HashMap 统计频率
3. **局部 Top-K**：每个小文件维护大小为 100 的最小堆
4. **全局合并**：1000 个局部结果用 K 路归并得到全局 Top-100

**关键**：相同 URL 一定被分到同一个文件，所以分别统计不会遗漏。

### Q25：你的搜索系统需要对 1000 万条记录的某个字段进行排序返回，但内存只有 2GB，怎么设计？

**参考答案**：

1. **评估数据量**：1000 万条 × 平均 200B/条 ≈ 2GB，刚好放不下
2. **方案 A（数据库下推）**：如果数据在数据库中，利用数据库索引排序（`ORDER BY field LIMIT N`），不要全部加载到内存
3. **方案 B（外部排序）**：分块读取，块内排序，多路归并写出
4. **方案 C（索引优化）**：只将排序字段 + 主键加载到内存（约 200MB），排序后再批量查询完整记录

**追问**：如何支持实时排序？→ 预建排序索引（B+Tree 或跳表），写入时维护有序结构。
