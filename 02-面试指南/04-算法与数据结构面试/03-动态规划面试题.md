## ⭐ 基础题

### Q1：什么是动态规划？它和暴力递归、贪心算法有什么区别？

**参考答案**：

动态规划通过**存储子问题的解**避免重复计算。三者对比：

|            | 暴力递归   | 动态规划                | 贪心                         |
| ---------- | ---------- | ----------------------- | ---------------------------- |
| 子问题重叠 | 重复计算   | 记忆化/DP 表            | 不适用                       |
| 时间复杂度 | 通常指数级 | 多项式级                | 多项式级                     |
| 最优保证   | ✅         | ✅                      | ❌（局部最优不一定全局最优） |
| 适用条件   | 任何       | 最优子结构 + 重叠子问题 | 贪心选择性质                 |

### Q2：爬楼梯问题——n 级台阶，每次爬 1 或 2 级，有几种爬法？写出 DP 解法和空间优化。

**参考答案**：

```python
# DP 表
def climb(n):
    dp = [0] * (n + 1)
    dp[0], dp[1] = 1, 1
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]

# 空间优化：只需两个变量
def climb_opt(n):
    a, b = 1, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b
```

**追问**：如果每次可以爬 1/2/3 级呢？→ `dp[i] = dp[i-1] + dp[i-2] + dp[i-3]`

### Q3：0-1 背包问题的状态转移方程和空间优化是什么？

**参考答案**：

```
dp[i][w] = max(dp[i-1][w], dp[i-1][w-weight[i]] + value[i])

空间优化（逆序遍历）：
dp[w] = max(dp[w], dp[w-weight[i]] + value[i])  (w 从大到小遍历)
```

**为什么逆序？** 正序遍历时 dp[w-weight[i]] 可能已经被当前物品更新过，导致同一物品被选多次（变成完全背包）。

### Q4：零钱兑换——用最少硬币凑出金额 amount。给出状态设计和代码。

**参考答案**：

```python
def coin_change(coins, amount):
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    for i in range(1, amount + 1):
        for coin in coins:
            if coin <= i:
                dp[i] = min(dp[i], dp[i - coin] + 1)
    return dp[amount] if dp[amount] != float('inf') else -1
```

这是**完全背包**变体——每个硬币可以用无限次。

### Q5：最大子数组和的 DP 解法（Kadane 算法）是什么？

**参考答案**：

```python
def max_subarray(nums):
    max_sum = current = nums[0]
    for num in nums[1:]:
        current = max(num, current + num)  # 续上 or 从头开始
        max_sum = max(max_sum, current)
    return max_sum
```

`current` 代表"以当前元素结尾的最大子数组和"。如果加上当前元素后和比当前元素本身还小，就从当前元素重新开始。

### Q6：打家劫舍问题的 DP 思路？如果房屋排成环形怎么办？

**参考答案**：

**线性版**：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

**环形版**：首尾不能同时偷。分两种情况取最大值：

1. 偷第 1 间 → 不偷最后一间 → 在 nums[0:n-1] 上做线性版
2. 不偷第 1 间 → 在 nums[1:n] 上做线性版

---

### Q7：什么是"状态定义"？为什么说它是 DP 最难的一步？

**参考答案**：

状态定义就是决定 dp[i]（或 dp[i][j]）代表什么含义。它决定了：

- 转移方程怎么写
- 初始值怎么设
- 最终答案在哪

**常见状态定义模式**：

- `dp[i]` = 前 i 个元素的最优解（前缀型）
- `dp[i]` = 以第 i 个元素结尾的最优解（后缀型）
- `dp[i][j]` = 第 i 到 j 范围的最优解（区间型）

---

### Q8：最长递增子序列的 O(n²) DP 解法和 O(n log n) 优化思路分别是什么？

**参考答案**：

**O(n²)**：`dp[i] = max(dp[j] + 1) for j < i where nums[j] < nums[i]`

**O(n log n)**：维护 tails 数组（长度为 k 的 LIS 的最小末尾），每个新元素用二分查找定位。tails 始终有序，因此可以二分。

### Q9：编辑距离的转移方程和时间/空间复杂度？

**参考答案**：

```
dp[i][j] =
  dp[i-1][j-1]            if word1[i] == word2[j]
  1 + min(dp[i-1][j],     ← 删除
          dp[i][j-1],     ← 插入
          dp[i-1][j-1])   ← 替换
```

时间 O(mn)，空间 O(mn)，可优化到 O(min(m,n))。

**实际应用**：Git diff、拼写检查、DNA 比对。

### Q10：如何判断一个问题能用 DP 解？

**参考答案**：

两个必要条件：

1. **最优子结构**：大问题的最优解包含子问题的最优解（可以通过"剪切-粘贴"反证法验证）
2. **重叠子问题**：不同决策路径会遇到相同子问题

**判断技巧**：画出递归树，如果同一个节点出现多次就有重叠子问题。如果贪心选择导致反例就不能贪心，考虑 DP。

### Q11：完全背包和 0-1 背包在代码上的唯一区别是什么？为什么？

**参考答案**：

一维 DP 中，0-1 背包**逆序**遍历容量，完全背包**正序**遍历。

- 逆序：dp[w-weight] 还没被当前物品更新，保证每件只选一次
- 正序：dp[w-weight] 可能已包含当前物品，允许重复选

---

### Q12：最长公共子序列（LCS）和最长公共子串的区别？

**参考答案**：

- **LCS**：子序列可以不连续。状态：dp[i][j] = text1 前 i 和 text2 前 j 的 LCS 长度
- **最长公共子串**：必须连续。不匹配时 dp[i][j] = 0（不能从上方或左方继承）

### Q13：如何用 DP 解决"分割等和子集"问题？

**参考答案**：

判断数组能否分成两个子集使得和相等 → 转化为 0-1 背包：能否用若干元素凑出 sum/2。

```python
def can_partition(nums):
    total = sum(nums)
    if total % 2: return False
    target = total // 2
    dp = [False] * (target + 1)
    dp[0] = True
    for num in nums:
        for j in range(target, num - 1, -1):  # 0-1 背包逆序
            dp[j] = dp[j] or dp[j - num]
    return dp[target]
```

### Q14：股票买卖问题系列（最多 k 次交易）的通用 DP 框架？

**参考答案**：

```
状态：dp[i][k][0/1] = 第 i 天、已交易 k 次、持有(1)/未持有(0) 股票时的最大利润

转移：
dp[i][k][0] = max(dp[i-1][k][0], dp[i-1][k][1] + prices[i])  # 今天不操作 or 卖出
dp[i][k][1] = max(dp[i-1][k][1], dp[i-1][k-1][0] - prices[i])  # 不操作 or 买入
```

k=1、k=2、k=∞、含冷冻期、含手续费都是这个框架的特例。

### Q15：单词拆分（Word Break）问题的 DP 解法？

**参考答案**：

dp[i] = s[0:i] 能否被字典中的单词拆分

```python
def word_break(s, word_dict):
    dp = [False] * (len(s) + 1)
    dp[0] = True
    for i in range(1, len(s) + 1):
        for word in word_dict:
            if i >= len(word) and dp[i - len(word)] and s[i-len(word):i] == word:
                dp[i] = True
                break
    return dp[len(s)]
```

### Q16：不同路径问题——网格从左上到右下有多少条路径？有障碍物时怎么处理？

**参考答案**：

无障碍：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`，初始化第一行和第一列为 1。

有障碍：障碍物处 dp = 0，且初始化时遇到障碍后面都是 0。

## ⭐⭐⭐ 高级题

### Q17：如何用 DP 解决矩阵链乘法问题？

**参考答案**：

区间 DP：dp[i][j] = 计算矩阵 i 到 j 连乘的最少标量乘法次数。枚举分割点 k：

```
dp[i][j] = min(dp[i][k] + dp[k+1][j] + p[i-1]*p[k]*p[j])  for k in [i, j-1]
```

时间 O(n³)，空间 O(n²)。

---

### Q18：什么是状态压缩 DP？以旅行商问题（TSP）为例说明。

**参考答案**：

用二进制位表示集合状态。`dp[mask][i]` = 访问了 mask 表示的城市集合，当前在城市 i 时的最短路径。

`mask = 0b10110` 表示访问了城市 1、2、4。

时间 O(2ⁿ × n²)，只适用于 n ≤ 20。

---

### Q19：DP 中的"滚动数组"和"空间压缩"分别是什么？

**参考答案**：

- **滚动数组**：dp[i] 只依赖 dp[i-1]，用两个一维数组交替使用
- **空间压缩**：直接在一个数组上原地修改（注意遍历顺序）

滚动数组更安全（不用考虑遍历顺序），空间压缩更极致（只用一行）。

---

### Q20：如何确定一个 DP 问题的遍历顺序？

**参考答案**：

**原则**：计算 dp[i][j] 时，它依赖的状态必须已经计算完毕。

- 依赖左和上方 → 从左到右、从上到下
- 依赖右和下方 → 从右到左、从下到上
- 区间 DP → 按区间长度从小到大遍历

---

### Q21：最长回文子序列和最长回文子串的 DP 区别？

**参考答案**：

- **子序列**（可不连续）：dp[i][j] = s[i..j] 中的最长回文子序列长度。遍历顺序：从下到上。
- **子串**（必须连续）：dp[i][j] = s[i..j] 是否是回文。如果 s[i]==s[j] 且 dp[i+1][j-1]，则 dp[i][j]=true。

另一个子串高效解法是 **Manacher 算法** O(n)。

---

### Q22：如何用 DP 求解"正则表达式匹配"（. 和 \* 通配符）？

**参考答案**：

```
dp[i][j] = s[0:i] 和 p[0:j] 是否匹配

转移：
  p[j-1] 是普通字符或 '.'：dp[i][j] = dp[i-1][j-1] and (s[i-1]==p[j-1] or p[j-1]=='.')
  p[j-1] 是 '*'：
    匹配 0 次：dp[i][j] = dp[i][j-2]
    匹配 1+ 次：dp[i][j] = dp[i-1][j] and (s[i-1]==p[j-2] or p[j-2]=='.')
```

## 🎯 场景题

### Q23：设计一个文本编辑器的"撤销/重做"功能。从编辑距离的角度分析，如何高效存储编辑历史？

**参考答案**：

不存储完整文本快照，而存储**操作增量**（插入/删除/替换），本质上就是编辑距离中的操作序列。撤销 = 反向执行操作（插入→删除，删除→插入，替换→换回来）。这就是 **Command 模式**的经典应用。

---

### Q24：推荐系统需要计算两个用户的"行为序列相似度"，你会选择什么算法？

**参考答案**：

选择 **LCS（最长公共子序列）** 或 **编辑距离** 的变体：

- LCS 衡量两个行为序列的共同行为数
- 归一化相似度 = LCS 长度 / max(len(seq1), len(seq2))
- 对于长序列，可以用 Hunt-Szymanski 算法将 LCS 从 O(mn) 优化到 O((r + n) log n)（r 是匹配对数）

### Q25：一个电商平台有 100 种商品，背包容量是用户预算。如何用 DP 生成"凑单推荐"（尽量接近包邮门槛）？

**参考答案**：

转化为 0-1 背包变体：物品 = 商品，价值 = 用户偏好评分，重量 = 价格，容量 = 预算。

```python
# dp[i] = 花 i 元能获得的最大偏好评分
dp = [0] * (budget + 1)
for item in items:
    for w in range(budget, item.price - 1, -1):
        dp[w] = max(dp[w], dp[w - item.price] + item.score)
```

实际工程中需考虑：商品库存、类目多样性约束（分组背包变体）、实时计算性能（预计算+缓存）。
