## 参考答案

### Q1: 树形消息结构

**核心要点**：
- 线性列表无法支持：用户编辑之前的消息后重新生成、对同一条消息尝试不同的 AI 回复
- 树形结构：每条消息有 parent_id 字段，形成父子关系
- 用户"重新生成"时创建新分支，不覆盖旧回复
- 用户"编辑消息"时从编辑点创建新子树
- 展示时沿当前活跃路径（从根到叶）渲染消息列表

### Q5: 数据库 Schema 设计

```sql
CREATE TABLE messages (
    id UUID PRIMARY KEY,
    conversation_id UUID NOT NULL,
    parent_id UUID REFERENCES messages(id),  -- 树形关系
    role VARCHAR(20),  -- user/assistant/system/tool
    content TEXT,
    model VARCHAR(100),
    token_count_prompt INTEGER,
    token_count_completion INTEGER,
    metadata JSONB DEFAULT '{}',
    created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_messages_parent ON messages(parent_id);
```
