## 参考答案

### Q1: 企业级 AI 编码助手架构

**5 层架构设计**：

1. **表现层**：Next.js + Chat UI + Code Viewer
2. **API 层**：认证 + 限流 + API 路由
3. **Agent 层**：ReAct 循环 + RAG + Prompt 管理
4. **工具层**：MCP Server（GitHub、代码搜索、文件系统、终端）
5. **模型层**：LiteLLM 网关 → vLLM（自托管 70B） + GPT-4o（Fallback）
6. **基础设施**：K8s + PostgreSQL + Redis + Qdrant + LangFuse + Prometheus

**关键设计决策**：
- 自托管推理保证代码不出网
- LiteLLM 统一多模型管理和 Fallback
- 模型级联（8B 分类 + 70B 生成）降低成本
- MCP 标准化工具集成

### Q7: GPU 成本优化

**系统化优化方案**：
1. **模型级联**（节省 40-70%）：小模型处理简单请求
2. **Prompt Caching**（节省 50-90%）：缓存共享系统提示词
3. **量化**（节省 50%）：FP8/AWQ 减少 GPU 需求
4. **自动扩缩容**（节省 20-30%）：低峰缩容
5. **批处理 API**（节省 50%）：非实时任务用 Batch API
6. **Prefix Caching**（节省 30%）：vLLM/SGLang 开启前缀缓存
