## 参考答案

### Q1: SSE vs WebSocket

| 维度 | SSE | WebSocket |
|------|-----|-----------|
| 方向 | 单向（服务端→客户端） | 双向 |
| 协议 | HTTP（标准） | 独立协议（ws://） |
| 重连 | 浏览器原生自动重连 | 需手动实现 |
| 代理兼容性 | 优秀（标准 HTTP） | 需要代理支持 Upgrade |
| LLM 适用性 | ✅ 完美匹配 | ❌ 过于复杂 |

LLM 流式输出首选 SSE 原因：LLM 输出是单向的，SSE 简单可靠且 HTTP 原生支持。

### Q10: 流式卡顿排查

**排查步骤**：
1. **ALB 层**：检查 idle timeout（默认 60s），增加到 300s
2. **Nginx 层**：检查 `proxy_buffering`（必须 off）、`proxy_cache`（必须 off）
3. **Backend 层**：检查 `X-Accel-Buffering: no` Header 是否设置
4. **逐层验证**：直连 Backend 测试 → 加 Nginx → 加 ALB，定位哪层引入缓冲
