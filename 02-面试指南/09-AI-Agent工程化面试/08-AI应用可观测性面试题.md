## 参考答案

### Q10: TTFT 飙升排查

**排查步骤**：
1. **检查 GPU 指标**：KV Cache 使用率是否接近 100%？→ 请求排队
2. **检查队列深度**：pending_requests 是否异常增加？→ 流量突增
3. **检查模型提供商**：如果用云端 API，提供商是否有延迟问题？
4. **检查 Prefill 长度**：最近是否有 Prompt 变长的改动？
5. **检查资源竞争**：GPU 利用率是否 100%？其他 Pod 是否抢占资源？
6. **快速恢复**：扩容推理实例 / 启用 Fallback 到云端 / 限流保护
