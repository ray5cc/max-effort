## 参考答案

### Q5: 模型级联

**核心思路**：简单问题用便宜的小模型，复杂问题用高级大模型。

1. 先用小模型（如 GPT-4o-mini）对请求做复杂度分类（SIMPLE/COMPLEX）
2. SIMPLE 请求由小模型直接回答（成本 1/10）
3. COMPLEX 请求转发给大模型（GPT-4o/Claude）
4. 整体可节省 40-70% 成本，同时保证复杂问题的质量

### Q10: 多团队 AI 网关设计

**设计要点**：
1. **Virtual Keys**：每个团队独立的 API Key，隔离配额
2. **Token 计量**：每次调用记录 prompt_tokens / completion_tokens / cost
3. **预算控制**：日/月预算上限，超出自动拒绝或降级
4. **成本看板**：Grafana 仪表盘按团队/模型/功能维度展示
5. **告警规则**：日消耗超均值 3 倍自动告警
