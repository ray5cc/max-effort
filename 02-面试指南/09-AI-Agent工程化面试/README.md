## 高频考点速查

### 推理与部署

| 考点 | 核心要点 |
|------|---------|
| PagedAttention | OS 虚拟内存分页 → KV Cache 按 Block 管理 → 内存利用率 95%+ |
| Continuous Batching | 请求级调度 → 吞吐量提升 10-20x |
| 推理引擎选型 | vLLM(通用) / SGLang(多轮) / TRT-LLM(极致) |

### Agent 架构

| 考点 | 核心要点 |
|------|---------|
| ReAct 模式 | Think → Act → Observe 循环 |
| MCP 协议 | N×M → N+M 集成 / Resources+Tools+Prompts |
| 上下文管理 | 渐进加载 / 记忆层级 / Token 预算 |

### 工程实践

| 考点 | 核心要点 |
|------|---------|
| 混合检索 | 向量 + BM25 → Recall 提升 15-30% |
| SSE 流式输出 | proxy_buffering off / 缓冲区行解析 |
| 成本优化 | 模型级联 + Caching + 量化 |
| 安全防御 | 沙箱隔离 + Prompt 注入防御 + HITL |

## 说明

本面试指南专注于 AI Agent 应用的**工程化实践**。面试中建议结合真实项目经验回答，展示对 vLLM、LiteLLM、MCP 等开源项目的理解和使用经验。
