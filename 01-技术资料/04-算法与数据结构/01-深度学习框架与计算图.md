## 1. TensorFlow 简介与历史

### 起源

TensorFlow 由 **Google Brain** 团队开发，于 **2015 年 11 月** 以 Apache 2.0 开源协议对外发布。其前身是 Google 内部系统 **DistBelief**（2011 年），用于大规模神经网络训练。

```
时间线：

2011  DistBelief        Google 内部深度学习系统（第一代）
  │
2015  TensorFlow 0.x   开源发布，静态计算图，Session 执行
  │
2017  TensorFlow 1.x   生态成熟，Keras 集成，TFLite 发布
  │
2019  TensorFlow 2.0   Eager Execution 默认开启，API 大幅简化
  │
2021  TensorFlow 2.5+  DTensor、TF-DF、Keras 独立化进程
  │
2023  TensorFlow 2.13+ 模型签名改进，JAX 与 TF 协同生态
```

### 命名含义

**Tensor**（张量）：多维数据数组，是框架中数据流动的基本单元。  
**Flow**（流动）：数据（张量）沿计算图流动并完成变换。

## 3. 核心概念

### 3.1 张量（Tensor）

张量是 TensorFlow 中的基本数据结构，本质上是 N 维数组。

```python
import tensorflow as tf

# 标量（rank 0）
scalar = tf.constant(3.14)
print(scalar.shape)  # ()

# 向量（rank 1）
vector = tf.constant([1.0, 2.0, 3.0])
print(vector.shape)  # (3,)

# 矩阵（rank 2）
matrix = tf.constant([[1, 2], [3, 4]])
print(matrix.shape)  # (2, 2)

# 3D 张量（rank 3）—— 典型图像批次 [batch, height, width, channels]
image_batch = tf.zeros([32, 224, 224, 3])
print(image_batch.shape)  # (32, 224, 224, 3)

# 张量属性
print(matrix.dtype)   # tf.int32
print(matrix.device)  # 所在设备
```

#### 张量操作

```python
a = tf.constant([[1.0, 2.0], [3.0, 4.0]])
b = tf.constant([[5.0, 6.0], [7.0, 8.0]])

# 元素级运算
c = a + b                   # 广播加法
d = tf.multiply(a, b)       # 元素级乘法
e = tf.matmul(a, b)         # 矩阵乘法

# 形状变换
reshaped = tf.reshape(a, [4])     # [1,2,3,4]
transposed = tf.transpose(a)       # [[1,3],[2,4]]

# 类型转换
f = tf.cast(a, dtype=tf.float16)
```

### 3.2 计算图（Computation Graph）

计算图是 TensorFlow 的核心抽象，将计算表示为一个**有向无环图（DAG）**：

- **节点（Node）**：表示运算（Operations / Ops）
- **边（Edge）**：表示张量的流动

```
输入张量 x ──→ [MatMul Op] ──→ [BiasAdd Op] ──→ [ReLU Op] ──→ 输出张量 y
               权重矩阵 W ↗        偏置 b ↗
```

#### 静态图 vs 动态图

| 特性 | 静态图（Define-and-Run） | 动态图（Define-by-Run） |
|------|-------------------------|------------------------|
| 图构建 | 执行前一次性构建 | 逐行即时构建 |
| 调试 | 困难，需 Session 运行 | 直接 Python 调试 |
| 性能 | 高（可优化整图） | 相对较低 |
| 灵活性 | 低（固定结构） | 高（动态控制流） |
| TF 版本 | TF 1.x 默认 | TF 2.x 默认（Eager） |
| 代表框架 | TF 1.x | PyTorch、TF 2.x Eager |

### 3.3 Eager Execution（即时执行）

TF 2.x 默认开启 Eager Execution，操作立即返回具体值：

```python
# TF 1.x 风格（静态图）
with tf.compat.v1.Session() as sess:
    x = tf.compat.v1.placeholder(tf.float32)
    y = x * 2
    result = sess.run(y, feed_dict={x: 3.0})  # 必须通过 Session 运行

# TF 2.x 风格（Eager，默认）
x = tf.constant(3.0)
y = x * 2
print(y.numpy())  # 6.0 — 立即得到结果
```

#### @tf.function 装饰器

使用 `@tf.function` 可将 Python 函数编译为计算图，兼顾灵活性与性能：

```python
@tf.function
def train_step(x, y):
    with tf.GradientTape() as tape:
        predictions = model(x, training=True)
        loss = loss_fn(y, predictions)
    gradients = tape.gradient(loss, model.trainable_variables)
    optimizer.apply_gradients(zip(gradients, model.trainable_variables))
    return loss

# 首次调用时追踪（tracing）并编译为图
# 后续调用直接执行图，性能更高
loss = train_step(x_batch, y_batch)
```

### 3.4 变量（Variable）

`tf.Variable` 是可变的张量，在训练中用于存储模型参数：

```python
# 创建变量
w = tf.Variable(tf.random.normal([784, 128]), name="weights")
b = tf.Variable(tf.zeros([128]), name="biases")

# 变量赋值
w.assign(new_value)
w.assign_add(delta)

# 在自动微分中，变量梯度被自动跟踪
with tf.GradientTape() as tape:
    y = tf.matmul(x, w) + b
    loss = compute_loss(y, labels)

grads = tape.gradient(loss, [w, b])
```

### 3.5 自动微分（Automatic Differentiation）

```python
x = tf.Variable(3.0)

with tf.GradientTape() as tape:
    y = x ** 2 + 2 * x + 1   # y = x² + 2x + 1

dy_dx = tape.gradient(y, x)
print(dy_dx.numpy())  # 8.0  (dy/dx = 2x+2, x=3 → 8)

# 高阶导数
with tf.GradientTape() as tape2:
    with tf.GradientTape() as tape1:
        y = x ** 3
    dy_dx = tape1.gradient(y, x)
d2y_dx2 = tape2.gradient(dy_dx, x)
print(d2y_dx2.numpy())  # 18.0  (d²y/dx² = 6x, x=3 → 18)
```

## 4. TF 1.x vs TF 2.x

### 主要差异对比

| 维度 | TF 1.x | TF 2.x |
|------|--------|--------|
| 执行模式 | 静态图（Session） | Eager Execution 默认 |
| API 风格 | 低级，冗余 | 简洁，Keras 一等公民 |
| 调试体验 | 困难 | 与 Python 调试一致 |
| 变量管理 | 手动 `tf.get_variable` | 自动 `tf.Variable` |
| 模型保存 | checkpoint / SavedModel | SavedModel（强化） |
| 分布式训练 | 复杂配置 | `tf.distribute.Strategy` |
| 控制流 | `tf.cond`, `tf.while_loop` | Python `if/for` + `@tf.function` |
| 图优化 | 手动 XLA | 自动（`@tf.function` + XLA） |

### 迁移示例

```python
# TF 1.x
import tensorflow as tf

# 定义图
x = tf.placeholder(tf.float32, [None, 784])
W = tf.Variable(tf.zeros([784, 10]))
b = tf.Variable(tf.zeros([10]))
y = tf.matmul(x, W) + b
loss = tf.reduce_mean(tf.nn.softmax_cross_entropy_with_logits(labels=y_, logits=y))
train_step = tf.train.GradientDescentOptimizer(0.5).minimize(loss)

# 执行
with tf.Session() as sess:
    sess.run(tf.global_variables_initializer())
    for _ in range(1000):
        sess.run(train_step, feed_dict={x: batch_xs, y_: batch_ys})

# ─────────────────────────────────────────────

# TF 2.x 等价代码
import tensorflow as tf

model = tf.keras.Sequential([
    tf.keras.layers.Dense(10, activation='softmax', input_shape=(784,))
])

model.compile(
    optimizer=tf.keras.optimizers.SGD(0.5),
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

model.fit(x_train, y_train, epochs=10, batch_size=32)
```

## 5. 与 PyTorch 的对比

### 综合对比

| 维度 | TensorFlow 2.x | PyTorch |
|------|---------------|---------|
| **执行模式** | Eager + Graph（`@tf.function`） | 默认 Eager，`torch.compile` 可图化 |
| **生态系统** | 完整生产链路（Serving/Lite/JS） | 研究主导，torchserve 相对新 |
| **移动端部署** | TFLite（成熟） | ExecuTorch（较新） |
| **分布式训练** | `tf.distribute.Strategy` | `torch.distributed` / DDP |
| **可视化** | TensorBoard（官方集成） | TensorBoard（通过 SummaryWriter） |
| **学习曲线** | 中等（Keras 简化了入门） | 较低（Pythonic 风格） |
| **研究使用率** | 较低（学术界多选 PyTorch） | 较高 |
| **工业使用率** | 较高（Google 生态、成熟工具链） | 增长中 |
| **TPU 支持** | 原生支持 | 通过 `torch_xla` |
| **模型格式** | SavedModel / TFLite | PT / ONNX |

### 静态图 vs 动态图的生产优势

TensorFlow 通过 `@tf.function` 在保持动态图灵活性的同时，编译为静态图用于部署：

```
开发阶段（Eager Mode）：
  Python 代码 → 立即执行 → 方便调试

部署阶段（Graph Mode via @tf.function）：
  Python 代码 → 追踪（Tracing）→ 计算图 → XLA 优化 → 高效执行

优势：
  1. 图级别优化（算子融合、内存复用）
  2. 跨平台部署（SavedModel 可在 C++/Java/Go 中加载）
  3. TF Serving 直接加载 SavedModel，无需 Python 运行时
  4. TFLite 将图转换为扁平化 FlatBuffers 格式
```

## 2. 计算图与执行引擎

### 2.1 计算图（DAG）结构

```
示例：y = ReLU(x @ W + b)

     x (Placeholder)    W (Variable)
          │                  │
          └──────┬───────────┘
                 ▼
            [MatMul Op]
                 │
                 ▼
     b ──→ [BiasAdd Op]
                 │
                 ▼
            [ReLU Op]
                 │
                 ▼
              y (Output)
```

每个节点（Op）包含：
- **名称（name）**：如 `"MatMul:0"`
- **类型（type）**：如 `MatMul`、`BiasAdd`、`Relu`
- **属性（attrs）**：如数据类型、维度
- **输入边列表**：指向前驱节点输出张量

### 2.2 图优化流程

```python
@tf.function
def my_fn(x):
    return tf.nn.relu(tf.matmul(x, w) + b)

# 调用时执行以下步骤：
# 1. Tracing（追踪）：将 Python 函数转换为 FuncGraph
# 2. Grappler 优化：
#    - 常量折叠（Constant Folding）
#    - 公共子表达式消除（CSE）
#    - 算子融合（Op Fusion）：MatMul + BiasAdd + Relu → FusedMatMul
# 3. （可选）XLA 编译：HLO 生成 → 硬件原生代码
# 4. 执行：调度到目标设备
```

### 2.3 设备放置（Device Placement）

```python
# 自动设备放置
with tf.device('/GPU:0'):
    a = tf.constant([[1.0, 2.0]])

with tf.device('/CPU:0'):
    b = tf.constant([[3.0], [4.0]])

# 跨设备操作（自动插入数据复制节点）
c = tf.matmul(a, b)

# 查看张量所在设备
print(c.device)  # /job:localhost/replica:0/task:0/device:GPU:0
```

### 2.4 Session 与 Eager 的对比（内部机制）

```
TF 1.x Session 模式：
  Python 侧          C++ 侧
  构建图 ──Proto──→  GraphDef
  sess.run() ─────→ Executor.Run()
                       │── 设备调度
                       │── Kernel 执行
                       └── 结果返回 Python

TF 2.x Eager 模式：
  Python 侧          C++ 侧
  tf.constant() ──→  EagerTensor（立即分配）
  tf.matmul() ────→  EagerExecute()（立即计算）
                       └── 结果立即返回

  @tf.function 追踪后：
  Python 函数 ──追踪──→ ConcreteFunction
              ──执行──→ FunctionLibraryRuntime
```

## 3. 核心 API 模块

### 3.1 tf.keras — 高级神经网络 API

Keras 提供三种模型构建方式：

#### Sequential API（顺序模型）

```python
model = tf.keras.Sequential([
    tf.keras.layers.Input(shape=(784,)),
    tf.keras.layers.Dense(256, activation='relu'),
    tf.keras.layers.Dropout(0.3),
    tf.keras.layers.Dense(128, activation='relu'),
    tf.keras.layers.Dense(10, activation='softmax')
])

model.compile(
    optimizer=tf.keras.optimizers.Adam(1e-3),
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)
model.summary()
```

#### Functional API（函数式模型）

```python
# 支持多输入/多输出、共享层、非线性拓扑
inputs = tf.keras.Input(shape=(784,))
x = tf.keras.layers.Dense(256, activation='relu')(inputs)
x = tf.keras.layers.Dropout(0.3)(x)
x = tf.keras.layers.Dense(128, activation='relu')(x)
outputs = tf.keras.layers.Dense(10, activation='softmax')(x)

model = tf.keras.Model(inputs=inputs, outputs=outputs)
```

#### Subclassing API（子类化模型）

```python
class MyModel(tf.keras.Model):
    def __init__(self):
        super().__init__()
        self.dense1 = tf.keras.layers.Dense(256, activation='relu')
        self.dropout = tf.keras.layers.Dropout(0.3)
        self.dense2 = tf.keras.layers.Dense(10, activation='softmax')

    def call(self, inputs, training=False):
        x = self.dense1(inputs)
        x = self.dropout(x, training=training)
        return self.dense2(x)

model = MyModel()
```

## 8. XLA 编译器

XLA（Accelerated Linear Algebra）是 TensorFlow 的领域专用编译器，通过图级别优化提升执行性能。

### 编译流程

```
TF 计算图（tf.Graph）
        │
  HLO（High-Level Operations）生成
  ├── 算子规范化
  └── 内联展开
        │
  HLO 优化 Pass
  ├── 算子融合（Fusion）：将多个小算子合并成一个 Kernel
  ├── 缓冲区分析（Buffer Assignment）：最小化内存分配
  ├── 循环展开（Loop Unrolling）
  └── 常量传播（Constant Propagation）
        │
  LLO（Low-Level Operations）代码生成
  ├── CPU → LLVM IR → 机器码
  ├── GPU → PTX → CUBIN
  └── TPU → TPU 固件指令
```

### 启用 XLA

```python
# 方式 1：全局启用（所有 @tf.function）
tf.config.optimizer.set_jit(True)

# 方式 2：单函数启用
@tf.function(jit_compile=True)
def compute(x, y):
    return tf.reduce_sum(x * y)

# 方式 3：环境变量
# TF_XLA_FLAGS=--tf_xla_auto_jit=2

# XLA 主要优化收益：
# - 算子融合减少内存带宽瓶颈
# - 减少 Kernel launch 开销
# - 消除中间结果的内存分配
# 典型加速比：1.2x - 3x（依模型结构而异）
```

### XLA vs cuDNN 的关系

```
cuDNN：NVIDIA 提供的手工优化 Kernel 库
  - 针对特定算子（Conv、GEMM、RNN）高度优化
  - 适合标准模型结构

XLA：通用编译器优化
  - 对自定义计算图更灵活
  - 通过融合减少访存开销
  - 在 TPU 上尤其重要（TPU 没有 cuDNN）

TF 的选择策略：
  标准层（Conv2D、Dense）→ 优先用 cuDNN
  自定义/融合场景 → XLA 更有优势
```

### 1.2 自定义训练循环（Custom Training Loop）

适用于需要精细控制训练过程的场景（GAN、元学习、强化学习等）：

```python
import tensorflow as tf

model = build_model(784, 10)
optimizer = tf.keras.optimizers.Adam(1e-3)
loss_fn = tf.keras.losses.SparseCategoricalCrossentropy()

# 指标跟踪
train_loss = tf.keras.metrics.Mean(name='train_loss')
train_accuracy = tf.keras.metrics.SparseCategoricalAccuracy(name='train_accuracy')
val_loss = tf.keras.metrics.Mean(name='val_loss')
val_accuracy = tf.keras.metrics.SparseCategoricalAccuracy(name='val_accuracy')

@tf.function  # 编译为图以提升性能
def train_step(x, y):
    with tf.GradientTape() as tape:
        predictions = model(x, training=True)
        loss = loss_fn(y, predictions)
        # 加入 L2 正则化损失
        loss += sum(model.losses)
    gradients = tape.gradient(loss, model.trainable_variables)
    # 梯度裁剪（防止梯度爆炸）
    gradients, _ = tf.clip_by_global_norm(gradients, clip_norm=1.0)
    optimizer.apply_gradients(zip(gradients, model.trainable_variables))
    train_loss.update_state(loss)
    train_accuracy.update_state(y, predictions)

@tf.function
def val_step(x, y):
    predictions = model(x, training=False)
    loss = loss_fn(y, predictions)
    val_loss.update_state(loss)
    val_accuracy.update_state(y, predictions)

# 训练循环
for epoch in range(50):
    train_loss.reset_state()
    train_accuracy.reset_state()
    val_loss.reset_state()
    val_accuracy.reset_state()

    for x_batch, y_batch in train_dataset:
        train_step(x_batch, y_batch)

    for x_val, y_val in val_dataset:
        val_step(x_val, y_val)

    print(f"Epoch {epoch+1}: "
          f"Loss={train_loss.result():.4f}, "
          f"Acc={train_accuracy.result():.4f}, "
          f"Val Loss={val_loss.result():.4f}, "
          f"Val Acc={val_accuracy.result():.4f}")
```

## 2. tf.data 流水线最佳实践

### 2.1 性能优化原则

```
原则：让 CPU 预处理与 GPU 计算并行，消除 I/O 等待

[非优化流水线]
读磁盘 → 处理 → 训练 → 读磁盘 → 处理 → 训练
  (每次训练必须等待前序 I/O 完成)

[优化后流水线]
读磁盘 → 处理 → ┐
读磁盘 → 处理 → ┤ prefetch → 训练
读磁盘 → 处理 → ┘           训练
  (CPU 预处理与 GPU 训练并行执行)
```

### 2.2 最佳实践代码

```python
import tensorflow as tf
AUTOTUNE = tf.data.AUTOTUNE

def build_train_pipeline(file_pattern, batch_size=32):
    # 1. 从 TFRecord 文件创建数据集
    files = tf.data.Dataset.list_files(file_pattern, shuffle=True)
    dataset = files.interleave(
        tf.data.TFRecordDataset,
        cycle_length=8,             # 并行读取 8 个文件
        num_parallel_calls=AUTOTUNE
    )

    # 2. 解析 TFRecord
    def parse_example(serialized):
        features = tf.io.parse_single_example(serialized, {
            'image': tf.io.FixedLenFeature([], tf.string),
            'label': tf.io.FixedLenFeature([], tf.int64),
        })
        image = tf.io.decode_jpeg(features['image'], channels=3)
        image = tf.image.resize(image, [224, 224])
        return image, features['label']

    # 3. 数据增强
    def augment(image, label):
        image = tf.image.random_flip_left_right(image)
        image = tf.image.random_brightness(image, 0.2)
        image = tf.image.random_contrast(image, 0.8, 1.2)
        image = tf.cast(image, tf.float32) / 255.0
        return image, label

    dataset = (dataset
        .map(parse_example, num_parallel_calls=AUTOTUNE)   # 并行解析
        .cache()                    # 缓存解析后的数据到内存（适合中小数据集）
        .shuffle(buffer_size=1000)  # 随机打乱
        .batch(batch_size, drop_remainder=True)             # 批次化
        .map(augment, num_parallel_calls=AUTOTUNE)          # 批次级增强
        .prefetch(AUTOTUNE)         # 预取下一批次，与 GPU 计算并行
    )
    return dataset

# 注意：cache() 放置位置影响性能
# .cache() 在 .map(expensive_decode) 之后：解码结果缓存
# .cache() 在 .batch() 之前：批次前缓存，灵活性更高
```

### 3.4 自定义分布式训练循环

```python
strategy = tf.distribute.MirroredStrategy()

with strategy.scope():
    model = build_model()
    optimizer = tf.keras.optimizers.Adam(1e-3)
    loss_fn = tf.keras.losses.SparseCategoricalCrossentropy(
        reduction=tf.keras.losses.Reduction.NONE  # 不自动归约
    )

def compute_loss(labels, predictions, global_batch_size):
    per_example_loss = loss_fn(labels, predictions)
    # 手动做全局平均（而非 per-replica 平均）
    return tf.nn.compute_average_loss(
        per_example_loss, global_batch_size=global_batch_size
    )

@tf.function
def distributed_train_step(dist_inputs):
    def step_fn(inputs):
        x, y = inputs
        with tf.GradientTape() as tape:
            predictions = model(x, training=True)
            loss = compute_loss(y, predictions, GLOBAL_BATCH_SIZE)
        gradients = tape.gradient(loss, model.trainable_variables)
        optimizer.apply_gradients(zip(gradients, model.trainable_variables))
        return loss

    per_replica_losses = strategy.run(step_fn, args=(dist_inputs,))
    return strategy.reduce(tf.distribute.ReduceOp.SUM,
                           per_replica_losses, axis=None)
```

### 4.2 模型剪枝（Pruning）

```python
import tensorflow_model_optimization as tfmot

# 幅度剪枝（Magnitude Pruning）
pruning_schedule = tfmot.sparsity.keras.PolynomialDecay(
    initial_sparsity=0.0,
    final_sparsity=0.5,        # 目标 50% 稀疏度

    end_step=1000
)

model_for_pruning = tfmot.sparsity.keras.prune_low_magnitude(
    model,
    pruning_schedule=pruning_schedule
)

model_for_pruning.compile(optimizer='adam', loss='sparse_categorical_crossentropy')
```

### 4.3 知识蒸馏（Knowledge Distillation）

```python
class DistillationModel(tf.keras.Model):
    def __init__(self, student, teacher):
        super().__init__()
        self.student = student
        self.teacher = teacher

    def compile(self, optimizer, metrics, student_loss_fn,
                distillation_loss_fn, alpha=0.1, temperature=3):
        super().compile(optimizer=optimizer, metrics=metrics)
        self.student_loss_fn = student_loss_fn
        self.distillation_loss_fn = distillation_loss_fn
        self.alpha = alpha
        self.temperature = temperature

    def train_step(self, data):
        x, y = data
        teacher_predictions = self.teacher(x, training=False)

        with tf.GradientTape() as tape:
            student_predictions = self.student(x, training=True)
            # 硬标签损失
            student_loss = self.student_loss_fn(y, student_predictions)
            # 软标签损失（蒸馏损失）
            distillation_loss = self.distillation_loss_fn(
                tf.nn.softmax(teacher_predictions / self.temperature, axis=1),
                tf.nn.softmax(student_predictions / self.temperature, axis=1),
            ) * self.temperature ** 2
            # 组合损失
            loss = self.alpha * student_loss + (1 - self.alpha) * distillation_loss

        gradients = tape.gradient(loss, self.student.trainable_variables)
        self.optimizer.apply_gradients(
            zip(gradients, self.student.trainable_variables)
        )
        return {"student_loss": student_loss, "distillation_loss": distillation_loss}
```

| 问题现象 | 可能原因 | 解决方案 |

## PyTorch 深度解析

> 以下内容为 PyTorch 框架的独立深度解析，与前述 TensorFlow 内容形成对照。PyTorch 在学术界和 LLM 领域已成为事实标准（2024-2026 年），理解其内部机制对 AI 工程师至关重要。

### P1. PyTorch 架构概览

```
┌─────────────────────────────────────────────────┐
│                 Python 接口层                     │
│  torch.nn │ torch.optim │ torch.utils.data       │
├─────────────────────────────────────────────────┤
│              Autograd 引擎                        │
│  动态计算图 │ 反向传播 │ 梯度累积                   │
├─────────────────────────────────────────────────┤
│            C++ / ATen (A Tensor Library)          │
│  张量运算 │ 内存管理 │ CUDA 内核调度                │
├─────────────────────────────────────────────────┤
│            Dispatch 机制                          │
│  CPU │ CUDA │ MPS │ XLA │ 自定义后端               │
├─────────────────────────────────────────────────┤
│            硬件层                                 │
│  CPU (OpenMP) │ NVIDIA GPU (cuDNN/cuBLAS)         │
│  Apple Silicon (MPS) │ TPU (torch_xla)            │
└─────────────────────────────────────────────────┘
```

**核心设计哲学**：
- **Pythonic 优先**：API 设计遵循 Python 习惯，`tensor.shape` 而非 `tf.shape(tensor)`
- **动态图默认**：每次前向传播动态构建计算图，天然支持条件分支和循环
- **研究友好**：可以用 `pdb` 在任意位置打断点调试

### P2. Autograd：动态自动微分

**类比**：想象你在解数学题，每一步计算你都在草稿纸上记录。做完后，从末尾开始反向推导每个变量的导数——这就是 Autograd 的工作方式。

```python
import torch

# 创建需要梯度的张量
x = torch.tensor(2.0, requires_grad=True)
w = torch.tensor(3.0, requires_grad=True)
b = torch.tensor(1.0, requires_grad=True)

# 前向计算（动态构建计算图）
y = w * x + b        # y = 3*2 + 1 = 7
loss = y ** 2         # loss = 49

# 反向传播（沿图反向计算梯度）
loss.backward()

print(x.grad)   # dloss/dx = 2*y * w = 2*7*3 = 42
print(w.grad)   # dloss/dw = 2*y * x = 2*7*2 = 28
print(b.grad)   # dloss/db = 2*y * 1 = 14
```

**Autograd 内部机制**：

```
前向传播时，每个操作创建一个 Function 节点：

  x ──→ [MulBackward0] ──→ [AddBackward0] ──→ [PowBackward0]
  w ──↗                    b ──↗                    │
                                                    loss

每个 Function 记录：
  - grad_fn：反向传播函数
  - next_functions：前驱节点列表
  - saved_tensors：反向传播需要的中间值

loss.backward() 时：
  1. 从 loss 的 grad_fn 开始
  2. 拓扑排序（后序遍历）
  3. 对每个节点调用 backward() 计算局部梯度
  4. 链式法则将梯度传播到叶子节点
```

### P3. torch.nn 与训练循环

```python
import torch
import torch.nn as nn
import torch.optim as optim

# 定义模型
class TextClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim, num_classes):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.encoder = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(d_model=embed_dim, nhead=8, batch_first=True),
            num_layers=6
        )
        self.classifier = nn.Linear(embed_dim, num_classes)

    def forward(self, x):
        x = self.embedding(x)        # (batch, seq_len) → (batch, seq_len, embed_dim)
        x = self.encoder(x)          # Transformer 编码
        x = x.mean(dim=1)            # 平均池化
        return self.classifier(x)    # 分类

# 完整训练循环
model = TextClassifier(vocab_size=30000, embed_dim=512, num_classes=10)
optimizer = optim.AdamW(model.parameters(), lr=1e-4, weight_decay=0.01)
scheduler = optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=100)
criterion = nn.CrossEntropyLoss()

model.train()
for epoch in range(100):
    for batch_x, batch_y in train_loader:
        optimizer.zero_grad()               # 清零梯度
        logits = model(batch_x)             # 前向传播
        loss = criterion(logits, batch_y)   # 计算损失
        loss.backward()                      # 反向传播
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)  # 梯度裁剪
        optimizer.step()                     # 更新参数
    scheduler.step()                         # 更新学习率
```

### P4. torch.compile（PyTorch 2.0+）

PyTorch 2.0 引入 `torch.compile`，将动态图编译为优化的静态图，**类似于 TF 的 @tf.function**：

```python
# 一行代码获得 2-3x 加速
model = torch.compile(model)  # 默认使用 TorchInductor 后端

# 编译过程：
# 1. TorchDynamo：通过 Python 字节码分析捕获计算图
# 2. AOTAutograd：自动生成反向传播图
# 3. TorchInductor：生成优化的 Triton/C++ 内核

# 编译模式选择
model = torch.compile(model, mode="reduce-overhead")  # 最小化编译开销
model = torch.compile(model, mode="max-autotune")     # 最大性能（编译时间长）
```

**torch.compile vs tf.function**：

| 特性 | torch.compile | @tf.function |
|------|--------------|-------------|
| **图捕获方式** | 字节码分析（TorchDynamo） | Python 追踪 |
| **动态形状** | 原生支持（guard 机制） | 需要 input_signature |
| **调试** | 可随时关闭回退到 eager | 图模式下调试困难 |
| **后端** | TorchInductor / Triton | XLA / TF Graph Executor |

### P5. 分布式训练（DDP / FSDP）

```python
# DistributedDataParallel (DDP) - 数据并行
import torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP

dist.init_process_group("nccl")
model = DDP(model.to(rank), device_ids=[rank])

model = FSDP(
    model,
    sharding_strategy=ShardingStrategy.FULL_SHARD,  # 类似 ZeRO-3
    mixed_precision=MixedPrecision(
        param_dtype=torch.bfloat16,

# 1. 模型参数、梯度、优化器状态按 GPU 分片
# 2. 前向传播前 All-Gather 收集参数
```
