## 1. 图算法基础

### 1.1 为什么需要图算法

现实世界中大量问题可以建模为图：社交网络中的好友关系、地图导航中的最短路径、课程的先修依赖、网页之间的超链接（PageRank）。掌握图算法，就掌握了解决这类问题的通用武器。

### 1.2 图的基本要素

| 概念 | 说明 | 示例 |
|------|------|------|
| 顶点 (Vertex) | 图中的节点 | 城市、用户、课程 |
| 边 (Edge) | 顶点之间的连接 | 公路、好友关系、先修关系 |
| 有向 vs 无向 | 边是否有方向 | 微博关注(有向) vs 微信好友(无向) |
| 加权 vs 无权 | 边是否有权重 | 距离/费用(加权) vs 是否连通(无权) |
| 度 (Degree) | 连接到顶点的边数 | 无向图度 / 有向图入度+出度 |
| 连通分量 | 互相可达的顶点集合 | 社交网络中的朋友圈 |
| DAG | 有向无环图 | 课程依赖、任务调度 |

### 1.3 图的存储回顾

```python
# 邻接表（最常用）
graph = {
    'A': [('B', 1), ('C', 4)],

    'C': [('D', 1)],
```

## 2. BFS 与 DFS 深度解析

### 2.1 BFS：层层扩展

> **类比**：BFS 就像往平静的水面扔一颗石子——水波从中心同时向所有方向一圈一圈扩散。每一圈（层）距离起点的步数相同。

**特点**：
- 使用**队列**（FIFO）
- 保证找到**最短路径**（无权图）
- 空间复杂度取决于图的**宽度**

```python
from collections import deque

def bfs(graph, start):
    """标准 BFS 模板"""
    visited = {start}
    queue = deque([start])
    order = []
    
    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    return order

def bfs_shortest_path(graph, start, end):
    """BFS 求无权图最短路径"""
    visited = {start}
    queue = deque([(start, [start])])
    
    while queue:
        node, path = queue.popleft()
        if node == end:
            return path
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, path + [neighbor]))
    return []  # 不可达
```

### 2.2 DFS：一路走到底

> **类比**：DFS 就像走迷宫——沿着一条路一直走到死胡同，然后回头（回溯）尝试下一条路，直到找到出口。

**特点**：
- 使用**栈**（递归调用栈 / 显式栈）
- 适合探索**所有可能路径**
- 空间复杂度取决于图的**深度**

```python
def dfs_recursive(graph, start, visited=None):
    """递归 DFS"""
    if visited is None:
        visited = set()
    visited.add(start)
    order = [start]
    for neighbor in graph[start]:
        if neighbor not in visited:
            order.extend(dfs_recursive(graph, neighbor, visited))
    return order

def dfs_iterative(graph, start):
    """迭代 DFS（用栈）"""
    visited = set()
    stack = [start]
    order = []
    
    while stack:
        node = stack.pop()
        if node in visited:
            continue
        visited.add(node)
        order.append(node)
        # 逆序入栈，保证左邻居先被访问
        for neighbor in reversed(graph[node]):
            if neighbor not in visited:
                stack.append(neighbor)
    return order
```

### 2.3 经典例题：岛屿数量（LeetCode 200）

```python
def num_islands(grid: list[list[str]]) -> int:
    """DFS 沉岛法"""
    if not grid:
        return 0
    
    rows, cols = len(grid), len(grid[0])
    count = 0
    
    def dfs(r, c):
        if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] != '1':
            return
        grid[r][c] = '0'  # 标记为已访问（沉岛）
        dfs(r + 1, c)
        dfs(r - 1, c)
        dfs(r, c + 1)
        dfs(r, c - 1)
    
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                count += 1
                dfs(r, c)
    return count
```

### 2.4 BFS vs DFS 选择指南

| 场景 | 选择 | 原因 |
|------|------|------|
| 最短路径（无权） | BFS | 层层扩展保证最短 |
| 连通性检测 | DFS/BFS 均可 | 都能遍历所有可达节点 |
| 拓扑排序 | DFS（后序反转）或 BFS（Kahn） | 两种方法各有优势 |
| 检测环 | DFS | 用颜色标记更直观 |
| 层级信息（社交几度好友） | BFS | 天然按层遍历 |
| 回溯搜索（排列组合） | DFS | 递归天然适合 |

## 3. 最短路径算法

### 3.1 算法选择速览

| 算法 | 适用场景 | 时间复杂度 | 关键限制 |
|------|---------|-----------|---------|
| BFS | 无权图 | O(V+E) | 不能处理加权 |
| Dijkstra | 非负权图 | O((V+E)log V) | 不能处理负权边 |
| Bellman-Ford | 可处理负权 | O(VE) | 可检测负权环 |
| Floyd-Warshall | 全源最短路 | O(V³) | 适合小图 |

### 3.2 Dijkstra 算法

> **核心思想**：贪心 —— 每次从未确定的节点中，选距离起点最近的节点，用它更新邻居的距离。

```
Dijkstra 执行过程（起点 A）：

       A ──(1)── B
       |         |
      (4)       (2)
       |         |
       C ──(1)── D

步骤 1: dist = {A:0, B:∞, C:∞, D:∞}  → 选 A(0)
        更新：B=1, C=4
步骤 2: dist = {A:0, B:1, C:4, D:∞}  → 选 B(1)
        更新：D=1+2=3
步骤 3: dist = {A:0, B:1, C:4, D:3}  → 选 D(3)
        更新：C=min(4, 3+1)=4（无变化）
步骤 4: dist = {A:0, B:1, C:4, D:3}  → 选 C(4)

最终：A→B=1, A→C=4, A→D=3
```

```python
import heapq

def dijkstra(graph, start):
    """
    Dijkstra 最短路径算法（优先队列实现）
    graph: {node: [(neighbor, weight), ...]}
    返回: {node: shortest_distance}
    """
    dist = {start: 0}
    pq = [(0, start)]  # (距离, 节点)
    
    while pq:
        d, u = heapq.heappop(pq)
        # 如果当前距离已经大于已知最短距离，跳过
        if d > dist.get(u, float('inf')):
            continue
        for v, w in graph.get(u, []):
            new_dist = d + w
            if new_dist < dist.get(v, float('inf')):
                dist[v] = new_dist
                heapq.heappush(pq, (new_dist, v))
    return dist

# 示例使用
graph = {
    'A': [('B', 1), ('C', 4)],
    'B': [('C', 2), ('D', 5)],
    'C': [('D', 1)],
    'D': []
}
print(dijkstra(graph, 'A'))
# {'A': 0, 'B': 1, 'C': 3, 'D': 4}
```

### 3.3 Bellman-Ford 算法

**适用场景**：可以处理**负权边**，还能检测**负权环**。

```python
def bellman_ford(n, edges, start):
    """
    Bellman-Ford 算法
    n: 节点数, edges: [(u, v, weight), ...]
    返回: dist 字典，或 None（存在负权环）
    """
    dist = {i: float('inf') for i in range(n)}
    dist[start] = 0
    
    # 松弛 n-1 轮
    for _ in range(n - 1):
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
    
    # 检测负权环：第 n 轮如果还能松弛，说明有负权环
    for u, v, w in edges:
        if dist[u] + w < dist[v]:
            return None  # 存在负权环
    return dist
```

### 3.4 Floyd-Warshall 算法

**适用场景**：求所有节点对之间的最短路径。

```python
def floyd_warshall(n, edges):
    """
    Floyd-Warshall 全源最短路
    返回: dist[i][j] = i 到 j 的最短距离
    """
    INF = float('inf')
    dist = [[INF] * n for _ in range(n)]
    
    for i in range(n):
        dist[i][i] = 0
    for u, v, w in edges:
        dist[u][v] = w
    
    # 核心：三重循环，k 为中转节点
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    return dist
```

## 4. 拓扑排序

### 4.1 什么是拓扑排序

对有向无环图（DAG）的所有顶点进行线性排序，使得对于每条边 (u, v)，u 在排序中出现在 v 之前。

> **类比**：穿衣服有固定顺序——必须先穿内衣再穿外套，先穿袜子再穿鞋。拓扑排序就是找出一个不违反所有"先后关系"的合法顺序。

### 4.2 应用场景

- **课程安排**：每门课有先修课要求
- **任务调度**：某些任务必须在其他任务之前完成
- **编译依赖**：源文件的编译顺序
- **包管理**：npm/pip 安装依赖顺序

### 4.3 Kahn 算法（BFS）

```python
from collections import deque, defaultdict

def topological_sort_kahn(n, edges):
    """
    Kahn 算法：BFS 拓扑排序
    n: 节点数, edges: [(u, v), ...] 表示 u → v（u 是 v 的前置）
    返回: 拓扑排序结果，或空列表（有环）
    """
    graph = defaultdict(list)
    in_degree = [0] * n
    
    for u, v in edges:
        graph[u].append(v)
        in_degree[v] += 1
    
    # 入度为 0 的节点入队（没有前置依赖）
    queue = deque([i for i in range(n) if in_degree[i] == 0])
    order = []
    
    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)
    
    # 如果不是所有节点都被排序，说明有环
    return order if len(order) == n else []
```

### 4.4 DFS 后序反转法

```python
def topological_sort_dfs(n, edges):
    """DFS 拓扑排序：后序遍历的逆序就是拓扑序"""
    graph = defaultdict(list)
    for u, v in edges:
        graph[u].append(v)
    
    WHITE, GRAY, BLACK = 0, 1, 2
    color = [WHITE] * n
    order = []
    has_cycle = False
    
    def dfs(node):
        nonlocal has_cycle
        color[node] = GRAY  # 正在访问
        for neighbor in graph[node]:
            if color[neighbor] == GRAY:
                has_cycle = True  # 检测到环
                return
            if color[neighbor] == WHITE:
                dfs(neighbor)
        color[node] = BLACK  # 访问完成
        order.append(node)   # 后序添加
    
    for i in range(n):
        if color[i] == WHITE:
            dfs(i)
    
    if has_cycle:
        return []
    return order[::-1]  # 反转后序
```

### 4.5 经典例题：课程表 (LeetCode 207)

```python
def can_finish(num_courses: int, prerequisites: list[list[int]]) -> bool:
    """判断是否可以完成所有课程（即检测有向图是否有环）"""
    graph = defaultdict(list)
    in_degree = [0] * num_courses
    
    for course, prereq in prerequisites:
        graph[prereq].append(course)
        in_degree[course] += 1
    
    queue = deque([i for i in range(num_courses) if in_degree[i] == 0])
    count = 0
    
    while queue:
        node = queue.popleft()
        count += 1
        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)
    
    return count == num_courses
```

## 5. 并查集 (Union-Find)

### 5.1 概念与类比

> **类比**：并查集就像族谱系统。每个家族有一个族长（代表元素）。`find(x)` 是顺着族谱往上查，找到 x 的族长是谁；`union(x, y)` 是让两个家族合并，一个族长认另一个为家族代表。

### 5.2 两大优化

1. **路径压缩 (Path Compression)**：find 时让路径上所有节点直接指向根，加速后续查询
2. **按秩合并 (Union by Rank)**：合并时让矮树接到高树上，避免退化成链表

优化后，m 次操作的总时间复杂度为 **O(m·α(n))**，α 是反阿克曼函数，实际可视为常数。

### 5.3 代码实现

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
        self.count = n  # 连通分量数
    
    def find(self, x):
        """路径压缩：让 x 直接指向根"""
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        """按秩合并"""
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return False  # 已经在同一集合
        # 矮树接到高树上
        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1
        self.count -= 1
        return True
    
    def connected(self, x, y):
        return self.find(x) == self.find(y)
```

### 5.4 应用场景

- **连通分量**：判断图中有几个独立的子图
- **冗余连接**（LeetCode 684）：找到使图变成树需要删除的边
- **朋友圈数量**：社交网络中有多少个独立的朋友圈
- **最小生成树 Kruskal 算法**：用并查集判断是否形成环

## 6. 最小生成树

### 6.1 问题定义

给一个连通无向加权图，找一棵包含所有顶点的树，使得边的权重之和最小。

> **类比**：一个城市群需要铺设网线把所有城市连起来，每段光缆的铺设费用不同。最小生成树就是找费用最少的铺设方案。

### 6.2 Kruskal 算法

**策略**：贪心 —— 按边权从小到大排序，依次加入不形成环的边。

```python
def kruskal(n, edges):
    """
    Kruskal 最小生成树
    edges: [(weight, u, v), ...]
    返回: MST 的总权重和选中的边
    """
    edges.sort()  # 按权重排序
    uf = UnionFind(n)
    mst_weight = 0
    mst_edges = []
    
    for w, u, v in edges:
        if uf.union(u, v):  # 不形成环才加入
            mst_weight += w
            mst_edges.append((u, v, w))
            if len(mst_edges) == n - 1:
                break  # MST 恰好有 n-1 条边
    
    return mst_weight, mst_edges
```

### 6.3 Prim 算法

**策略**：贪心 —— 从一个起点开始，每次选与当前树相连的最小权重边。

```python
import heapq

def prim(graph, start=0):
    """
    Prim 最小生成树
    graph: {node: [(neighbor, weight), ...]}
    """
    visited = set()
    mst_weight = 0
    # (权重, 节点)
    pq = [(0, start)]
    
    while pq and len(visited) < len(graph):
        w, u = heapq.heappop(pq)
        if u in visited:
            continue
        visited.add(u)
        mst_weight += w
        for v, weight in graph[u]:
            if v not in visited:
                heapq.heappush(pq, (weight, v))
    
    return mst_weight
```

## 7. 贪心算法思想

### 7.1 什么是贪心

**贪心算法**在每一步选择当前看起来最优的选项（局部最优），希望最终得到全局最优解。

> **类比**：贪心就像百米赛跑中每一步都尽全力跑最远——并不是所有情况下这都是最优策略（比如马拉松就需要配速），但在很多特定问题中，局部最优确实能导向全局最优。

### 7.2 贪心 vs 动态规划

| 特性 | 贪心 | 动态规划 |
|------|------|---------|
| 决策方式 | 每步选局部最优，不回头 | 考虑所有子问题，取全局最优 |
| 正确性 | 需要证明（不总是对的） | 只要子问题分解正确就保证最优 |
| 时间复杂度 | 通常更快 | 通常更慢 |
| 适用条件 | 贪心选择性质 + 最优子结构 | 最优子结构 + 重叠子问题 |

### 7.3 贪心正确性证明方法

**1. 交换论证**：假设存在一个最优解 OPT 与贪心解 G 不同，证明可以把 OPT 中不同的部分"交换"成 G 的选择而不变差。

**2. 反证法**：假设贪心解不是最优的，推导出矛盾。

**3. 归纳法**：证明贪心每一步选择后，剩余问题的最优解与全局最优解一致。

### 7.4 贪心适用条件

1. **贪心选择性质**：局部最优选择能导向全局最优
2. **最优子结构**：问题的最优解包含子问题的最优解

> 💡 面试技巧：不确定能否用贪心时，先用贪心的直觉想出方案，再用一两个反例验证。如果贪心不行，考虑动态规划。

## 8. 经典贪心问题

### 8.1 活动选择 / 区间调度

**问题**：给定 n 个活动的 [start, end] 区间，选择最多的不重叠活动。

**贪心策略**：按**结束时间**排序，每次选结束最早的且不与已选冲突的活动。

```python
def max_non_overlapping(intervals: list[list[int]]) -> int:
    """贪心：最大不重叠区间数"""
    intervals.sort(key=lambda x: x[1])  # 按结束时间排序
    count = 0
    last_end = float('-inf')
    
    for start, end in intervals:
        if start >= last_end:
            count += 1
            last_end = end
    return count
```

### 8.2 跳跃游戏 (LeetCode 55)

**问题**：数组 `nums[i]` 表示从位置 i 可以跳的最远距离，判断能否到达最后一个位置。

```python
def can_jump(nums: list[int]) -> bool:
    """贪心：维护最远可达位置"""
    max_reach = 0
    for i in range(len(nums)):
        if i > max_reach:
            return False  # 当前位置不可达
        max_reach = max(max_reach, i + nums[i])
    return True
```

### 8.3 跳跃游戏 II (LeetCode 45)

**问题**：求到达最后位置的最少跳跃次数。

```python
def jump(nums: list[int]) -> int:
    """贪心：每次跳到能到达最远处的位置"""
    jumps = 0
    curr_end = 0    # 当前跳跃能到达的边界
    farthest = 0    # 在当前范围内能跳到的最远处
    
    for i in range(len(nums) - 1):
        farthest = max(farthest, i + nums[i])
        if i == curr_end:
            jumps += 1
            curr_end = farthest
    return jumps
```

### 8.4 分发糖果 (LeetCode 135)

**问题**：n 个孩子站成一排，每人有一个评分。规则：每人至少 1 颗糖；评分更高的孩子比邻居多。求最少需要多少糖果。

```python
def candy(ratings: list[int]) -> int:
    """两次遍历：先从左到右，再从右到左"""
    n = len(ratings)
    candies = [1] * n
    
    # 从左到右：如果右边评分更高，比左边多 1
    for i in range(1, n):
        if ratings[i] > ratings[i - 1]:
            candies[i] = candies[i - 1] + 1
    
    # 从右到左：如果左边评分更高，取 max
    for i in range(n - 2, -1, -1):
        if ratings[i] > ratings[i + 1]:
            candies[i] = max(candies[i], candies[i + 1] + 1)
    
    return sum(candies)
```

### 8.5 加油站 (LeetCode 134)

```python
def can_complete_circuit(gas: list[int], cost: list[int]) -> int:
    """贪心：如果总油量 >= 总消耗，一定有解"""
    total_tank = 0
    curr_tank = 0
    start = 0
    
    for i in range(len(gas)):
        diff = gas[i] - cost[i]
        total_tank += diff
        curr_tank += diff
        if curr_tank < 0:
            # 从 start 到 i 都不能作为起点
            start = i + 1
            curr_tank = 0
    
    return start if total_tank >= 0 else -1
```

### 8.6 分发饼干 (LeetCode 455)

```python
def find_content_children(g: list[int], s: list[int]) -> int:
    """贪心：最小的饼干满足最容易满足的孩子"""
    g.sort()  # 孩子的胃口
    s.sort()  # 饼干的大小
    child = cookie = 0
    
    while child < len(g) and cookie < len(s):
        if s[cookie] >= g[child]:
            child += 1  # 满足了这个孩子
        cookie += 1
    return child
```

## 9. 回溯算法

### 9.1 什么是回溯

回溯算法本质是 **DFS + 剪枝**。它系统地搜索所有可能的解，在发现当前路径不可能得到合法解时，立即"回头"（回溯），避免无用搜索。

> **类比**：回溯就像走迷宫画地图——每到一个岔路口做个标记，走到死胡同就回到上一个标记继续试另一条路。

### 9.2 回溯模板

```python
def backtrack(path, choices):
    """
    回溯通用模板
    path: 当前已做的选择
    choices: 当前可选的选项
    """
    if is_solution(path):
        result.append(path[:])  # 找到一个解
        return
    
    for choice in choices:
        if not is_valid(choice):  # 剪枝
            continue
        path.append(choice)       # 做选择
        backtrack(path, new_choices)  # 递归
        path.pop()                # 撤销选择（回溯）
```

### 9.3 子集 (LeetCode 78)

```python
def subsets(nums: list[int]) -> list[list[int]]:
    result = []
    
    def backtrack(start, path):
        result.append(path[:])  # 每个节点都是一个子集
        for i in range(start, len(nums)):
            path.append(nums[i])
            backtrack(i + 1, path)
            path.pop()
    
    backtrack(0, [])
    return result

# subsets([1, 2, 3]) →
# [[], [1], [1,2], [1,2,3], [1,3], [2], [2,3], [3]]
```

### 9.4 全排列 (LeetCode 46)

```python
def permute(nums: list[int]) -> list[list[int]]:
    result = []
    
    def backtrack(path, remaining):
        if not remaining:
            result.append(path[:])
            return
        for i in range(len(remaining)):
            path.append(remaining[i])
            backtrack(path, remaining[:i] + remaining[i+1:])
            path.pop()
    
    backtrack([], nums)
    return result
```

### 9.5 组合总和 (LeetCode 39)

```python
def combination_sum(candidates: list[int], target: int) -> list[list[int]]:
    result = []
    candidates.sort()
    
    def backtrack(start, path, remaining):
        if remaining == 0:
            result.append(path[:])
            return
        for i in range(start, len(candidates)):
            if candidates[i] > remaining:
                break  # 剪枝：排序后后面更大，不可能
            path.append(candidates[i])
            backtrack(i, path, remaining - candidates[i])  # i 不是 i+1，允许重复
            path.pop()
    
    backtrack(0, [], target)
    return result
```

### 9.6 N 皇后 (LeetCode 51)

**问题**：在 n×n 棋盘上放 n 个皇后，使其不相互攻击（不同行、不同列、不同对角线）。

```python
def solve_n_queens(n: int) -> list[list[str]]:
    result = []
    board = [['.' for _ in range(n)] for _ in range(n)]
    cols = set()       # 已占用的列
    diag1 = set()      # 已占用的主对角线 (row - col)
    diag2 = set()      # 已占用的副对角线 (row + col)
    
    def backtrack(row):
        if row == n:
            result.append([''.join(r) for r in board])
            return
        
        for col in range(n):
            if col in cols or (row - col) in diag1 or (row + col) in diag2:
                continue  # 剪枝
            
            # 放置皇后
            board[row][col] = 'Q'
            cols.add(col)
            diag1.add(row - col)
            diag2.add(row + col)
            
            backtrack(row + 1)
            
            # 回溯：移除皇后
            board[row][col] = '.'
            cols.remove(col)
            diag1.remove(row - col)
            diag2.remove(row + col)
    
    backtrack(0)
    return result
```

### 9.7 回溯三大经典总结

| 问题类型 | 题目 | 关键区别 |
|---------|------|---------|
| 子集 | 求所有子集 | for 从 start 开始，每个节点都加入结果 |
| 排列 | 求所有排列 | 不用 start，用 visited 标记已选元素 |
| 组合 | 求目标和的组合 | for 从 start 开始 + 剪枝(排序后提前终止) |

## 常见陷阱与最佳实践

### 陷阱

1. **BFS 忘记标记 visited**：导致无限循环
2. **Dijkstra 用于负权图**：负权边会导致贪心策略失效
3. **拓扑排序不检测环**：DAG 前提不满足时结果无意义
4. **贪心不证明正确性**：直觉上的贪心策略不一定正确（如 0-1 背包不能用贪心）
5. **回溯忘记撤销选择**：导致状态污染

### 最佳实践

1. **图题先画图**：把示例画出来，确定是有向/无向、加权/无权
2. **BFS/DFS 选择有原则**：最短路用 BFS，全路径搜索用 DFS
3. **并查集写成模板**：面试直接默写，省时间
4. **回溯题先写模板再填细节**：子集/排列/组合只有微小差异
5. **贪心题先想反例**：想到一个策略就试试 [3,2,1] 这种逆序场景
