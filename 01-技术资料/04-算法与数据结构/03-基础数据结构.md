## 1. 为什么掌握数据结构如此重要

### 1.1 程序的本质：数据结构 + 算法

Niklaus Wirth 的经典公式：**程序 = 数据结构 + 算法**。数据结构决定了数据如何存储和组织，算法决定了如何操作这些数据。选错数据结构，再好的算法也无法挽救性能。

> **生活类比**：数据结构就像收纳工具。同样是收纳衣物——扔地上（无结构），找一件外套要翻遍全部；挂衣柜里按类别排列（有结构），一伸手就拿到。程序中数据的组织方式同理。

### 1.2 面试中的核心地位

据统计，70% 以上的编程面试题都可以归结为：**选择合适的数据结构 + 应用对应的算法**。掌握数组、链表、栈、队列、哈希表、树、堆、图这 8 大核心数据结构，就能覆盖绝大多数面试场景。

### 1.3 本文组织方式

每种数据结构按以下模式展开：

1. **概念类比** —— 用生活场景建立直觉
2. **核心操作与时间复杂度** —— 一表看清性能特征
3. **内部结构图解** —— ASCII 图揭示底层原理
4. **Python 实现代码** —— 可运行的完整实现
5. **典型应用场景** —— 知道什么时候该用它
6. **面试常考操作** —— 高频考点精准定位

## 2. 数组与字符串

### 2.1 概念与类比

> **类比**：数组就像电影院的座位——一排座位连续排列，每个座位有唯一编号。只要知道座位号（下标），就能直接找到对应位置，不需要从第一个开始数。

**数组（Array）** 是最基础的数据结构：元素在**连续内存**中存放，通过**下标**直接访问。

```
内存布局（连续存储）：
┌─────┬─────┬─────┬─────┬─────┐
│  10 │  20 │  30 │  40 │  50 │
└─────┴─────┴─────┴─────┴─────┘
  [0]   [1]   [2]   [3]   [4]

地址计算：addr[i] = base_addr + i * element_size
→ 任意位置访问 O(1)
```

### 2.2 核心操作复杂度

| 操作              | 时间复杂度 | 说明             |
| ----------------- | ---------- | ---------------- |
| 随机访问 `arr[i]` | O(1)       | 地址计算直接定位 |
| 尾部追加          | 均摊 O(1)  | 动态数组扩容     |
| 头部/中间插入     | O(n)       | 需要搬移后续元素 |
| 头部/中间删除     | O(n)       | 需要搬移后续元素 |
| 搜索（无序）      | O(n)       | 逐个遍历         |
| 搜索（有序）      | O(log n)   | 二分查找         |

### 2.3 动态数组扩容策略

Python 的 `list` 和 Java 的 `ArrayList` 都是动态数组，核心策略是 **2 倍扩容**（Python 实际约 1.125 倍）：

```
初始容量：4
追加第 5 个元素时：
  1. 申请新数组，容量 = 4 * 2 = 8
  2. 复制旧数据到新数组  ← O(n)
  3. 释放旧数组

扩容代价虽是 O(n)，但因为不是每次都扩容——
均摊分析：n 次 append 总代价 ≈ n + n/2 + n/4 + ... ≈ 2n → 均摊 O(1)
```

### 2.4 代码：实现动态数组

```python
class DynamicArray:
    """模拟动态数组（Python list 底层原理）"""

    def __init__(self):
        self._capacity = 4
        self._size = 0
        self._data = [None] * self._capacity

    def append(self, val):
        if self._size == self._capacity:
            self._resize(self._capacity * 2)
        self._data[self._size] = val
        self._size += 1

    def get(self, index):
        if index < 0 or index >= self._size:
            raise IndexError("Index out of range")
        return self._data[index]

    def pop(self):
        if self._size == 0:
            raise IndexError("Pop from empty array")
        self._size -= 1
        val = self._data[self._size]
        self._data[self._size] = None
        # 缩容：当使用率低于 1/4 时缩容到一半
        if self._size > 0 and self._size == self._capacity // 4:
            self._resize(self._capacity // 2)
        return val

    def _resize(self, new_cap):
        new_data = [None] * new_cap
        for i in range(self._size):
            new_data[i] = self._data[i]
        self._data = new_data
        self._capacity = new_cap

    def __len__(self):
        return self._size
```

### 2.5 面试高频技巧

**双指针**：两个指针从两端向中间靠拢（如两数之和-有序数组），或快慢指针同向移动（如移除元素）。

**滑动窗口**：维护一个可变长度的窗口，用于子串/子数组问题（如最小覆盖子串、无重复字符最长子串）。

```python
# 滑动窗口模板
def sliding_window(s):
    left = 0
    window = {}  # 窗口内的状态
    result = 0
    for right in range(len(s)):
        # 扩大窗口：加入 s[right]
        c = s[right]
        window[c] = window.get(c, 0) + 1
        # 收缩窗口：当窗口不满足条件时
        while not valid(window):  # 自定义条件
            d = s[left]
            window[d] -= 1
            left += 1
        # 更新结果
        result = max(result, right - left + 1)
    return result
```

## 3. 链表

### 3.1 概念与类比

> **类比**：链表就像寻宝游戏——每条线索（节点）上写着两样东西：一个宝物（数据），以及下一条线索的位置（指针）。你必须按顺序一个接一个地找，不能直接跳到第 5 条线索。

```
单链表结构：
┌──────┬──────┐    ┌──────┬──────┐    ┌──────┬──────┐
│ data │ next │───→│ data │ next │───→│ data │ next │───→ null
└──────┴──────┘    └──────┴──────┘    └──────┴──────┘
  节点 1              节点 2              节点 3

双向链表：
null ←──┌──────┬──────┬──────┐    ┌──────┬──────┬──────┐──→ null
        │ prev │ data │ next │←──→│ prev │ data │ next │
        └──────┴──────┴──────┘    └──────┴──────┴──────┘
```

### 3.2 链表类型对比

| 类型     | 特点                    | 常用场景                   |
| -------- | ----------------------- | -------------------------- |
| 单链表   | 只能单向遍历，空间省    | 基本链表操作题             |
| 双向链表 | 双向遍历，删除节点 O(1) | LRU Cache / 浏览器前进后退 |
| 循环链表 | 尾节点指向头节点        | 约瑟夫问题 / 循环缓冲区    |

### 3.3 核心操作复杂度

| 操作                      | 时间复杂度 | 说明           |
| ------------------------- | ---------- | -------------- |
| 头部插入/删除             | O(1)       | 修改指针即可   |
| 尾部插入（有尾指针）      | O(1)       | 直接追加       |
| 中间插入/删除（已知位置） | O(1)       | 修改指针       |
| 按值搜索                  | O(n)       | 必须遍历       |
| 按索引访问                | O(n)       | 不支持随机访问 |

### 3.4 经典操作：翻转链表

翻转链表是面试高频 Top 3 的题目，核心是逐个翻转指针方向：

```
翻转链表过程：
1 → 2 → 3 → 4 → null
↓ (逐步翻转指针方向)
null ← 1   2 → 3 → 4 → null  (prev=1, curr=2)
null ← 1 ← 2   3 → 4 → null  (prev=2, curr=3)
null ← 1 ← 2 ← 3   4 → null  (prev=3, curr=4)
null ← 1 ← 2 ← 3 ← 4         (prev=4=new head)
```

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def reverse_list(head: ListNode) -> ListNode:
    """迭代法：三指针翻转"""
    prev, curr = None, head
    while curr:
        nxt = curr.next    # 1. 保存下一个节点
        curr.next = prev   # 2. 翻转指针
        prev = curr        # 3. prev 前进
        curr = nxt         # 4. curr 前进
    return prev  # prev 就是新的头节点

def reverse_list_recursive(head: ListNode) -> ListNode:
    """递归法"""
    if not head or not head.next:
        return head
    new_head = reverse_list_recursive(head.next)
    head.next.next = head  # 让后继节点指回自己
    head.next = None       # 断开原来的正向指针
    return new_head
```

### 3.5 经典操作：检测环（Floyd 算法）

> **类比**：想象环形跑道上两个跑步者——一个快（每步走 2 格），一个慢（每步走 1 格）。如果跑道是环形的，快跑者最终一定会"套圈"追上慢跑者。

```python
def has_cycle(head: ListNode) -> bool:
    slow = fast = head
    while fast and fast.next:
        slow = slow.next        # 慢指针走 1 步
        fast = fast.next.next   # 快指针走 2 步
        if slow == fast:
            return True
    return False

def detect_cycle_start(head: ListNode) -> ListNode:
    """找到环的入口节点"""
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            # 相遇后，一个从 head 出发，一个从相遇点出发，再次相遇就是入口
            p = head
            while p != slow:
                p = p.next
                slow = slow.next
            return p
    return None
```

### 3.6 快慢指针：找链表中点

```python
def find_middle(head: ListNode) -> ListNode:
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow  # 对于偶数节点，返回第二个中间节点
```

### 3.7 面试必知

- **翻转链表**：迭代（O(1) 空间）和递归两种解法
- **检测环 + 找环入口**：Floyd 快慢指针
- **合并两个有序链表**：哨兵节点技巧
- **删除倒数第 N 个节点**：快慢指针间隔 N 步
- **回文链表**：找中点 + 翻转后半段 + 比较

## 4. 栈与队列

### 4.1 概念与类比

> **栈类比**：栈就像叠盘子——最后放上去的盘子最先被取走（LIFO: Last In, First Out）。
>
> **队列类比**：队列就像排队买票——先排队的人先买到票（FIFO: First In, First Out）。

```
栈 (LIFO)：              队列 (FIFO)：
  ┌─────┐                入队 ──→ ┌───┬───┬───┬───┐ ──→ 出队
  │  3  │ ← 栈顶 (top)           │ D │ C │ B │ A │
  ├─────┤                        └───┴───┴───┴───┘
  │  2  │                         后           前
  ├─────┤
  │  1  │ ← 栈底 (bottom)
  └─────┘
  push/pop 都在栈顶
```

### 4.2 核心操作复杂度

| 数据结构       | push/enqueue | pop/dequeue | peek/front | 搜索 |
| -------------- | ------------ | ----------- | ---------- | ---- |
| 栈             | O(1)         | O(1)        | O(1)       | O(n) |
| 队列           | O(1)         | O(1)        | O(1)       | O(n) |
| 双端队列 deque | O(1) 两端    | O(1) 两端   | O(1)       | O(n) |

### 4.3 栈的经典应用：括号匹配

```python
def is_valid_parentheses(s: str) -> bool:
    stack = []
    mapping = {')': '(', ']': '[', '}': '{'}
    for char in s:
        if char in mapping:
            if not stack or stack[-1] != mapping[char]:
                return False
            stack.pop()
        else:
            stack.append(char)
    return len(stack) == 0
```

### 4.4 单调栈

**单调栈**维护一个从栈底到栈顶单调递增（或递减）的栈，用于解决"下一个更大/更小元素"类问题。

```python
def next_greater_element(nums: list) -> list:
    """找每个元素右边第一个比它大的元素"""
    n = len(nums)
    result = [-1] * n
    stack = []  # 存下标，维护单调递减栈
    for i in range(n):
        while stack and nums[i] > nums[stack[-1]]:
            idx = stack.pop()
            result[idx] = nums[i]
        stack.append(i)
    return result

# 示例：nums = [2, 1, 2, 4, 3]
# result = [4, 2, 4, -1, -1]
```

### 4.5 双端队列与滑动窗口最大值

```python
from collections import deque

def max_sliding_window(nums: list, k: int) -> list:
    """单调队列解法：滑动窗口最大值"""
    dq = deque()  # 存下标，维护单调递减队列
    result = []
    for i in range(len(nums)):
        # 移除窗口外的元素
        while dq and dq[0] < i - k + 1:
            dq.popleft()
        # 维护单调递减：移除比当前值小的元素
        while dq and nums[dq[-1]] < nums[i]:
            dq.pop()
        dq.append(i)
        if i >= k - 1:
            result.append(nums[dq[0]])
    return result
```

### 4.6 栈的其他经典应用

- **函数调用栈**：操作系统用栈管理函数调用和返回
- **表达式求值**：中缀转后缀、计算器实现
- **DFS 的迭代实现**：用栈模拟递归
- **浏览器前进后退**：双栈实现历史记录

## 5. 哈希表

### 5.1 概念与类比

> **类比**：哈希表就像快递柜——你的手机号经过一个公式（哈希函数）算出取件码（下标），然后直接去对应的柜子（桶）取包裹。不需要逐个柜子找。

哈希表的核心原理：**哈希函数** 将 key 映射为数组下标，实现 O(1) 平均时间的查找、插入和删除。

```
哈希表工作流程：
key("apple") ──→ hash("apple") = 2378 ──→ 2378 % 8 = 2 ──→ buckets[2]

┌─────────────────────────────────────────┐
│  key        hash()     % capacity  idx  │
├─────────────────────────────────────────┤
│ "apple"  →  2378    →  2378%8  →   2   │
│ "banana" →  5141    →  5141%8  →   5   │
│ "cherry" →  7890    →  7890%8  →   2   │ ← 冲突！
└─────────────────────────────────────────┘
```

### 5.2 哈希冲突解决

当不同的 key 映射到同一个下标时，就发生了**哈希冲突**。两种主流解决方案：

**方案一：链地址法（Separate Chaining）**—— Java HashMap / Go map

```
buckets 数组：
[0] → null
[1] → null
[2] → ("apple", 3) → ("cherry", 7) → null   ← 链表
[3] → null
[4] → null
[5] → ("banana", 5) → null
[6] → null
[7] → null

每个桶是一个链表（Java 8 之后当链表长度 > 8 时转红黑树）
```

**方案二：开放寻址法（Open Addressing）**—— Python dict

```
线性探测：如果位置被占，就看下一个位置
buckets[hash(key) % cap]  → 被占了
buckets[(hash(key)+1) % cap]  → 被占了
buckets[(hash(key)+2) % cap]  → 空！放这里
```

### 5.3 负载因子与扩容

**负载因子 (Load Factor)** = 元素数量 / 桶数量。负载因子越大，冲突越多，性能越差。

| 语言/实现    | 负载因子阈值    | 扩容策略 | 冲突解决              |
| ------------ | --------------- | -------- | --------------------- |
| Java HashMap | 0.75            | 2 倍扩容 | 链地址法(链表/红黑树) |
| Python dict  | 2/3 ≈ 0.67      | 2 倍扩容 | 开放寻址法            |
| Go map       | 6.5（每桶平均） | 2 倍扩容 | 链地址法 + 溢出桶     |

扩容过程：

1. 创建一个 2 倍大小的新数组
2. 对所有已有元素重新计算哈希值（rehash），放入新数组
3. 释放旧数组

> **注意**：扩容时所有元素都要 rehash，这是 O(n) 操作。但因为不是每次插入都扩容，均摊下来仍是 O(1)。

### 5.4 代码：手写简易 HashMap

```python
class HashMap:
    """链地址法实现的哈希表"""

    def __init__(self, capacity=16):
        self.capacity = capacity
        self.size = 0
        self.buckets = [[] for _ in range(capacity)]

    def _hash(self, key):
        return hash(key) % self.capacity

    def put(self, key, value):
        idx = self._hash(key)
        # 检查 key 是否已存在，存在则更新
        for i, (k, v) in enumerate(self.buckets[idx]):
            if k == key:
                self.buckets[idx][i] = (key, value)
                return
        # 不存在则追加
        self.buckets[idx].append((key, value))
        self.size += 1
        # 检查负载因子，超过 0.75 则扩容
        if self.size / self.capacity > 0.75:
            self._resize()

    def get(self, key, default=None):
        idx = self._hash(key)
        for k, v in self.buckets[idx]:
            if k == key:
                return v
        return default

    def remove(self, key):
        idx = self._hash(key)
        for i, (k, v) in enumerate(self.buckets[idx]):
            if k == key:
                self.buckets[idx].pop(i)
                self.size -= 1
                return v
        raise KeyError(key)

    def _resize(self):
        old_buckets = self.buckets
        self.capacity *= 2
        self.buckets = [[] for _ in range(self.capacity)]
        self.size = 0
        for bucket in old_buckets:
            for k, v in bucket:
                self.put(k, v)

    def __contains__(self, key):
        idx = self._hash(key)
        return any(k == key for k, _ in self.buckets[idx])

    def __len__(self):
        return self.size
```

### 5.5 哈希表核心复杂度

| 操作 | 平均 | 最坏 | 说明                         |
| ---- | ---- | ---- | ---------------------------- |
| 插入 | O(1) | O(n) | 最坏：所有 key 冲突到同一桶  |
| 查找 | O(1) | O(n) | 均摊 O(1) 前提：好的哈希函数 |
| 删除 | O(1) | O(n) | 同上                         |

### 5.6 面试高频考法

- **两数之和**：用哈希表存已遍历的值，O(n) 解决
- **字母异位词分组**：用 sorted 字符串作为哈希 key
- **最长连续序列**：HashSet + 只从序列起点开始计数
- **手写 HashMap**：链地址法 + 扩容机制
- **Java HashMap 面试三连**：初始容量 / 负载因子 / 链表转红黑树条件

## 6. 树与二叉树

### 6.1 概念与类比

> **类比**：树就像一个家族族谱——有一个祖先（根节点），每个人可以有多个孩子（子节点），没有孩子的人是"末代"（叶子节点）。

```
        二叉搜索树 (BST)：
              8
            /   \
           3     10
          / \      \
         1   6     14
            / \    /
           4   7  13

        性质：左子树所有值 < 根 < 右子树所有值
        中序遍历结果：1, 3, 4, 6, 7, 8, 10, 13, 14 (有序！)
```

### 6.2 树的基本术语

| 术语            | 含义                                   |
| --------------- | -------------------------------------- |
| 根节点 (Root)   | 没有父节点的顶层节点                   |
| 叶子节点 (Leaf) | 没有子节点的节点                       |
| 深度 (Depth)    | 从根到该节点的边数                     |
| 高度 (Height)   | 从该节点到最远叶子的边数               |
| 完全二叉树      | 除最后一层外全满，最后一层从左到右连续 |
| 满二叉树        | 每层都完全填满                         |

### 6.3 四种遍历方式

```
        1
       / \
      2   3
     / \
    4   5

前序 (Pre-order):  根→左→右  →  1, 2, 4, 5, 3
中序 (In-order):   左→根→右  →  4, 2, 5, 1, 3
后序 (Post-order): 左→右→根  →  4, 5, 2, 3, 1
层序 (Level-order): BFS      →  1, 2, 3, 4, 5
```

### 6.4 代码：BST 实现 + 三种遍历

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class BST:
    def __init__(self):
        self.root = None

    def insert(self, val):
        self.root = self._insert(self.root, val)

    def _insert(self, node, val):
        if not node:
            return TreeNode(val)
        if val < node.val:
            node.left = self._insert(node.left, val)
        elif val > node.val:
            node.right = self._insert(node.right, val)
        return node

    def search(self, val):
        return self._search(self.root, val)

    def _search(self, node, val):
        if not node or node.val == val:
            return node
        if val < node.val:
            return self._search(node.left, val)
        return self._search(node.right, val)

    def delete(self, val):
        self.root = self._delete(self.root, val)

    def _delete(self, node, val):
        if not node:
            return None
        if val < node.val:
            node.left = self._delete(node.left, val)
        elif val > node.val:
            node.right = self._delete(node.right, val)
        else:
            # 找到要删除的节点
            if not node.left:
                return node.right
            if not node.right:
                return node.left
            # 两个子节点：用中序后继替换
            successor = self._find_min(node.right)
            node.val = successor.val
            node.right = self._delete(node.right, successor.val)
        return node

    def _find_min(self, node):
        while node.left:
            node = node.left
        return node

# 三种遍历
def preorder(root):
    """前序遍历：根→左→右"""
    if not root:
        return []
    return [root.val] + preorder(root.left) + preorder(root.right)

def inorder(root):
    """中序遍历：左→根→右（BST 中序遍历是有序的）"""
    if not root:
        return []
    return inorder(root.left) + [root.val] + inorder(root.right)

def postorder(root):
    """后序遍历：左→右→根"""
    if not root:
        return []
    return postorder(root.left) + postorder(root.right) + [root.val]

def level_order(root):
    """层序遍历（BFS）"""
    if not root:
        return []
    from collections import deque
    queue = deque([root])
    result = []
    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        result.append(level)
    return result
```

### 6.5 中序遍历的迭代实现

递归实现简单但有栈溢出风险，迭代实现面试常考：

```python
def inorder_iterative(root):
    """中序遍历迭代版：用栈模拟递归"""
    result = []
    stack = []
    curr = root
    while curr or stack:
        # 一路向左走到底
        while curr:
            stack.append(curr)
            curr = curr.left
        # 弹出节点，处理
        curr = stack.pop()
        result.append(curr.val)
        # 转向右子树
        curr = curr.right
    return result
```

### 6.6 平衡树对比：AVL vs 红黑树

| 特性      | AVL 树                     | 红黑树                           |
| --------- | -------------------------- | -------------------------------- |
| 平衡程度  | 严格平衡（左右高度差 ≤ 1） | 近似平衡（最长路径 ≤ 2×最短）    |
| 查找效率  | 更高（树更矮）             | 略低                             |
| 插入/删除 | 旋转次数多，维护成本高     | 旋转次数少（最多 3 次）          |
| 适用场景  | 读多写少（数据库索引）     | 通用场景（Java TreeMap/HashMap） |

### 6.7 Trie 前缀树

```
插入 "app", "apple", "api"：

        root
       /
      a
       \
        p
       / \
      p   i*
     /
    l
    |
    e*

*标记单词结尾
```

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str):
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True

    def search(self, word: str) -> bool:
        node = self._find(word)
        return node is not None and node.is_end

    def starts_with(self, prefix: str) -> bool:
        return self._find(prefix) is not None

    def _find(self, prefix: str):
        node = self.root
        for char in prefix:
            if char not in node.children:
                return None
            node = node.children[char]
        return node
```

## 7. 堆（优先队列）

### 7.1 概念与类比

> **类比**：堆就像 VIP 通道——不管你什么时候来，优先级最高的（最小/最大值）总是最先出来。普通队列看先来后到，优先队列看优先级。

**堆**是一棵**完全二叉树**，用**数组**存储，满足堆序性质：

- **小顶堆**：父节点 ≤ 子节点 → 堆顶是最小值
- **大顶堆**：父节点 ≥ 子节点 → 堆顶是最大值

```
小顶堆示例：
        1
       / \
      3   2
     / \ / \
    7  8 5  4

数组表示：[1, 3, 2, 7, 8, 5, 4]
索引关系：parent(i) = (i-1)//2
          left(i)   = 2*i + 1
          right(i)  = 2*i + 2
```

### 7.2 核心操作

| 操作            | 时间复杂度 | 说明                            |
| --------------- | ---------- | ------------------------------- |
| 插入 (push)     | O(log n)   | sift_up：新元素上浮             |
| 删除堆顶 (pop)  | O(log n)   | sift_down：末尾元素放堆顶后下沉 |
| 查看堆顶 (peek) | O(1)       | 直接返回 arr[0]                 |
| 建堆 (heapify)  | O(n)       | 从最后一个非叶节点开始下沉      |

### 7.3 代码：手写小顶堆

```python
class MinHeap:
    def __init__(self):
        self.heap = []

    def push(self, val):
        self.heap.append(val)
        self._sift_up(len(self.heap) - 1)

    def pop(self):
        if not self.heap:
            raise IndexError("Heap is empty")
        # 将堆顶和末尾交换，弹出末尾，然后堆顶下沉
        self.heap[0], self.heap[-1] = self.heap[-1], self.heap[0]
        val = self.heap.pop()
        if self.heap:
            self._sift_down(0)
        return val

    def peek(self):
        if not self.heap:
            raise IndexError("Heap is empty")
        return self.heap[0]

    def _sift_up(self, i):
        while i > 0:
            parent = (i - 1) // 2
            if self.heap[i] < self.heap[parent]:
                self.heap[i], self.heap[parent] = self.heap[parent], self.heap[i]
                i = parent
            else:
                break

    def _sift_down(self, i):
        n = len(self.heap)
        while True:
            smallest = i
            left = 2 * i + 1
            right = 2 * i + 2
            if left < n and self.heap[left] < self.heap[smallest]:
                smallest = left
            if right < n and self.heap[right] < self.heap[smallest]:
                smallest = right
            if smallest != i:
                self.heap[i], self.heap[smallest] = self.heap[smallest], self.heap[i]
                i = smallest
            else:
                break
```

### 7.4 TopK 问题：Python heapq 实战

```python
import heapq

def top_k_largest(nums: list, k: int) -> list:
    """找前 K 大元素：维护大小为 K 的小顶堆"""
    # 小顶堆中保留最大的 K 个元素
    # 堆顶是这 K 个中最小的
    min_heap = []
    for num in nums:
        if len(min_heap) < k:
            heapq.heappush(min_heap, num)
        elif num > min_heap[0]:
            heapq.heapreplace(min_heap, num)  # pop + push
    return sorted(min_heap, reverse=True)

# 更简洁的写法
def top_k_largest_v2(nums: list, k: int) -> list:
    return heapq.nlargest(k, nums)
```

### 7.5 堆的典型应用

- **TopK 问题**：维护大小为 K 的堆
- **合并 K 个有序链表**：用小顶堆维护每个链表的当前最小值
- **数据流中位数**：大顶堆 + 小顶堆
- **Dijkstra 最短路径**：优先队列取最小距离节点
- **任务调度 / 操作系统进程调度**

## 8. 图

### 8.1 概念与类比

> **类比**：图就像城市的地图——城市是节点（顶点），城市之间的公路是边。公路可以是单行道（有向图）或双向通行（无向图），还可以标注距离（加权图）。

### 8.2 图的表示

```
无向图示例：       邻接矩阵：          邻接表：
  A --- B           A  B  C  D        A: [B, C]
  |   / |        A [0, 1, 1, 0]       B: [A, C, D]
  |  /  |        B [1, 0, 1, 1]       C: [A, B]
  C --- D        C [1, 1, 0, 0]       D: [B]
                 D [0, 1, 0, 0]
```

| 表示方式 | 空间   | 查边      | 适用场景                         |
| -------- | ------ | --------- | -------------------------------- |
| 邻接矩阵 | O(V²)  | O(1)      | 稠密图、需要快速判断两点是否相连 |
| 邻接表   | O(V+E) | O(degree) | 稀疏图（大多数实际场景）         |

### 8.3 邻接表 Python 实现

```python
from collections import defaultdict, deque

class Graph:
    def __init__(self, directed=False):
        self.adj = defaultdict(list)
        self.directed = directed

    def add_edge(self, u, v, weight=1):
        self.adj[u].append((v, weight))
        if not self.directed:
            self.adj[v].append((u, weight))

    def bfs(self, start):
        """广度优先搜索：层层扩展"""
        visited = {start}
        queue = deque([start])
        order = []
        while queue:
            node = queue.popleft()
            order.append(node)
            for neighbor, _ in self.adj[node]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)
        return order

    def dfs(self, start):
        """深度优先搜索：一路走到底"""
        visited = set()
        order = []
        def _dfs(node):
            visited.add(node)
            order.append(node)
            for neighbor, _ in self.adj[node]:
                if neighbor not in visited:
                    _dfs(neighbor)
        _dfs(start)
        return order
```

### 8.4 BFS vs DFS 速览

| 特性       | BFS                | DFS                    |
| ---------- | ------------------ | ---------------------- |
| 数据结构   | 队列               | 栈/递归                |
| 搜索方式   | 层层扩展           | 一路到底               |
| 最短路径   | ✅ 无权图最短路    | ❌                     |
| 空间复杂度 | O(宽度)            | O(深度)                |
| 经典应用   | 最短路径、层序遍历 | 连通性、拓扑排序、回溯 |

> **详细图算法**（Dijkstra / 拓扑排序 / 并查集 / 最小生成树 / 回溯）见 [图算法与贪心策略](./05-图算法与贪心.md)。

## 9. 数据结构选型指南

### 9.1 时间复杂度综合对比

| 数据结构 | 访问     | 搜索     | 插入     | 删除     | 空间 |
| -------- | -------- | -------- | -------- | -------- | ---- |
| 数组     | O(1)     | O(n)     | O(n)     | O(n)     | O(n) |
| 链表     | O(n)     | O(n)     | O(1)\*   | O(1)\*   | O(n) |
| 栈/队列  | O(n)     | O(n)     | O(1)     | O(1)     | O(n) |
| 哈希表   | —        | O(1)     | O(1)     | O(1)     | O(n) |
| BST      | O(log n) | O(log n) | O(log n) | O(log n) | O(n) |
| 堆       | —        | O(n)     | O(log n) | O(log n) | O(n) |

> \*链表的 O(1) 插入/删除前提是**已经定位到目标节点**。

### 9.2 选择决策流程

```
需求分析 → 选择数据结构：

需要快速查找？
  ├── 按 key 查找 → 哈希表
  ├── 按范围查找 → BST / 有序数组 + 二分
  └── 前缀匹配   → Trie

需要有序？
  ├── 动态插入且保持有序 → BST / 平衡树
  └── 只需找最大/最小    → 堆

需要队列/栈语义？
  ├── LIFO → 栈
  ├── FIFO → 队列
  └── 优先级 → 堆

需要处理关系/连通性？
  └── 图（邻接表 + BFS/DFS）

不确定？
  └── 先用哈希表（Python dict），不够再换
```

### 9.3 常见面试组合模式

| 组合              | 应用                          |
| ----------------- | ----------------------------- |
| 哈希表 + 双向链表 | LRU Cache                     |
| 哈希表 + 堆       | TopK / LFU Cache              |
| 栈 + 栈           | 浏览器前进后退 / 队列实现     |
| 数组 + 哈希表     | O(1) 随机获取 + O(1) 插入删除 |
| Trie + DFS        | 单词搜索 / 自动补全           |
| 并查集 + 图       | 连通分量 / 冗余连接           |

## 常见陷阱与最佳实践

### 陷阱

1. **忘记处理空链表**：链表题一定先判空，或使用哨兵节点
2. **哈希函数不均匀**：导致大量冲突，性能退化到 O(n)
3. **BST 退化成链表**：有序插入时 BST 高度为 n，需要平衡树
4. **堆排序不稳定**：堆操作不保持相同元素的原始顺序
5. **Python list 当栈用没问题，当队列用性能差**：popleft 是 O(n)，应该用 `collections.deque`

### 最佳实践

1. **面试时先说数据结构选择**：在写代码前，先向面试官说明为什么选择该数据结构
2. **善用 Python 标准库**：`collections.deque`、`heapq`、`collections.defaultdict`、`collections.Counter`
3. **链表题用哨兵节点**：`dummy = ListNode(0); dummy.next = head` 简化边界处理
4. **树题多想递归**：树的递归结构天然适合递归解法
5. **哈希表是万能钥匙**：遇到 O(n²) 暴力解，先想想哈希表能否优化到 O(n)
