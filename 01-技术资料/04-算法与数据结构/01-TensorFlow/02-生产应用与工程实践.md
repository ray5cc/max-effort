## 1. 训练模式与 Keras API

### 1.1 标准 Keras 训练循环

适用于大多数场景，代码简洁，内置回调机制完善：

```python
import tensorflow as tf

# 构建模型（Functional API）
def build_model(input_dim, num_classes):
    inputs = tf.keras.Input(shape=(input_dim,))
    x = tf.keras.layers.Dense(512, activation='relu')(inputs)
    x = tf.keras.layers.BatchNormalization()(x)
    x = tf.keras.layers.Dropout(0.4)(x)
    x = tf.keras.layers.Dense(256, activation='relu')(x)
    x = tf.keras.layers.Dropout(0.3)(x)
    outputs = tf.keras.layers.Dense(num_classes, activation='softmax')(x)
    return tf.keras.Model(inputs, outputs)

model = build_model(784, 10)

# 编译
model.compile(
    optimizer=tf.keras.optimizers.Adam(learning_rate=1e-3),
    loss=tf.keras.losses.SparseCategoricalCrossentropy(),
    metrics=[tf.keras.metrics.SparseCategoricalAccuracy()]
)

# 回调（Callbacks）
callbacks = [
    tf.keras.callbacks.EarlyStopping(
        monitor='val_loss', patience=5, restore_best_weights=True
    ),
    tf.keras.callbacks.ReduceLROnPlateau(
        monitor='val_loss', factor=0.5, patience=3, min_lr=1e-6
    ),
    tf.keras.callbacks.ModelCheckpoint(
        filepath='checkpoints/model_{epoch:02d}_{val_loss:.4f}.h5',
        save_best_only=True,
        monitor='val_loss'
    ),
    tf.keras.callbacks.TensorBoard(
        log_dir='logs/', histogram_freq=1
    ),
]

history = model.fit(
    train_dataset,
    epochs=50,
    validation_data=val_dataset,
    callbacks=callbacks
)
```

### 1.2 自定义训练循环（Custom Training Loop）

适用于需要精细控制训练过程的场景（GAN、元学习、强化学习等）：

```python
import tensorflow as tf

model = build_model(784, 10)
optimizer = tf.keras.optimizers.Adam(1e-3)
loss_fn = tf.keras.losses.SparseCategoricalCrossentropy()

# 指标跟踪
train_loss = tf.keras.metrics.Mean(name='train_loss')
train_accuracy = tf.keras.metrics.SparseCategoricalAccuracy(name='train_accuracy')
val_loss = tf.keras.metrics.Mean(name='val_loss')
val_accuracy = tf.keras.metrics.SparseCategoricalAccuracy(name='val_accuracy')

@tf.function  # 编译为图以提升性能
def train_step(x, y):
    with tf.GradientTape() as tape:
        predictions = model(x, training=True)
        loss = loss_fn(y, predictions)
        # 加入 L2 正则化损失
        loss += sum(model.losses)
    gradients = tape.gradient(loss, model.trainable_variables)
    # 梯度裁剪（防止梯度爆炸）
    gradients, _ = tf.clip_by_global_norm(gradients, clip_norm=1.0)
    optimizer.apply_gradients(zip(gradients, model.trainable_variables))
    train_loss.update_state(loss)
    train_accuracy.update_state(y, predictions)

@tf.function
def val_step(x, y):
    predictions = model(x, training=False)
    loss = loss_fn(y, predictions)
    val_loss.update_state(loss)
    val_accuracy.update_state(y, predictions)

# 训练循环
for epoch in range(50):
    train_loss.reset_state()
    train_accuracy.reset_state()
    val_loss.reset_state()
    val_accuracy.reset_state()

    for x_batch, y_batch in train_dataset:
        train_step(x_batch, y_batch)

    for x_val, y_val in val_dataset:
        val_step(x_val, y_val)

    print(f"Epoch {epoch+1}: "
          f"Loss={train_loss.result():.4f}, "
          f"Acc={train_accuracy.result():.4f}, "
          f"Val Loss={val_loss.result():.4f}, "
          f"Val Acc={val_accuracy.result():.4f}")
```

## 2. tf.data 流水线最佳实践

### 2.1 性能优化原则

```
原则：让 CPU 预处理与 GPU 计算并行，消除 I/O 等待

[非优化流水线]
读磁盘 → 处理 → 训练 → 读磁盘 → 处理 → 训练
  (每次训练必须等待前序 I/O 完成)

[优化后流水线]
读磁盘 → 处理 → ┐
读磁盘 → 处理 → ┤ prefetch → 训练
读磁盘 → 处理 → ┘           训练
  (CPU 预处理与 GPU 训练并行执行)
```

### 2.2 最佳实践代码

```python
import tensorflow as tf
AUTOTUNE = tf.data.AUTOTUNE

def build_train_pipeline(file_pattern, batch_size=32):
    # 1. 从 TFRecord 文件创建数据集
    files = tf.data.Dataset.list_files(file_pattern, shuffle=True)
    dataset = files.interleave(
        tf.data.TFRecordDataset,
        cycle_length=8,             # 并行读取 8 个文件
        num_parallel_calls=AUTOTUNE
    )

    # 2. 解析 TFRecord
    def parse_example(serialized):
        features = tf.io.parse_single_example(serialized, {
            'image': tf.io.FixedLenFeature([], tf.string),
            'label': tf.io.FixedLenFeature([], tf.int64),
        })
        image = tf.io.decode_jpeg(features['image'], channels=3)
        image = tf.image.resize(image, [224, 224])
        return image, features['label']

    # 3. 数据增强
    def augment(image, label):
        image = tf.image.random_flip_left_right(image)
        image = tf.image.random_brightness(image, 0.2)
        image = tf.image.random_contrast(image, 0.8, 1.2)
        image = tf.cast(image, tf.float32) / 255.0
        return image, label

    dataset = (dataset
        .map(parse_example, num_parallel_calls=AUTOTUNE)   # 并行解析
        .cache()                    # 缓存解析后的数据到内存（适合中小数据集）
        .shuffle(buffer_size=1000)  # 随机打乱
        .batch(batch_size, drop_remainder=True)             # 批次化
        .map(augment, num_parallel_calls=AUTOTUNE)          # 批次级增强
        .prefetch(AUTOTUNE)         # 预取下一批次，与 GPU 计算并行
    )
    return dataset

# 注意：cache() 放置位置影响性能
# .cache() 在 .map(expensive_decode) 之后：解码结果缓存
# .cache() 在 .batch() 之前：批次前缓存，灵活性更高
```

### 2.3 大规模数据集处理

```python
# 当数据集过大无法全部缓存时，使用 tf.io.TFRecordWriter 预处理
def write_tfrecord(images, labels, output_path):
    with tf.io.TFRecordWriter(output_path) as writer:
        for image, label in zip(images, labels):
            feature = {
                'image': tf.train.Feature(
                    bytes_list=tf.train.BytesList(value=[image.tobytes()])
                ),
                'label': tf.train.Feature(
                    int64_list=tf.train.Int64List(value=[label])
                ),
            }
            example = tf.train.Example(
                features=tf.train.Features(feature=feature)
            )
            writer.write(example.SerializeToString())
```

## 3. 分布式训练策略

### 3.1 策略对比

| 策略 | 适用场景 | 通信方式 | 参数存储 |
|------|---------|---------|---------|
| `MirroredStrategy` | 单机多 GPU | All-Reduce（NCCL） | 每卡一份 |
| `MultiWorkerMirroredStrategy` | 多机多 GPU | All-Reduce（CollectiveOps） | 每卡一份 |
| `TPUStrategy` | Cloud TPU Pod | All-Reduce（TPU 互联） | 每核一份 |
| `ParameterServerStrategy` | 异步大规模训练 | Push/Pull | 参数服务器 |
| `CentralStorageStrategy` | 单机，内存受限 | Broadcast/Reduce | CPU 一份 |

### 3.2 单机多 GPU（MirroredStrategy）

```python
strategy = tf.distribute.MirroredStrategy(
    devices=["/GPU:0", "/GPU:1", "/GPU:2", "/GPU:3"]
)
print(f"并行副本数: {strategy.num_replicas_in_sync}")

with strategy.scope():
    model = build_model()
    model.compile(
        optimizer=tf.keras.optimizers.Adam(
            # 线性学习率缩放：单卡 lr × 副本数
            learning_rate=1e-3 * strategy.num_replicas_in_sync
        ),
        loss='sparse_categorical_crossentropy',
        metrics=['accuracy']
    )

# 注意：batch_size 是全局 batch size，每卡实际收到 batch_size/num_replicas
GLOBAL_BATCH_SIZE = 32 * strategy.num_replicas_in_sync
train_dataset = build_train_pipeline('train-*.tfrecord', GLOBAL_BATCH_SIZE)
model.fit(train_dataset, epochs=10)
```

### 3.4 自定义分布式训练循环

```python
strategy = tf.distribute.MirroredStrategy()

with strategy.scope():
    model = build_model()
    optimizer = tf.keras.optimizers.Adam(1e-3)
    loss_fn = tf.keras.losses.SparseCategoricalCrossentropy(
        reduction=tf.keras.losses.Reduction.NONE  # 不自动归约
    )

def compute_loss(labels, predictions, global_batch_size):
    per_example_loss = loss_fn(labels, predictions)
    # 手动做全局平均（而非 per-replica 平均）
    return tf.nn.compute_average_loss(
        per_example_loss, global_batch_size=global_batch_size
    )

@tf.function
def distributed_train_step(dist_inputs):
    def step_fn(inputs):
        x, y = inputs
        with tf.GradientTape() as tape:
            predictions = model(x, training=True)
            loss = compute_loss(y, predictions, GLOBAL_BATCH_SIZE)
        gradients = tape.gradient(loss, model.trainable_variables)
        optimizer.apply_gradients(zip(gradients, model.trainable_variables))
        return loss

    per_replica_losses = strategy.run(step_fn, args=(dist_inputs,))
    return strategy.reduce(tf.distribute.ReduceOp.SUM,
                           per_replica_losses, axis=None)
```

### 4.3 知识蒸馏（Knowledge Distillation）

```python
class DistillationModel(tf.keras.Model):
    def __init__(self, student, teacher):
        super().__init__()
        self.student = student
        self.teacher = teacher

    def compile(self, optimizer, metrics, student_loss_fn,
                distillation_loss_fn, alpha=0.1, temperature=3):
        super().compile(optimizer=optimizer, metrics=metrics)
        self.student_loss_fn = student_loss_fn
        self.distillation_loss_fn = distillation_loss_fn
        self.alpha = alpha
        self.temperature = temperature

    def train_step(self, data):
        x, y = data
        teacher_predictions = self.teacher(x, training=False)

        with tf.GradientTape() as tape:
            student_predictions = self.student(x, training=True)
            # 硬标签损失
            student_loss = self.student_loss_fn(y, student_predictions)
            # 软标签损失（蒸馏损失）
            distillation_loss = self.distillation_loss_fn(
                tf.nn.softmax(teacher_predictions / self.temperature, axis=1),
                tf.nn.softmax(student_predictions / self.temperature, axis=1),
            ) * self.temperature ** 2
            # 组合损失
            loss = self.alpha * student_loss + (1 - self.alpha) * distillation_loss

        gradients = tape.gradient(loss, self.student.trainable_variables)
        self.optimizer.apply_gradients(
            zip(gradients, self.student.trainable_variables)
        )
        return {"student_loss": student_loss, "distillation_loss": distillation_loss}
```

## 5. SavedModel 与签名设计

### 5.1 定义服务签名

```python
class MyModel(tf.keras.Model):
    @tf.function(input_signature=[
        tf.TensorSpec(shape=[None, 224, 224, 3], dtype=tf.float32,
                      name='image_input')
    ])
    def serve(self, image_input):
        predictions = self(image_input, training=False)
        class_ids = tf.argmax(predictions, axis=-1)
        probabilities = tf.reduce_max(predictions, axis=-1)
        return {
            'class_ids': class_ids,
            'probabilities': probabilities,
            'predictions': predictions
        }

model = MyModel()
# ... 训练 ...

# 保存带签名的 SavedModel
tf.saved_model.save(
    model,
    'saved_model/',
    signatures={
        'serving_default': model.serve.get_concrete_function()
    }
)

# 验证签名
loaded = tf.saved_model.load('saved_model/')
infer = loaded.signatures['serving_default']
print(infer.structured_input_signature)   # 检查输入签名
print(infer.structured_outputs)           # 检查输出签名
```

### 常见性能问题排查

| 问题现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| GPU 利用率低（<50%） | 数据预处理瓶颈 | 增加 `prefetch(AUTOTUNE)`，启用 `cache()` |
| 内存不足 OOM | batch_size 过大 | 缩小 batch，使用梯度累积 |
| 训练速度慢 | `@tf.function` 未使用 | 对 train_step 加 `@tf.function` |
| 每 epoch 耗时不稳 | shuffle buffer 太小 | 增大 shuffle buffer_size |
| 多 GPU 利用率不均 | 数据分发瓶颈 | 使用 `distribute.Strategy` 的 dataset 分发 |

### 8.1 模型版本管理

```
版本策略：

    }
```

### 8.2 A/B 测试配置

```bash
# TF Serving 支持流量分流（通过 Istio/Nginx 等网关实现）
# 也可使用 TF Serving 的多版本服务 + 应用层分流

# 应用层分流示例
import random

def predict_with_ab_test(input_data, traffic_split=0.1):
    """10% 流量发送到新模型版本"""
    if random.random() < traffic_split:
        model_version = 2  # 新版本
        endpoint = 'http://localhost:8501/v1/models/my_model/versions/2:predict'
    else:
        model_version = 1  # 当前版本
        endpoint = 'http://localhost:8501/v1/models/my_model/versions/1:predict'

    response = requests.post(endpoint, json={"instances": input_data})
    # 记录版本信息用于后续分析
    log_prediction(model_version, input_data, response.json())
    return response.json()
```
