## 1. 什么是动态规划？

### 1.1 从一个简单问题说起

**问题**：爬楼梯。你在楼梯底部，要到达第 n 级台阶，每次可以爬 1 级或 2 级。有多少种不同的爬法？

**暴力递归**：要爬到第 n 级，要么从第 n-1 级爬 1 步上来，要么从第 n-2 级爬 2 步上来。

```
f(n) = f(n-1) + f(n-2)
```

但暴力递归会重复计算大量子问题：

```
                    f(5)
                   /    \
                f(4)     f(3)
               /   \     /   \
            f(3)  f(2) f(2)  f(1)    ← f(3) 和 f(2) 被重复计算！
           /   \
        f(2)  f(1)
```

**动态规划的核心**：把已经计算过的子问题结果存起来（记忆化），避免重复计算。

### 1.2 生活类比

**DP 就像"做笔记"**：

考试时遇到一道计算题，中间需要算 `37 × 48`。如果你计算一次后把结果写在草稿纸上，下次需要这个结果时直接查，就比重新算快得多。**动态规划就是把子问题的答案记在"草稿纸"（数组/表格）上。**

### 1.3 DP 的两个前提条件

| 条件           | 含义                             | 类比                                                         |
| -------------- | -------------------------------- | ------------------------------------------------------------ |
| **最优子结构** | 大问题的最优解包含子问题的最优解 | 北京到上海的最短路经过南京，那北京到南京的那段也必须是最短的 |
| **重叠子问题** | 不同的决策路径会遇到相同的子问题 | 不同楼层的爬法都需要知道更低楼层的爬法数                     |

### 1.4 自顶向下 vs 自底向上

```python
# 方法 1：自顶向下（记忆化递归）
def climb_top_down(n, memo={}):
    if n <= 2: return n
    if n in memo: return memo[n]
    memo[n] = climb_top_down(n-1, memo) + climb_top_down(n-2, memo)
    return memo[n]

# 方法 2：自底向上（迭代 DP）
def climb_bottom_up(n):
    if n <= 2: return n
    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2
    for i in range(3, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]

# 方法 3：空间优化（滚动变量）
def climb_optimized(n):
    if n <= 2: return n
    prev2, prev1 = 1, 2
    for i in range(3, n + 1):
        prev2, prev1 = prev1, prev2 + prev1
    return prev1
```

## 2. DP 解题框架

### 万能五步法

遇到任何 DP 问题，按这五步推导：

```
第 1 步：定义状态 → dp[i] 或 dp[i][j] 的含义是什么？
第 2 步：状态转移方程 → dp[i] 怎么从之前的状态推导出来？
第 3 步：初始化 → dp[0]、dp[1] 等基础情况的值是什么？
第 4 步：遍历顺序 → 从前往后？从后往前？先行后列？
第 5 步：举例推导 → 手算一个小例子验证方程是否正确
```

**关键心法**：定义好状态是 DP 最难的一步。一旦状态定义好了，转移方程往往自然浮现。

## 3. 一维 DP 经典问题

### 3.1 打家劫舍（House Robber）

**问题**：一排房屋，每间有不同金额。相邻两间不能同时偷。求能偷到的最大金额。

**五步法**：

```
1. 状态定义：dp[i] = 考虑前 i 间房屋能获得的最大金额
2. 转移方程：dp[i] = max(dp[i-1], dp[i-2] + nums[i])
   - 不偷第 i 间：dp[i-1]
   - 偷第 i 间：dp[i-2] + nums[i]（跳过第 i-1 间）
3. 初始化：dp[0] = nums[0], dp[1] = max(nums[0], nums[1])
4. 遍历方向：从左到右（i=2 到 n-1）
5. 验证：nums=[2,7,9,3,1] → dp=[2,7,11,11,12] → 答案 12
```

```python
def rob(nums):
    if len(nums) <= 2:
        return max(nums) if nums else 0
    dp = [0] * len(nums)
    dp[0], dp[1] = nums[0], max(nums[0], nums[1])
    for i in range(2, len(nums)):
        dp[i] = max(dp[i-1], dp[i-2] + nums[i])
    return dp[-1]
```

### 3.2 最长递增子序列（LIS）

**问题**：在数组 [10, 9, 2, 5, 3, 7, 101, 18] 中找最长递增子序列的长度。

**O(n²) DP 解法**：

```
状态：dp[i] = 以 nums[i] 结尾的 LIS 长度
转移：dp[i] = max(dp[j] + 1) for all j < i where nums[j] < nums[i]
初始化：每个位置至少是自身，dp[i] = 1
```

```python
def length_of_lis(nums):
    dp = [1] * len(nums)
    for i in range(1, len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)  # [1,1,1,2,2,3,4,4] → 答案 4（子序列 [2,3,7,101]）
```

> O(n log n) 的优化解法见排序与搜索章节的 tails 数组 + 二分搜索方法。

### 3.3 最大子数组和（Kadane's Algorithm）

```
状态：dp[i] = 以 nums[i] 结尾的最大子数组和
转移：dp[i] = max(nums[i], dp[i-1] + nums[i])
       要么从 nums[i] 重新开始，要么续上之前的和
```

```python
def max_subarray(nums):
    max_sum = current = nums[0]
    for num in nums[1:]:
        current = max(num, current + num)
        max_sum = max(max_sum, current)
    return max_sum
```

## 4. 二维 DP 经典问题

### 4.1 最长公共子序列（LCS）

**问题**：找出 "ABCBDAB" 和 "BDCABA" 的最长公共子序列。

**状态定义**：`dp[i][j]` = text1 前 i 个字符和 text2 前 j 个字符的 LCS 长度。

```
转移方程：
  如果 text1[i-1] == text2[j-1]:
    dp[i][j] = dp[i-1][j-1] + 1    ← 两个字符匹配，LCS 长度 +1
  否则:
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])  ← 取跳过任一字符的较大值
```

```
        ""  B  D  C  A  B  A
    ""   0  0  0  0  0  0  0
    A    0  0  0  0  1  1  1
    B    0  1  1  1  1  2  2
    C    0  1  1  2  2  2  2
    B    0  1  1  2  2  3  3
    D    0  1  2  2  2  3  3
    A    0  1  2  2  3  3  4
    B    0  1  2  2  3  4  4

    LCS 长度 = 4（"BCBA"）
```

```python
def lcs(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i-1] == text2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]
```

### 4.2 编辑距离（Edit Distance）

**问题**：将 "horse" 变成 "ros" 最少需要几次操作（插入/删除/替换）？

```
状态：dp[i][j] = word1 前 i 个字符变成 word2 前 j 个字符的最少操作次数
转移：
  如果 word1[i-1] == word2[j-1]:
    dp[i][j] = dp[i-1][j-1]        ← 字符相同，不需要操作
  否则:
    dp[i][j] = 1 + min(
      dp[i-1][j],    ← 删除 word1[i-1]
      dp[i][j-1],    ← 插入 word2[j-1]
      dp[i-1][j-1]   ← 替换 word1[i-1] → word2[j-1]
    )
```

```python
def min_distance(word1, word2):
    m, n = len(word1), len(word2)
    dp = [[0] * (n+1) for _ in range(m+1)]
    for i in range(m+1): dp[i][0] = i  # 全删除
    for j in range(n+1): dp[0][j] = j  # 全插入
    for i in range(1, m+1):
        for j in range(1, n+1):
            if word1[i-1] == word2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
    return dp[m][n]
```

**实战应用**：拼写纠错、DNA 序列比对、Git diff 算法。

## 5. 背包问题系列

### 5.1 0-1 背包

**类比**：你去野外露营，背包最多装 W 公斤。每件装备有重量和价值，每件只能带或不带（不能切割），怎么装让总价值最大？

```
状态：dp[i][w] = 考虑前 i 件物品、容量为 w 时的最大价值
转移：dp[i][w] = max(
    dp[i-1][w],              ← 不选第 i 件
    dp[i-1][w-weight[i]] + value[i]  ← 选第 i 件（前提：w >= weight[i]）
  )
```

```python
def knapsack_01(weights, values, capacity):
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for w in range(capacity + 1):
            dp[i][w] = dp[i-1][w]  # 不选
            if w >= weights[i-1]:
                dp[i][w] = max(dp[i][w], dp[i-1][w-weights[i-1]] + values[i-1])
    return dp[n][capacity]
```

**空间优化**：逆序遍历 w 可以压缩到一维数组：

```python
def knapsack_01_optimized(weights, values, capacity):
    dp = [0] * (capacity + 1)
    for i in range(len(weights)):
        for w in range(capacity, weights[i] - 1, -1):  # 逆序！
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
    return dp[capacity]
```

### 5.2 完全背包

每件物品可以无限次选取。只需将遍历顺序从逆序改为正序：

```python
def knapsack_complete(weights, values, capacity):
    dp = [0] * (capacity + 1)
    for i in range(len(weights)):
        for w in range(weights[i], capacity + 1):  # 正序！（允许重复选）
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
    return dp[capacity]
```

**为什么正序 = 完全背包？** 因为正序遍历时，dp[w - weight[i]] 可能已经包含了物品 i，等于允许重复选。

### 5.3 背包问题变体

| 变体     | 关键区别        | 经典例题               |
| -------- | --------------- | ---------------------- |
| 0-1 背包 | 每件最多选 1 次 | 分割等和子集           |
| 完全背包 | 每件可选无限次  | 零钱兑换               |
| 多重背包 | 每件有数量限制  | 物品有库存限制         |
| 分组背包 | 每组最多选一件  | 课程选修（每组选一门） |

## 6. 区间 DP 与树形 DP

### 6.1 区间 DP

#### 核心思想

**类比**：想象你手上有一串珠子，每次合并相邻两颗珠子会产生一定的分数。你需要找到合并所有珠子的最优顺序——这就是区间 DP 的典型场景。

区间 DP 的特征：

- 在一个**线性序列**上操作
- 操作的对象是**连续的子区间**
- 大区间的最优解依赖于**子区间**的最优解

**通用模板**：

```python
# 区间 DP 通用框架
for length in range(2, n + 1):        # 枚举区间长度
    for i in range(n - length + 1):   # 枚举左端点
        j = i + length - 1            # 右端点
        for k in range(i, j):         # 枚举分割点
            dp[i][j] = optimal(dp[i][j], dp[i][k] + dp[k+1][j] + cost(i, j, k))
```

**关键点**：枚举顺序必须保证计算 `dp[i][j]` 时，所有更短的子区间已经计算完毕。

#### 经典问题 1：矩阵链乘法

**问题**：给定 n 个矩阵 A₁(p₀×p₁), A₂(p₁×p₂), ..., Aₙ(pₙ₋₁×pₙ)，找到最优的括号化方式使得标量乘法次数最少。

**为什么顺序很重要？** 假设有三个矩阵 A(10×30)、B(30×5)、C(5×60)：

- `(AB)C`：10×30×5 + 10×5×60 = 1500 + 3000 = **4500** 次
- `A(BC)`：30×5×60 + 10×30×60 = 9000 + 18000 = **27000** 次

同样的矩阵，不同的计算顺序差了 **6 倍**！

```
五步法：
1. 状态：dp[i][j] = 计算矩阵 Aᵢ 到 Aⱼ 的最少乘法次数
2. 转移：dp[i][j] = min(dp[i][k] + dp[k+1][j] + p[i-1]*p[k]*p[j])
         其中 k 从 i 到 j-1
3. 初始化：dp[i][i] = 0（单个矩阵不需要乘法）
4. 遍历：按区间长度从小到大
5. 验证：p = [10, 30, 5, 60] → dp[1][3] = 4500
```

```python
def matrix_chain_order(p):
    """矩阵链乘法 - 区间 DP"""
    n = len(p) - 1  # 矩阵个数
    dp = [[0] * n for _ in range(n)]

    # 按区间长度枚举
    for length in range(2, n + 1):          # 区间长度 2 到 n
        for i in range(n - length + 1):     # 左端点
            j = i + length - 1               # 右端点
            dp[i][j] = float('inf')
            for k in range(i, j):            # 分割点
                cost = dp[i][k] + dp[k+1][j] + p[i] * p[k+1] * p[j+1]
                dp[i][j] = min(dp[i][j], cost)

    return dp[0][n-1]

# 验证
print(matrix_chain_order([10, 30, 5, 60]))  # 输出 4500
```

#### 经典问题 2：戳气球

**问题**（LeetCode 312）：一排气球编号 0~n-1，戳破第 i 个气球得分为 `nums[left] × nums[i] × nums[right]`，求最大总分。

**关键洞察**：正向思考（先戳哪个）会导致边界不断变化，非常复杂。**逆向思考**——假设第 k 个气球是区间 (i, j) 中**最后一个**被戳的，那么戳它时左右邻居一定是 i 和 j。

```
思路转换：
  正向：先戳 i，边界立刻变化 → 难以建模
  逆向：区间 (i,j) 中最后戳 k → 此时 k 的邻居确定为 i 和 j → 完美建模！

状态：dp[i][j] = 戳破 (i, j) 开区间内所有气球能获得的最大分数
转移：dp[i][j] = max(dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j])
      枚举 k ∈ (i+1, ..., j-1) 作为最后一个被戳的气球
初始化：在原数组两端添加虚拟气球 nums = [1] + nums + [1]
```

```python
def max_coins(nums):
    """戳气球 - 区间 DP 经典"""
    nums = [1] + nums + [1]  # 添加虚拟边界
    n = len(nums)
    dp = [[0] * n for _ in range(n)]

    for length in range(2, n):              # 区间长度（开区间，至少间隔 2）
        for i in range(n - length):         # 左端点
            j = i + length                  # 右端点
            for k in range(i + 1, j):       # 最后一个戳的气球
                score = nums[i] * nums[k] * nums[j]
                dp[i][j] = max(dp[i][j], dp[i][k] + dp[k][j] + score)

    return dp[0][n - 1]

# 验证：nums = [3,1,5,8]
# 最优顺序：戳1(3×1×5=15) → 戳5(3×5×8=120) → 戳3(1×3×8=24) → 戳8(1×8×1=8) = 167
print(max_coins([3, 1, 5, 8]))  # 输出 167
```

#### 经典问题 3：最长回文子序列

```python
def longest_palindrome_subseq(s):
    """
    状态：dp[i][j] = s[i..j] 的最长回文子序列长度
    转移：s[i]==s[j] → dp[i][j] = dp[i+1][j-1] + 2
          s[i]!=s[j] → dp[i][j] = max(dp[i+1][j], dp[i][j-1])
    """
    n = len(s)
    dp = [[0] * n for _ in range(n)]
    for i in range(n):
        dp[i][i] = 1  # 单个字符是长度 1 的回文

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j]:
                dp[i][j] = dp[i+1][j-1] + 2
            else:
                dp[i][j] = max(dp[i+1][j], dp[i][j-1])

    return dp[0][n-1]
```

### 6.2 树形 DP

#### 核心思想

**类比**：想象一家公司的组织架构图，每个员工有一个"快乐指数"。公司规定：如果一个人参加聚会，他的直接下属就不会参加（谁愿意和领导一起 happy？）。怎么选人让总快乐指数最大？——这就是经典的**树形 DP（派对问题）**。

树形 DP 的特征：

- 数据结构是**树**（通常是有根树）
- 使用 **DFS 后序遍历**——先计算所有子节点，再计算父节点
- 每个节点的状态由其子节点的状态决定

#### 经典问题 1：打家劫舍 III（LeetCode 337）

**问题**：小偷发现一个社区的房屋结构形成一棵二叉树。相连的两间房屋不能同时偷（父-子关系 = 相连）。

```
     3
    / \
   2   3
    \   \
     3   1

不偷根节点：2 + 3 + 3 + 1 = 9？不对——2 和它的子节点 3 也不能同时偷
偷根节点 3：3 + 3 + 1 = 7
不偷根节点：max(偷2的子树, 不偷2的子树) + max(偷3的子树, 不偷3的子树)
```

**状态设计**：每个节点返回两个值 `(rob, not_rob)`

- `rob`：偷当前节点能得到的最大值
- `not_rob`：不偷当前节点能得到的最大值

```python
def rob_tree(root):
    """打家劫舍 III - 树形 DP"""
    def dfs(node):
        if not node:
            return (0, 0)  # (偷, 不偷)

        left = dfs(node.left)
        right = dfs(node.right)

        # 偷当前节点：子节点都不能偷
        rob = node.val + left[1] + right[1]
        # 不偷当前节点：子节点可偷可不偷，取最大值
        not_rob = max(left) + max(right)

        return (rob, not_rob)

    return max(dfs(root))
```

#### 经典问题 2：树的直径

**问题**：求树中任意两节点之间的最长路径（边数）。

**关键洞察**：对于每个节点，经过它的最长路径 = 左子树深度 + 右子树深度。树的直径就是所有节点中这个值的最大值。

```python
def diameter_of_binary_tree(root):
    """树的直径 - 树形 DP"""
    diameter = 0

    def depth(node):
        nonlocal diameter
        if not node:
            return 0
        left_depth = depth(node.left)
        right_depth = depth(node.right)
        # 经过当前节点的最长路径
        diameter = max(diameter, left_depth + right_depth)
        return max(left_depth, right_depth) + 1

    depth(root)
    return diameter
```

#### 经典问题 3：树的最大路径和（LeetCode 124）

```python
def max_path_sum(root):
    """
    每个节点计算两个值：
    1. 包含该节点的单侧最大路径（向上传递给父节点）
    2. 经过该节点的完整路径（更新全局最大值）
    """
    max_sum = float('-inf')

    def dfs(node):
        nonlocal max_sum
        if not node:
            return 0
        # 左右子树的最大贡献（负数则不取）
        left_gain = max(dfs(node.left), 0)
        right_gain = max(dfs(node.right), 0)
        # 经过当前节点的完整路径
        max_sum = max(max_sum, node.val + left_gain + right_gain)
        # 向上传递：只能选一侧
        return node.val + max(left_gain, right_gain)

    dfs(root)
    return max_sum
```

#### 树形 DP 的一般模式

```python
def tree_dp(root):
    """树形 DP 通用模板"""
    def dfs(node):
        if not node:
            return BASE_CASE

        # 1. 先递归处理所有子节点
        left_result = dfs(node.left)
        right_result = dfs(node.right)

        # 2. 利用子节点结果计算当前节点
        current_result = combine(node.val, left_result, right_result)

        # 3. 可选：更新全局答案
        update_global_answer(current_result)

        # 4. 返回给父节点使用的值
        return current_result

    dfs(root)
```

## 7. 状态压缩 DP

### 7.1 为什么需要状态压缩？

**类比**：假设你要计划一次公路旅行，要访问 15 个城市。你需要记录"已经去过哪些城市"这个状态。用数组记录？15 个元素的布尔数组不方便做 DP 的键。用**一个整数的二进制位**来表示？一个 15 位的整数（0 到 32767）就够了！

**核心思想**：用一个整数的**二进制表示**来编码集合状态，每一位代表一个元素是否在集合中。

```
城市 0 1 2 3 4
状态 = 0b10110 = 22  表示访问了城市 1, 2, 4

常用位运算：
  检查第 i 位：    mask & (1 << i)       # 非零则在集合中
  设置第 i 位：    mask | (1 << i)       # 添加元素 i
  清除第 i 位：    mask & ~(1 << i)      # 移除元素 i
  枚举子集：      sub = mask; while sub: sub = (sub - 1) & mask
  集合大小：      bin(mask).count('1')
```

### 7.2 经典问题：旅行商问题（TSP）

**问题**：从城市 0 出发，访问所有 n 个城市恰好一次并返回起点，求最短路径。

**暴力解法**：枚举所有排列 → O(n!)，n=20 时约 2.4×10¹⁸，不可行。

**状态压缩 DP**：

```
状态：dp[mask][i] = 已访问城市集合为 mask，当前在城市 i 的最短路径长度
转移：dp[mask | (1<<j)][j] = min(dp[mask][i] + dist[i][j])
      条件：j 不在 mask 中（还没访问过）
初始化：dp[1][0] = 0（只访问了城市 0，在城市 0，路径长度 0）
答案：min(dp[(1<<n)-1][i] + dist[i][0])  对所有 i
```

```python
def tsp(dist):
    """旅行商问题 - 状态压缩 DP"""
    n = len(dist)
    INF = float('inf')
    # dp[mask][i]: 已访问集合 mask，当前在城市 i 的最短路径
    dp = [[INF] * n for _ in range(1 << n)]
    dp[1][0] = 0  # 起始：只访问了城市 0

    for mask in range(1 << n):
        for i in range(n):
            if dp[mask][i] == INF:
                continue
            if not (mask & (1 << i)):  # 当前城市 i 必须在 mask 中
                continue
            for j in range(n):
                if mask & (1 << j):    # 城市 j 已经访问过，跳过
                    continue
                new_mask = mask | (1 << j)
                dp[new_mask][j] = min(dp[new_mask][j], dp[mask][i] + dist[i][j])

    # 最终：所有城市都访问了，加上返回起点的距离
    full_mask = (1 << n) - 1
    return min(dp[full_mask][i] + dist[i][0] for i in range(n))

# 验证
dist = [
    [0, 10, 15, 20],
    [10, 0, 35, 25],
    [15, 35, 0, 30],
    [20, 25, 30, 0]
]
print(tsp(dist))  # 输出 80（路径 0→1→3→2→0）
```

**复杂度**：时间 O(2ⁿ × n²)，空间 O(2ⁿ × n)。n=20 时：2²⁰ × 400 ≈ 4 亿次操作，约几十秒可解。

### 7.3 经典问题：分配问题

**问题**：n 个人分配 n 个任务，每人恰好一个任务，`cost[i][j]` 是第 i 人做第 j 个任务的代价，求最小总代价。

```python
def min_cost_assignment(cost):
    """任务分配 - 状态压缩 DP"""
    n = len(cost)
    dp = [float('inf')] * (1 << n)
    dp[0] = 0

    for mask in range(1 << n):
        i = bin(mask).count('1')  # 当前分配到第 i 个人
        if i >= n:
            continue
        for j in range(n):
            if mask & (1 << j):  # 任务 j 已分配
                continue
            dp[mask | (1 << j)] = min(dp[mask | (1 << j)], dp[mask] + cost[i][j])

    return dp[(1 << n) - 1]
```

### 7.4 经典问题：铺地砖

**问题**：用 1×2 的多米诺骨牌铺满 n×m 的网格（n ≤ 12），求方案数。

用状态压缩表示每一行的"凸出状态"（哪些列被上一行的竖放骨牌占据），逐行转移。

```
n=3, m=4 的铺法示意（一种方案）：
  ┌──┬──┬──┬──┐
  │  │  │  │  │  行 0：两个横放
  ├──┼──┤  ├──┤
  │  │  │  │  │  行 1：一个横放 + 一个竖放（从行0延伸）
  ├──┤  ├──┼──┤
  │  │  │  │  │  行 2：...
  └──┴──┴──┴──┘
```

### 7.5 适用场景总结

| 场景     | 状态含义         | 典型规模  |
| -------- | ---------------- | --------- |
| 集合选择 | 哪些元素已被选中 | n ≤ 20    |
| 排列问题 | 哪些位置已被占用 | n ≤ 20    |
| 棋盘问题 | 一行的放置状态   | 行长 ≤ 20 |
| 图上路径 | 已访问节点集合   | 节点 ≤ 20 |

## 8. DP 优化技巧

### 8.1 空间优化

#### 滚动数组

如果 `dp[i]` 只依赖 `dp[i-1]`，可以用两行交替使用，将 O(n×m) 空间降为 O(m)。

```python
# 原始：O(n*m) 空间
dp = [[0] * m for _ in range(n)]
for i in range(1, n):
    for j in range(m):
        dp[i][j] = f(dp[i-1][j], dp[i-1][j-1])

# 优化：O(m) 空间，用两行交替
prev = [0] * m
curr = [0] * m
for i in range(1, n):
    for j in range(m):
        curr[j] = f(prev[j], prev[j-1])
    prev, curr = curr, prev  # 交换引用，零拷贝
```

#### 一维压缩（背包技巧）

```python
# 0-1 背包：逆序遍历（每件物品最多选一次）
for i in range(n):
    for w in range(capacity, weights[i] - 1, -1):  # ← 逆序
        dp[w] = max(dp[w], dp[w - weights[i]] + values[i])

# 完全背包：正序遍历（每件物品可无限选）
for i in range(n):
    for w in range(weights[i], capacity + 1):       # ← 正序
        dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
```

**为什么逆序 = 0-1 背包？** 逆序遍历时，`dp[w - weights[i]]` 还是上一轮（不含物品 i）的值，确保每件物品只选一次。正序遍历时，`dp[w - weights[i]]` 可能已经包含了物品 i，等于允许重复选。

### 8.2 单调队列优化

#### 适用场景

当转移方程形如：

```
dp[i] = min/max(dp[j] + cost(j, i))，其中 j 的范围是一个滑动窗口
```

朴素 O(n²) 可以用**单调队列**（双端队列）优化到 O(n)。

#### 经典问题：滑动窗口最大值（LeetCode 239）

**问题**：给定数组和窗口大小 k，求每个窗口中的最大值。

```python
from collections import deque

def max_sliding_window(nums, k):
    """单调递减队列 - 队头始终是当前窗口最大值"""
    dq = deque()  # 存索引，保持对应值单调递减
    result = []

    for i in range(len(nums)):
        # 移除超出窗口的元素
        while dq and dq[0] < i - k + 1:
            dq.popleft()
        # 移除所有比当前值小的元素（它们不可能成为最大值了）
        while dq and nums[dq[-1]] <= nums[i]:
            dq.pop()
        dq.append(i)
        # 窗口形成后开始记录结果
        if i >= k - 1:
            result.append(nums[dq[0]])

    return result
```

#### 跳跃游戏变体的 DP 优化

```
原始：dp[i] = min(dp[j]) + 1，j ∈ [i-k, i-1]
朴素：O(nk)，双重循环
优化：用单调队列维护窗口 [i-k, i-1] 的最小值 → O(n)
```

### 8.3 单调栈优化

**适用于**：需要找每个元素左边/右边第一个更大/更小的元素。

#### 经典问题：柱状图最大矩形（LeetCode 84）

```python
def largest_rectangle_area(heights):
    """每个柱子向左右扩展，找到第一个比它矮的柱子"""
    stack = []  # 单调递增栈
    max_area = 0
    heights.append(0)  # 哨兵，确保最后都能出栈

    for i, h in enumerate(heights):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)

    return max_area
```

### 8.4 斜率优化（进阶）

当转移方程可以变形为：

```
dp[i] = min(dp[j] + a[i]*b[j] + c[i] + d[j])
```

其中 a、b、c、d 是只与 i 或 j 有关的函数，可以将其转化为**凸包上的直线查询**问题，用单调队列维护下凸壳，实现 O(n) 转移。

这是竞赛中常见的高级技巧，一般面试不要求掌握，了解即可。

### 8.5 常见 DP 问题分类速查

| 问题类型 | 代表题目                     | 状态设计                         | 时间复杂度   |
| -------- | ---------------------------- | -------------------------------- | ------------ |
| 线性 DP  | 爬楼梯/打家劫舍/LIS          | dp[i] = 以 i 结尾的最优解        | O(n) ~ O(n²) |
| 二维 DP  | LCS/编辑距离/网格路径        | dp[i][j] = 前 i/j 的最优解       | O(nm)        |
| 背包 DP  | 0-1 背包/零钱兑换/分割子集   | dp[w] = 容量 w 下的最优解        | O(nW)        |
| 区间 DP  | 戳气球/矩阵链乘法/回文子序列 | dp[i][j] = 区间 [i,j] 最优解     | O(n³)        |
| 树形 DP  | 树的直径/树上打家劫舍/路径和 | dp[node] = 以 node 为根的最优解  | O(n)         |
| 状态压缩 | TSP/分配问题/铺砖            | dp[mask] = 集合 mask 下的最优解  | O(2ⁿ × n)    |
| 数位 DP  | 数字计数/特殊数字            | dp[pos][state] = 前 pos 位的方案 | O(D × S)     |

## 常见陷阱与最佳实践

1. **忘记初始化**：dp 数组的初始值要根据问题含义设置（求最小值用 ∞，求最大值用 -∞，求方案数用 0）
2. **遍历顺序错误**：0-1 背包必须逆序遍历容量，完全背包必须正序；区间 DP 必须按长度从小到大
3. **状态定义不精确**：如果 dp[i] 的含义模糊不清，转移方程一定推不出来。**写代码前先把 dp 数组的含义用一句话写清楚**
4. **没有空间优化**：面试中先写清楚的二维 DP，再优化为一维展示功底
5. **贪心 vs DP**：能用贪心就不用 DP。DP 用于贪心不成立但有最优子结构的问题
6. **边界条件**：区间 DP 注意开区间还是闭区间；树形 DP 注意空节点的返回值
7. **状态压缩的规模**：n > 20 时 2ⁿ 就已经超过 10⁶，要考虑是否真的需要状态压缩
