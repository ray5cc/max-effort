## 1. 为什么需要手写代码

### 1.1 面试中的重要性

手写代码（Live Coding）是技术面试中最核心的环节之一。它就像**驾照路考**：理论知识（数据结构、算法）是笔试，但真正能否上路开车，需要实际操作验证。

**面试官通过手写代码考察的能力：**

1. **问题理解能力**
   - 能否快速理解需求，提取关键信息
   - 能否识别边界条件和特殊情况
   - 能否提出澄清问题

2. **方案设计能力**
   - 能否选择合适的数据结构
   - 能否设计高效的算法
   - 能否权衡时间/空间复杂度

3. **编码实现能力**
   - 代码的正确性（功能完整、无bug）
   - 代码的可读性（命名清晰、结构合理）
   - 代码的健壮性（边界处理、错误处理）

4. **沟通协作能力**
   - 能否边写边讲解思路
   - 能否接受反馈并快速调整
   - 能否在压力下保持清晰思维

### 1.2 与日常开发的区别

| 维度 | 日常开发 | 面试手写代码 |
|------|----------|-------------|
| **时间** | 天/周级别 | 30-45分钟 |
| **工具** | IDE、调试器、搜索引擎 | 白板/在线编辑器（无提示） |
| **要求** | 可运行、可维护 | 快速、正确、清晰 |
| **压力** | 相对较低 | 高压环境（面试官观察） |

**类比：**

- 日常开发像**马拉松**：有充足时间优化细节
- 手写代码像**百米冲刺**：在短时间内展示核心能力

## 2. 编码题的分类与特点

### 2.1 前端编码题

**特点：**
- 侧重 DOM 操作、事件处理、异步编程
- 需要理解浏览器环境和 JavaScript 语言特性
- 常涉及设计模式和框架原理

**典型题目：**
```javascript
// 实现防抖函数
function debounce(fn, delay) {
  let timer = null;
  return function(...args) {
    if (timer) clearTimeout(timer);
    timer = setTimeout(() => {
      fn.apply(this, args);
    }, delay);
  };
}

// 实现深拷贝
function deepClone(obj, hash = new WeakMap()) {
  if (obj === null || typeof obj !== 'object') return obj;
  if (obj instanceof Date) return new Date(obj);
  if (obj instanceof RegExp) return new RegExp(obj);

  if (hash.has(obj)) return hash.get(obj);

  const clone = Array.isArray(obj) ? [] : {};
  hash.set(obj, clone);

  for (let key in obj) {
    if (obj.hasOwnProperty(key)) {
      clone[key] = deepClone(obj[key], hash);
    }
  }

  return clone;
}
```

### 2.2 后端编码题

**特点：**
- 侧重业务逻辑、并发控制、错误处理

**典型题目：**
```python
# 实现限流器（令牌桶算法）
import time
import threading

class RateLimiter:
    def __init__(self, rate, capacity):
        self.rate = rate          # 每秒生成的令牌数
        self.capacity = capacity  # 桶容量
        self.tokens = capacity    # 当前令牌数
        self.last_time = time.time()
        self.lock = threading.Lock()

    def acquire(self, tokens=1):
        with self.lock:
            now = time.time()
            # 补充令牌
            elapsed = now - self.last_time
            self.tokens = min(self.capacity, self.tokens + elapsed * self.rate)
            self.last_time = now

            # 尝试获取令牌
            if self.tokens >= tokens:
                self.tokens -= tokens
                return True
            return False
```

### 2.4 算法编码题

**特点：**
- 侧重算法思维、时间/空间复杂度优化
- 需要扎实的数据结构基础
- 常涉及动态规划、图论、搜索算法

**典型题目：**
```python
# 最长递增子序列（动态规划 + 二分查找）
def lengthOfLIS(nums):
    """
    时间复杂度：O(n log n)
    空间复杂度：O(n)
    """
    if not nums:
        return 0

    # tails[i] 表示长度为 i+1 的递增子序列的最小末尾元素
    tails = []

    for num in nums:
        # 二分查找插入位置
        left, right = 0, len(tails)
        while left < right:
            mid = (left + right) // 2
            if tails[mid] < num:
                left = mid + 1
            else:
                right = mid

        if left == len(tails):
            tails.append(num)
        else:
            tails[left] = num

    return len(tails)
```

```python
# 实现 LRU 缓存
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity: int):
        self.cache = OrderedDict()
        self.capacity = capacity

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        # 移动到末尾（最近使用）
        self.cache.move_to_end(key)
        return self.cache[key]

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            # 移除最久未使用的项（开头）
            self.cache.popitem(last=False)
```

```bash
#!/bin/bash
# 监控服务健康状态并自动重启

SERVICE_NAME="myapp"
CHECK_INTERVAL=60
MAX_RETRIES=3

check_service() {
    systemctl is-active --quiet $SERVICE_NAME
    return $?
}

restart_service() {
    echo "$(date): Service $SERVICE_NAME is down. Attempting restart..." >> /var/log/service_monitor.log
    systemctl restart $SERVICE_NAME
    sleep 5
}

while true; do
    if ! check_service; then
        retry_count=0
        while [ $retry_count -lt $MAX_RETRIES ]; do
            restart_service
            if check_service; then
                echo "$(date): Service $SERVICE_NAME restarted successfully" >> /var/log/service_monitor.log
                break
            fi
            retry_count=$((retry_count + 1))
        done

        if [ $retry_count -eq $MAX_RETRIES ]; then
            echo "$(date): CRITICAL - Failed to restart $SERVICE_NAME after $MAX_RETRIES attempts" >> /var/log/service_monitor.log
            # 发送告警
            curl -X POST "https://alert.example.com/api/notify" -d "service=$SERVICE_NAME&status=critical"
        fi
    fi
    sleep $CHECK_INTERVAL
done
```

### 2.7 AI Agent 编码题

**特点：**
- 侧重 Prompt 工程、工具调用、流式处理
- 需要理解 LLM 交互模式
- 常涉及异步处理、错误重试、上下文管理

**典型题目：**
```python
# 实现带重试的 LLM 调用包装器
import asyncio
from typing import Optional, Callable
import openai

class LLMClient:
    def __init__(self, api_key: str, model: str = "gpt-4"):
        self.client = openai.AsyncOpenAI(api_key=api_key)
        self.model = model

    async def chat_with_retry(
        self,
        messages: list,
        max_retries: int = 3,
        timeout: float = 30.0,
        on_retry: Optional[Callable] = None
    ) -> str:
        """
        带指数退避的重试机制
        """
        for attempt in range(max_retries):
            try:
                response = await asyncio.wait_for(
                    self.client.chat.completions.create(
                        model=self.model,
                        messages=messages,
                        temperature=0.7
                    ),
                    timeout=timeout
                )
                return response.choices[0].message.content

            except asyncio.TimeoutError:
                if attempt == max_retries - 1:
                    raise
                wait_time = 2 ** attempt  # 指数退避：1s, 2s, 4s
                if on_retry:
                    on_retry(attempt, "timeout")
                await asyncio.sleep(wait_time)

            except openai.RateLimitError:
                if attempt == max_retries - 1:
                    raise
                wait_time = 5 ** attempt  # 更长的退避时间
                if on_retry:
                    on_retry(attempt, "rate_limit")
                await asyncio.sleep(wait_time)

            except Exception as e:
                if attempt == max_retries - 1:
                    raise
                if on_retry:
                    on_retry(attempt, str(e))
                await asyncio.sleep(2 ** attempt)

        raise Exception("Max retries exceeded")
```

## 3. 解题方法论

### 3.1 四步解题法

```
┌─────────────┐
│ 1. 理解题意 │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 2. 设计方案 │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 3. 编码实现 │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 4. 测试验证 │
└─────────────┘
```

### 3.2 第一步：理解题意

**类比：** 像医生问诊，先搞清楚症状再开药方。

**必做事项：**

1. **复述问题**
   ```
   面试官："请实现一个函数，查找数组中第 K 大的元素"
   你："您的意思是，给定一个整数数组和整数 K，返回数组中第 K 大的数字，对吗？"
   ```

2. **确认输入输出**
   - 输入格式（数组、字符串、对象？）
   - 输入范围（数组长度、数字范围？）
   - 输出格式（返回值、原地修改、打印？）
   - 特殊情况（空输入、重复元素？）

3. **提出测试用例**
   ```python
   # 示例
   输入：nums = [3, 2, 1, 5, 6, 4], k = 2
   输出：5  # 第 2 大的元素

   # 边界
   输入：nums = [1], k = 1
   输出：1

   # 重复
   输入：nums = [3, 3, 3], k = 2
   输出：3
   ```

### 3.3 第二步：设计方案

**类比：** 像建筑设计，先画图纸再动工。

**思考流程：**

```
1. 暴力解法（Brute Force）
   ↓ 能否优化？
2. 优化数据结构（Hash、Heap、Tree）
   ↓ 能否优化算法？
3. 优化算法（双指针、滑动窗口、动态规划）
   ↓ 权衡复杂度
4. 最终方案（时间/空间平衡）
```

**示例：查找第 K 大元素**

```python
# 方案 1：排序
# 时间：O(n log n)，空间：O(1)
def findKthLargest_v1(nums, k):
    nums.sort(reverse=True)
    return nums[k-1]

# 方案 2：堆（优先队列）
# 时间：O(n log k)，空间：O(k)
import heapq
def findKthLargest_v2(nums, k):
    return heapq.nlargest(k, nums)[-1]

# 方案 3：快速选择（QuickSelect）
# 时间：O(n) 平均，空间：O(1)
def findKthLargest_v3(nums, k):
    def partition(left, right, pivot_idx):
        pivot = nums[pivot_idx]
        nums[pivot_idx], nums[right] = nums[right], nums[pivot_idx]
        store_idx = left
        for i in range(left, right):
            if nums[i] > pivot:
                nums[i], nums[store_idx] = nums[store_idx], nums[i]
                store_idx += 1
        nums[store_idx], nums[right] = nums[right], nums[store_idx]
        return store_idx

    left, right = 0, len(nums) - 1
    k_idx = k - 1

    while left <= right:
        pivot_idx = (left + right) // 2
        new_pivot_idx = partition(left, right, pivot_idx)

        if new_pivot_idx == k_idx:
            return nums[new_pivot_idx]
        elif new_pivot_idx < k_idx:
            left = new_pivot_idx + 1
        else:
            right = new_pivot_idx - 1
```

**与面试官沟通：**
```
你："我想到了三种方案：
1. 排序，时间 O(n log n)
2. 最小堆，时间 O(n log k)
3. 快速选择，平均 O(n)

您希望我实现哪一种？或者我先写最优的快速选择算法？"
```

### 3.4 第三步：编码实现

**原则：边写边讲，保持沟通**

**实现顺序：**

```
1. 写函数签名和注释
   ↓
2. 处理边界情况
   ↓
3. 实现核心逻辑
   ↓
4. 补充辅助函数
```

**示例：**

```python
def findKthLargest(nums, k):
    """
    查找数组中第 K 大的元素

    Args:
        nums: 整数数组
        k: 目标排名（1 <= k <= len(nums)）

    Returns:
        第 K 大的整数

    思路：使用快速选择算法，平均 O(n) 时间复杂度
    """
    # 边界处理
    if not nums or k < 1 or k > len(nums):
        raise ValueError("Invalid input")

    def partition(left, right, pivot_idx):
        """分区函数：将大于 pivot 的元素放左边"""
        pivot = nums[pivot_idx]
        # 将 pivot 移到末尾
        nums[pivot_idx], nums[right] = nums[right], nums[pivot_idx]

        store_idx = left
        for i in range(left, right):
            if nums[i] > pivot:  # 降序排列
                nums[i], nums[store_idx] = nums[store_idx], nums[i]
                store_idx += 1

        # 将 pivot 放到最终位置
        nums[store_idx], nums[right] = nums[right], nums[store_idx]
        return store_idx

    # 快速选择主逻辑
    left, right = 0, len(nums) - 1
    k_idx = k - 1  # 转换为索引

    while left <= right:
        # 选择中间元素作为 pivot
        pivot_idx = (left + right) // 2
        new_pivot_idx = partition(left, right, pivot_idx)

        if new_pivot_idx == k_idx:
            return nums[new_pivot_idx]
        elif new_pivot_idx < k_idx:
            left = new_pivot_idx + 1
        else:
            right = new_pivot_idx - 1

    # 理论上不会到达这里
    raise Exception("Unexpected error")
```

### 3.5 第四步：测试验证

**测试用例设计：**

```python
# 1. 正常情况
assert findKthLargest([3, 2, 1, 5, 6, 4], 2) == 5
assert findKthLargest([3, 2, 3, 1, 2, 4, 5, 5, 6], 4) == 4

# 2. 边界情况
assert findKthLargest([1], 1) == 1  # 单元素
assert findKthLargest([1, 2], 1) == 2  # 第 1 大
assert findKthLargest([1, 2], 2) == 1  # 第 K 大（K = 数组长度）

# 3. 特殊情况
assert findKthLargest([3, 3, 3], 2) == 3  # 所有元素相同
assert findKthLargest([-1, -2, -3], 1) == -1  # 负数

# 4. 错误输入（如果有错误处理）
try:
    findKthLargest([], 1)
    assert False, "Should raise error"
except ValueError:
    pass
```

**手动追踪（Dry Run）：**

```
输入：nums = [3, 2, 1, 5, 6, 4], k = 2

第 1 轮：
  pivot_idx = 2, pivot = 1
  分区后：[3, 2, 5, 6, 4, 1]
  new_pivot_idx = 5, k_idx = 1
  → 在左半部分：right = 4

第 2 轮：
  left = 0, right = 4
  pivot_idx = 2, pivot = 5
  分区后：[6, 5, 3, 2, 4]
  new_pivot_idx = 1, k_idx = 1
  → 找到答案：nums[1] = 5
```

## 4. 常见代码模式与技巧

### 4.1 双指针（Two Pointers）

**适用场景：** 数组、链表、字符串的查找、删除、合并

**模式 1：对撞指针**

```python
def isPalindrome(s: str) -> bool:
    """判断是否为回文串"""
    left, right = 0, len(s) - 1

    while left < right:
        # 跳过非字母数字字符
        while left < right and not s[left].isalnum():
            left += 1
        while left < right and not s[right].isalnum():
            right -= 1

        if s[left].lower() != s[right].lower():
            return False

        left += 1
        right -= 1

    return True
```

**模式 2：快慢指针**

```python
def hasCycle(head: ListNode) -> bool:
    """判断链表是否有环"""
    if not head or not head.next:
        return False

    slow = head
    fast = head.next

    while slow != fast:
        if not fast or not fast.next:
            return False
        slow = slow.next
        fast = fast.next.next

    return True
```

**模式 3：滑动窗口**

```python
def lengthOfLongestSubstring(s: str) -> int:
    """最长无重复子串"""
    char_set = set()
    left = 0
    max_len = 0

    for right in range(len(s)):
        # 移除重复字符
        while s[right] in char_set:
            char_set.remove(s[left])
            left += 1

        char_set.add(s[right])
        max_len = max(max_len, right - left + 1)

    return max_len
```

### 4.2 哈希表（Hash Map）

**适用场景：** 快速查找、去重、计数

```python
def twoSum(nums: list, target: int) -> list:
    """两数之和"""
    seen = {}  # {值: 索引}

    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i

    return []

def groupAnagrams(strs: list) -> list:
    """字母异位词分组"""
    from collections import defaultdict

    groups = defaultdict(list)

    for s in strs:
        # 使用排序后的字符串作为 key
        key = ''.join(sorted(s))
        groups[key].append(s)

    return list(groups.values())
```

### 4.3 栈（Stack）

**适用场景：** 括号匹配、表达式求值、单调栈

```python
def isValid(s: str) -> bool:
    """有效的括号"""
    stack = []
    pairs = {'(': ')', '{': '}', '[': ']'}

    for char in s:
        if char in pairs:
            stack.append(char)
        elif not stack or pairs[stack.pop()] != char:
            return False

    return not stack

def dailyTemperatures(temperatures: list) -> list:
    """下一个更高温度（单调栈）"""
    n = len(temperatures)
    result = [0] * n
    stack = []  # 存储索引

    for i in range(n):
        # 当前温度大于栈顶温度，弹出并记录天数
        while stack and temperatures[i] > temperatures[stack[-1]]:
            prev_idx = stack.pop()
            result[prev_idx] = i - prev_idx
        stack.append(i)

    return result
```

### 4.4 递归与回溯

**适用场景：** 树的遍历、组合问题、路径搜索

```python
def permute(nums: list) -> list:
    """全排列（回溯）"""
    result = []

    def backtrack(path, remaining):
        if not remaining:
            result.append(path[:])
            return

        for i in range(len(remaining)):
            # 选择
            path.append(remaining[i])
            # 递归
            backtrack(path, remaining[:i] + remaining[i+1:])
            # 撤销选择
            path.pop()

    backtrack([], nums)
    return result

def combinationSum(candidates: list, target: int) -> list:
    """组合总和"""
    result = []

    def backtrack(start, path, remain):
        if remain == 0:
            result.append(path[:])
            return
        if remain < 0:
            return

        for i in range(start, len(candidates)):
            path.append(candidates[i])
            # 可以重复使用当前元素，所以传 i 而不是 i+1
            backtrack(i, path, remain - candidates[i])
            path.pop()

    backtrack(0, [], target)
    return result
```

```python
def coinChange(coins: list, amount: int) -> int:
    """
    零钱兑换
    dp[i] = 凑成金额 i 所需的最少硬币数
    """
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0

    for i in range(1, amount + 1):
        for coin in coins:
            if i >= coin:
                dp[i] = min(dp[i], dp[i - coin] + 1)

    return dp[amount] if dp[amount] != float('inf') else -1

def longestCommonSubsequence(text1: str, text2: str) -> int:
    """
    最长公共子序列
    dp[i][j] = text1[:i] 和 text2[:j] 的 LCS 长度
    """
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i-1] == text2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    return dp[m][n]
```

```python
def searchRange(nums: list, target: int) -> list:
    """查找第一个和最后一个位置"""
    def findFirst():
        left, right = 0, len(nums) - 1
        result = -1
        while left <= right:
            mid = left + (right - left) // 2
            if nums[mid] >= target:
                if nums[mid] == target:
                    result = mid
                right = mid - 1
            else:
                left = mid + 1
        return result

    def findLast():
        left, right = 0, len(nums) - 1
        result = -1
        while left <= right:
            mid = left + (right - left) // 2
            if nums[mid] <= target:
                if nums[mid] == target:
                    result = mid
                left = mid + 1
            else:
                right = mid - 1
        return result

    return [findFirst(), findLast()]
```

## 8. 实战案例

### 8.1 案例 1：前端 - 实现 Promise.all

**题目：** 手写 `Promise.all` 实现

**分析：**
- 输入：Promise 数组
- 输出：新的 Promise（所有成功时返回结果数组，任一失败时返回错误）
- 关键：需要追踪所有 Promise 的完成状态

**实现：**

```javascript
function promiseAll(promises) {
    return new Promise((resolve, reject) => {
        // 边界处理
        if (!Array.isArray(promises)) {
            return reject(new TypeError('Argument must be an array'));
        }

        if (promises.length === 0) {
            return resolve([]);
        }

        const results = [];
        let completedCount = 0;

        promises.forEach((promise, index) => {
            // 确保是 Promise（支持非 Promise 值）
            Promise.resolve(promise)
                .then(value => {
                    results[index] = value;
                    completedCount++;

                    // 所有 Promise 都成功
                    if (completedCount === promises.length) {
                        resolve(results);
                    }
                })
                .catch(error => {
                    // 任一 Promise 失败，立即 reject
                    reject(error);
                });
        });
    });
}

// 测试
const p1 = Promise.resolve(1);
const p2 = new Promise(resolve => setTimeout(() => resolve(2), 100));
const p3 = Promise.resolve(3);

promiseAll([p1, p2, p3])
    .then(results => console.log(results))  // [1, 2, 3]
    .catch(error => console.error(error));
```

**关键点：**
1. 使用 `results[index]` 而非 `results.push()` 保持顺序
2. 用 `Promise.resolve()` 包装以支持非 Promise 值
3. 用计数器追踪完成状态，而非 `results.length`（因为数组是稀疏的）

### 8.2 案例 2：后端 - 实现线程安全的单例模式

**题目：** 实现一个线程安全的单例类

**分析：**
- 需求：全局唯一实例
- 挑战：多线程环境下避免重复创建
- 方案：双重检查锁定（Double-Checked Locking）

**实现（Python）：**

```python
import threading

class Singleton:
    _instance = None
    _lock = threading.Lock()

    def __new__(cls):
        # 第一次检查（无锁，性能优化）
        if cls._instance is None:
            with cls._lock:
                # 第二次检查（加锁，保证线程安全）
                if cls._instance is None:
                    cls._instance = super().__new__(cls)
        return cls._instance

    def __init__(self):
        # 确保初始化只执行一次
        if not hasattr(self, '_initialized'):
            self._initialized = True
            self.data = []

# 测试
def create_instance():
    instance = Singleton()
    print(f"Instance ID: {id(instance)}")

# 多线程测试
threads = [threading.Thread(target=create_instance) for _ in range(5)]
for thread in threads:
    thread.start()
for thread in threads:
    thread.join()

# 输出：所有线程得到相同的实例 ID
```

**关键点：**
1. 双重检查：第一次检查避免不必要的锁开销
2. 使用 `__new__` 而非 `__init__`（`__init__` 每次都会调用）
3. `_initialized` 标志防止重复初始化

**实现（Java）：**

```java
public class Singleton {
    // volatile 确保多线程可见性
    private static volatile Singleton instance;

    private Singleton() {
        // 私有构造函数
    }

    public static Singleton getInstance() {
        if (instance == null) {
            synchronized (Singleton.class) {
                if (instance == null) {
                    instance = new Singleton();
                }
            }
        }
        return instance;
    }
}
```

### 8.3 案例 3：算法 - 最小栈

**题目：** 设计一个栈，支持 push、pop、top 和 getMin 操作，所有操作时间复杂度为 O(1)

**分析：**
- 普通栈容易实现 push、pop、top
- 难点：如何在 O(1) 时间获取最小值
- 方案：维护一个辅助栈，存储当前最小值

**实现：**

```python
class MinStack:
    def __init__(self):
        """
        使用两个栈：
        - stack: 存储所有元素
        - min_stack: 存储每个位置对应的最小值
        """
        self.stack = []
        self.min_stack = []

    def push(self, val: int) -> None:
        """O(1) 时间"""
        self.stack.append(val)

        # 更新最小值栈
        if not self.min_stack:
            self.min_stack.append(val)
        else:
            self.min_stack.append(min(val, self.min_stack[-1]))

    def pop(self) -> None:
        """O(1) 时间"""
        if self.stack:
            self.stack.pop()
            self.min_stack.pop()

    def top(self) -> int:
        """O(1) 时间"""
        return self.stack[-1] if self.stack else None

    def getMin(self) -> int:
        """O(1) 时间"""
        return self.min_stack[-1] if self.min_stack else None

# 测试
min_stack = MinStack()
min_stack.push(-2)
min_stack.push(0)
min_stack.push(-3)
print(min_stack.getMin())  # -3
min_stack.pop()
print(min_stack.top())     # 0
print(min_stack.getMin())  # -2
```

**关键点：**
1. 空间换时间：使用额外栈存储最小值
2. 同步操作：push/pop 时同时更新两个栈
3. 边界处理：检查栈是否为空

**优化（空间）：**

```python
class MinStack:
    def __init__(self):
        # 只存储 (值, 当前最小值) 元组
        self.stack = []

    def push(self, val: int) -> None:
        if not self.stack:
            self.stack.append((val, val))
        else:
            self.stack.append((val, min(val, self.stack[-1][1])))

    def pop(self) -> None:
        if self.stack:
            self.stack.pop()

    def top(self) -> int:
        return self.stack[-1][0] if self.stack else None

    def getMin(self) -> int:
        return self.stack[-1][1] if self.stack else None
```

### 8.4 案例 4：系统设计 - 实现 URL 短链接服务

**题目：** 设计一个 URL 短链接服务，类似 bit.ly

**需求分析：**
1. 功能：长 URL → 短 URL，短 URL → 长 URL
2. 性能：读多写少，需要高并发
3. 约束：短 URL 长度固定（如 6 位）

**方案设计：**

```python
import hashlib
import string
import random

class URLShortener:
    def __init__(self):
        """
        使用两个哈希表：
        - long_to_short: {长 URL: 短码}
        - short_to_long: {短码: 长 URL}
        """
        self.long_to_short = {}
        self.short_to_long = {}
        self.domain = "http://short.ly/"
        self.chars = string.ascii_letters + string.digits  # 62 个字符

    def encode(self, long_url: str) -> str:
        """
        长 URL → 短 URL

        策略：使用 MD5 哈希 + 截取前 6 位
        冲突处理：添加随机盐重新哈希
        """
        # 检查是否已存在
        if long_url in self.long_to_short:
            return self.domain + self.long_to_short[long_url]

        # 生成短码
        short_code = self._generate_short_code(long_url)

        # 处理冲突
        while short_code in self.short_to_long:
            # 添加随机盐重新生成
            salt = ''.join(random.choices(self.chars, k=4))
            short_code = self._generate_short_code(long_url + salt)

        # 存储映射
        self.long_to_short[long_url] = short_code
        self.short_to_long[short_code] = long_url

        return self.domain + short_code

    def decode(self, short_url: str) -> str:
        """
        短 URL → 长 URL
        """
        short_code = short_url.replace(self.domain, "")
        return self.short_to_long.get(short_code, "")

    def _generate_short_code(self, url: str) -> str:
        """
        生成 6 位短码

        方法：MD5 哈希 → 转 Base62 → 截取前 6 位
        """
        hash_value = hashlib.md5(url.encode()).hexdigest()
        # 取前 8 位转为整数
        num = int(hash_value[:8], 16)
        # 转 Base62
        short_code = self._base62_encode(num)
        # 补齐到 6 位
        return short_code[:6].ljust(6, '0')

    def _base62_encode(self, num: int) -> str:
        """整数转 Base62"""
        if num == 0:
            return self.chars[0]

        result = []
        base = len(self.chars)

        while num:
            result.append(self.chars[num % base])
            num //= base

        return ''.join(reversed(result))

# 测试
shortener = URLShortener()

url1 = "https://www.example.com/very/long/url/path?query=123"
short1 = shortener.encode(url1)
print(f"Short URL: {short1}")

decoded = shortener.decode(short1)
print(f"Decoded: {decoded}")
assert decoded == url1

# 相同 URL 返回相同短码
short2 = shortener.encode(url1)
assert short1 == short2
```

**关键点：**
1. **哈希选择**：MD5 足够快，冲突率低
2. **Base62 编码**：比 Base64 更适合 URL（无特殊字符）
3. **冲突处理**：添加盐重新哈希
4. **双向映射**：支持快速查询

**生产级优化：**

```python

    def __init__(self, db, cache):

        self.cache = cache  # Redis 缓存

        # 1. 检查缓存

            return self.domain + cached

        # 2. 检查数据库
        result = self.db.query("SELECT short_code FROM urls WHERE long_url = ?", long_url)
        if result:
            short_code = result[0]
            self.cache.set(f"long:{long_url}", short_code, ttl=3600)
            return self.domain + short_code

        # 3. 生成新短码（使用自增 ID）
        url_id = self.db.execute("INSERT INTO urls (long_url) VALUES (?) RETURNING id", long_url)
        short_code = self._base62_encode(url_id)

        # 4. 更新数据库和缓存
        self.db.execute("UPDATE urls SET short_code = ? WHERE id = ?", short_code, url_id)
        self.cache.set(f"long:{long_url}", short_code, ttl=3600)
        self.cache.set(f"short:{short_code}", long_url, ttl=3600)

        return self.domain + short_code

    def decode(self, short_url: str) -> str:
        short_code = short_url.replace(self.domain, "")

        # 1. 检查缓存
        cached = self.cache.get(f"short:{short_code}")
        if cached:
            return cached

        # 2. 查询数据库
        result = self.db.query("SELECT long_url FROM urls WHERE short_code = ?", short_code)
        if result:
            long_url = result[0]
            self.cache.set(f"short:{short_code}", long_url, ttl=3600)
            return long_url

        return ""
```
