## 1. 项目背景与需求分析

### 1.1 项目目标

构建一个企业级 AI 编码助手，帮助开发团队：
- 理解代码库（通过 RAG 检索代码和文档）
- 自动修复 Bug（通过 Agent 编排执行代码修改）
- 代码审查（通过工具调用获取 PR 信息并分析）
- 回答技术问题（结合内部知识库）

### 1.2 技术需求

| 需求 | 指标 |
|------|------|
| 首 Token 延迟 | < 500ms (P95) |
| 并发用户数 | 500+ |
| 可用性 | 99.9% |
| 月度预算 | < $10,000 |
| 数据安全 | 代码不出企业网络 |
| 模型灵活性 | 支持切换模型（自托管 + 云端） |

### 1.3 技术选型决策

```
需求 → 技术选型:
├── 代码不出网 → 自托管推理 (vLLM)
├── 模型灵活性 → AI 网关 (LiteLLM)
├── 代码理解 → RAG + 代码搜索 (MCP Tools)
├── 自动修复 → ReAct Agent + 工具调用
├── 团队协作 → Web UI (Next.js)
├── 成本控制 → 模型级联 + 缓存
└── 可观测性 → LangFuse + Prometheus
```

## 5. Agent 层：核心逻辑

### 5.1 ReAct Agent 实现

```python
class CodingAgent:
    def __init__(self, llm_client, mcp_clients, rag_engine):
        self.llm = llm_client
        self.tools = self._collect_tools(mcp_clients)
        self.rag = rag_engine
        self.max_steps = 20
        self.max_tokens = 200_000
    
    async def execute(self, user_message: str, conversation: list):
        """ReAct 执行循环"""
        messages = self._build_context(user_message, conversation)
        total_tokens = 0
        
        for step in range(self.max_steps):
            # Token 预算检查
            if total_tokens > self.max_tokens:
                break
            
            # LLM 推理
            response = await self.llm.chat(
                model="code-assistant",
                messages=messages,
                tools=self.tools,
                stream=True
            )
            
            total_tokens += response.usage.total_tokens
            
            if response.tool_calls:
                # 执行工具调用
                for tc in response.tool_calls:
                    result = await self._execute_tool(tc)
                    messages.append({
                        "role": "tool",
                        "content": result,
                        "tool_call_id": tc.id
                    })
            else:
                # 生成最终回答
                return response
        
        return self._create_timeout_response()
    
    def _build_context(self, user_message, conversation):
        """构建上下文：系统提示 + RAG + 对话历史"""
        system_prompt = self._load_system_prompt()
        
        # RAG 检索相关代码
        code_context = self.rag.search(user_message, top_k=5)
        
        messages = [
            {"role": "system", "content": system_prompt},
            {"role": "system", "content": f"相关代码上下文:\n{code_context}"}
        ]
        
        # 添加对话历史（Token 预算内）
        messages.extend(self._truncate_history(conversation))
        messages.append({"role": "user", "content": user_message})
        
        return messages
```

### 5.2 请求分类（模型级联）

```python
async def classify_and_route(user_message: str) -> str:
    """使用小模型分类，决定路由策略"""
    classification = await llm.chat(
        model="classifier",  # 8B 小模型，快速便宜
        messages=[{
            "role": "system",
            "content": "Classify the user request. Reply with exactly one word: SIMPLE, COMPLEX, or CODE_CHANGE"
        }, {
            "role": "user",
            "content": user_message
        }],
        max_tokens=5
    )
    
    category = classification.choices[0].message.content.strip()
    
    if category == "SIMPLE":
        return "classifier"  # 小模型直接回答
    elif category == "COMPLEX":
        return "code-assistant"  # 大模型回答
    else:  # CODE_CHANGE
        return "code-assistant"  # 大模型 + Agent 模式
```

'use client';

import { useChat } from 'ai/react';

export function Chat() {
  const { messages, input, handleInputChange, handleSubmit, isLoading, stop } = useChat({

  });

  return (
    <div className="flex flex-col h-screen">
      <div className="flex-1 overflow-y-auto">

        ))}

        )}

## 10. 常见陷阱与最佳实践

### ❌ 陷阱 1：一开始就用最大的模型

```python
# ❌ 错误：所有请求都用 70B 模型
response = await llm.chat(model="llama-70b", ...)

# ✅ 正确：模型级联，简单请求用小模型
complexity = await classify(user_message)  # 8B 模型分类
if complexity == "SIMPLE":
    response = await llm.chat(model="llama-8b", ...)  # 便宜 10 倍
else:
    response = await llm.chat(model="llama-70b", ...)
```

### ❌ 陷阱 2：不设置 Agent 执行上限

```python
# ❌ 错误：Agent 可能无限循环
while not done:
    response = await agent.step()

# ✅ 正确：步数 + Token + 时间三重保护
for step in range(MAX_STEPS):
    if total_tokens > TOKEN_BUDGET:
        break
    if time.time() - start > TIMEOUT:
        break
    response = await agent.step()
```

### ❌ 陷阱 3：没有 Fallback 机制

```yaml
# ❌ 错误：只有自托管模型，硬件故障 = 服务中断

# ✅ 正确：自托管主力 + 云端 Fallback
router_settings:
  fallbacks: [{"code-assistant": ["openai/gpt-4o"]}]
```

### ❌ 陷阱 4：不做 RAG 质量评估

```python
# ❌ 错误：部署 RAG 后不评估检索质量

# ✅ 正确：定期自动评估
# 维护评估集 → 跑 RAGAS → 设置 Faithfulness < 0.8 告警
```

### ❌ 陷阱 5：忽略冷启动延迟

```yaml
# ❌ 错误：readinessProbe 太早开始检查
readinessProbe:
  initialDelaySeconds: 10  # 模型加载需要 3 分钟！

# ✅ 正确：根据模型大小设置合理的初始延迟
readinessProbe:
  initialDelaySeconds: 180  # 70B 模型需要 2-3 分钟加载
  periodSeconds: 10
```
