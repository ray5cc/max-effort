## 说明

编码题（Hand-written Code / Live Coding）是技术面试中最核心的环节之一，不仅考察技术能力，也考察问题解决能力和沟通协作能力。

本目录包含：
- **编码方法论**：四步解题法（理解题意 → 设计方案 → 编码实现 → 测试验证）
- **常见代码模式**：双指针、哈希表、栈、递归、动态规划、二分查找、位运算等
- **代码规范**：命名规范、注释文档、错误处理、边界条件
- **时间管理**：如何在限定时间内高效完成编码
- **调试技巧**：打印调试、断言验证、手动追踪
- **实战案例**：前端、后端、算法、系统设计等各领域典型编码题解析
