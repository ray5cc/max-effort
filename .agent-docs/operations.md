## 命名约定

| 类型 | 格式 | 示例 |
|------|------|------|
| 文件夹 | `NN-分类名` | `01-前端`、`07-AI-Agent全栈开发` |
| 文档文件 | `NN-技术名.md` | `01-LLM原理.md` |
| 月度日志 | `YYYY-MM.md` | `2026-03.md` |
| 目录文件 | `README.md`（固定） | — |
| 规范文档 | 小写连字符 | `operations.md` |

## 添加新文档时：必须执行的操作

添加或修改任何文件后，**必须**按顺序执行：

- [ ] 更新所在子目录的 `README.md`，添加新文件链接与描述
- [ ] 更新父级 `README.md`（若分类层面有变更）
- [ ] 更新根 `llms.txt`，在对应分类下追加新链接
- [ ] 在 `CHANGELOG/YYYY-MM.md` 中追加操作记录

> **提示**：`01-技术资料` 与 `02-面试指南` 分类编号完全对应，添加任一目录的内容时，应同步在对应目录中添加关联文档，并在文档内添加相互跳转的链接。

---

## 添加新分类文件夹时

1. 文件夹名称格式：`NN-分类名`（如 `08-移动端`）
2. 在 `01-技术资料/` 和 `02-面试指南/` 中**同步**创建对应分类文件夹
3. 每个新文件夹必须包含一个 `README.md` 目录文件
4. 更新 `CLAUDE.md` 技术分类表、各级 `README.md` 以及 `llms.txt`

---

## 操作日志格式

在 `CHANGELOG/YYYY-MM.md` 中追加如下格式的记录：

```markdown
## YYYY-MM-DD

### 新增
- `路径/文件名.md`：简短描述

### 修改
- `路径/文件名.md`：修改内容简述

### 删除
- `路径/文件名.md`：删除原因
```

> 单月文件超过 300 行时，在同一目录新建 `YYYY-MM-part2.md` 并在文件头注明。

## 注意事项

- 不要删除现有目录结构中的 `README.md` 文件
- 不要跳过编号，序号应连续；若需在中间插入，保持已有序号不变，新内容使用递增序号
- 所有链接使用**相对路径**
- `AGENTS.md` 保持精简（TOC 式），详细说明应在本文件或对应领域文档中
- 每篇技术文档**必须**包含「常见陷阱与最佳实践」章节
- 每篇技术文档**建议**包含开头 TL;DR 速览（5-8 条核心要点）
