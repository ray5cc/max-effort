# Max Effort — 技术资料与面试指南

> 一站式技术学习资料与面试指南知识库，涵盖前端、后端、数据库、算法、系统设计、DevOps 等核心领域。

## 项目简介

本项目分为两大根目录，内容分类一一对应，支持相互跳转：

| 目录 | 说明 |
|------|------|
| [01-技术资料](./01-技术资料/README.md) | 各技术领域的系统性学习文档 |
| [02-面试指南](./02-面试指南/README.md) | 对应领域的面试题目、解题思路与高频考点 |

## 技术分类

两大目录均按以下分类组织，分类编号一一对应：

1. **前端** — HTML/CSS/JavaScript/框架
2. **后端** — Java/Go/Python/Node.js 等服务端技术
3. **数据库** — 关系型数据库、NoSQL、缓存
4. **算法与数据结构** — 常见算法、复杂度分析、LeetCode
5. **系统设计** — 高并发、分布式、架构设计
6. **DevOps 与云计算** — CI/CD、容器化、云服务

## 使用说明

- 每个目录下包含一个 `README.md` 总目录文件，列出所有子文档的链接与描述
- 文件夹和文件均以序号开头，保持有序
- 技术资料与面试指南的分类相互对应，方便对照学习与备考
